1.数据库驱动

  • (1)常见的驱动例如声卡显卡，这些东西直接插到计算机上面是不能用的，必须要安装相应的驱动程序之后才能够使用，同样地，安装好数据库之后，应用程序也是不能直接使用数据库的，必须要通过相应的数据库驱动程序，通过驱动程序去和数据库打交道。JDBC(Java Database Connectivity)即使用Java语言操作关系型数据库的一套API，提供了一个Java操作数据库的规范（规则）接口，实现开发人员对数据库的统一操作，通过JDBC加载具体的驱动，以操作数据库。而这些规范的实现是由具体的厂商去做。
  • (2)驱动的本质就是各种实现类，我们可以使用这套接口（JDBC）编程，真正执行的代码是驱动jar包中的实现类。

// 示例代码
// 测试代码
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.ResultSet;
import java.sql.Statement;

public class JdbcFirstDemo {
    public static void main(String[] args) throws Exception{
        // 1.加载驱动，识别要用到什么驱动
        Class.forName("com.mysql.jdbc.Driver"); // 固定写法，Class.forName()类加载

        /** 2.填写用户信息和url
        * jdbcStudy是我们自己建的测试数据库
				* jdbc:mysql://localhost:3306/jdbcStudy这一串已经能指向数据库，这里我们在MySQL中已经新建一个数据库jdbcStudy
				* ?之后的参数是一些完善性的设置，其中，uesUnicode=true表示支持中文编码，characterEncoding=utf8表示设定字符集防止乱码，useSSL=true表示使用安全的连接
        */
        String url = "jdbc:mysql://localhost:3306/jdbcStudy?uesUnicode=true&characterEncoding=utf8&useSSL=true";
        String username = "root"; //用户名和密码都是当初MySQL数据库里自行设置的
        String password = "root";

        // 3.连接上数据库，数据库对象，这里的connection实际上就代表数据库
        Connection connection = DriverManager.getConnection(url, username, password);

        // 4.获取执行SQL的对象statement，statement对象做增删改查CRUD操作
        Statement statement = connection.createStatement(); // connection.createStatement()即创建向数据库发送sql的statement对象

        // 5.获取SQL对象，定义要执行的SQL语句
        String sql = "SELECT * FROM users";

        // resultSet解析对象只能一个字段一个字段解析
        ResultSet resultSet = statement.executeQuery(sql);  // 返回结果集，结果集中封装了我们全部查询出来的对象
        // 测试打印所有数据
        while(resultSet.next()){
            System.out.println("id=" + resultSet.getObject("id"));
            System.out.println("name=" + resultSet.getObject("NAME"));
            System.out.println("pwd=" + resultSet.getObject("PASSWORD"));
            System.out.println("email=" + resultSet.getObject("email"));
            System.out.println("both=" + resultSet.getObject("birthday"));
        }

        // 6.释放（关闭）连接，先开的后关，后开的先关
        resultSet.close();
        statement.close();
        connection.close();

    }
}

package com.github.test;

import java.sql.*;

public class TestJDBC2 {
    public static void main(String[] args) throws ClassNotFoundException, SQLException {
        // 配置信息
        // useUnicode=true&characterEncoding=utf-8 解决中文乱码
        String url="jdbc:mysql://localhost:3306/jdbc?useUnicode=true&characterEncoding=utf-8";
        String username = "root";
        String password = "root";

        // 1.加载驱动
        Class.forName("com.mysql.jdbc.Driver");
        // 2.连接数据库,代表数据库
        Connection connection = DriverManager.getConnection(url, username, password);

        // 3.编写SQL
        String sql = "insert into  users(id, name, password, email, birthday) values (?,?,?,?,?);";

        // 4.预编译
        PreparedStatement preparedStatement = connection.prepareStatement(sql);

        // 给第一个占位符？ 的值赋值为1；
        preparedStatement.setInt(1,2);
        // 给第二个占位符？ 的值赋值为测试熊；
        preparedStatement.setString(2,"测试熊");
        // 给第三个占位符？ 的值赋值为123456；
        preparedStatement.setString(3,"123456");
        // 给第四个占位符？ 的值赋值为654321@qq.com；
        preparedStatement.setString(4,"654321@qq.com");
        // 给第五个占位符？ 的值赋值为new Date(new java.util.Date().getTime())；
        preparedStatement.setDate(5,new Date(new java.util.Date().getTime()));

        // 5.执行SQL
        int i = preparedStatement.executeUpdate();

        if (i>0){
            System.out.println("插入成功@");
        }

        // 6.关闭连接，释放资源（一定要做） 先开后关
        preparedStatement.close();
        connection.close();
    }
}

3.核心类

(1)DriverManager

  • 1)作用：驱动管理。
    • (A)注册驱动。例：Class.forName("com.mysql.jdbc.Driver");，点击进.Driver的源码可以看到静态代码块，本质是调用了DriverManager类的注册方法registerDriver()。
    • (B)获取数据库连接。getConnection(String url, String user, String password)方法的参数：
      • url为数据库连接路径，格式：jdbc:mysql://ip地址(域名):端口号/数据库名称?参数键值对1&参数键值对2...。如果连接的是本机mysql服务器，并且mysql服务默认端口是3306，则url可以简写为：jdbc:mysql:///数据库名称?参数键值对。此外，配置useSSL=false参数，禁用安全连接方式，解决警告提示。
      • user为用户名，是提前在对应数据库中设置好的。
      • password为密码，是提前在对应数据库中设置好的。

(2)Connection

  • 1)作用：数据库连接。
    • (A)获取执行SQL的对象。包括普通执行SQL对象Statement createstatement()，以及预编译SQL的执行SQL对象PreparedStatement prepareStatement(sql)。
    • (B)事务管理。
      • 开启事务：setAutoCommit(boolean autoCommit)方法，true为自动提交事务；false为手动提交事务，即为开启事务
      • 提交事务：commit()方法，
      • 回滚事务：rollback()方法，嵌套try…catch异常捕获实现回滚。

(3)Statement

  • 1)作用：执行SQL语句

  • 2)Statement最核心的两个方法executeUpdate()和executeQuery()，通常增删改都用executeUpdate，查询用executeQuery（executeUpdate其实也可以查询，但较少这样用）。

  • 3)Statement是执行（接口）类，执行静态 SQL 语句，可以执行任何 SQL 语句，也是用Statement进行后续的增删改查操作。例如：

(4)ResultSet

  • 1)ResultSet结果集对象，作用：封装了DQL查询语句（executeQuery()）的结果。
  • 2)获取查询结果的方法：
    • next()方法，将光标从当前位置向前移动一行，并判断当前行是否为有效行（有数据）。常搭配while循环将结果集进行遍历。
    • get某数据类型()方法，如getInt()。

(5)PreparedStatement

  • 1)继承自Statement，作用：预编译SQL，执行SQL语句。
    • (A)正是因为存在SQL注入这样的漏洞，因此实际业务中PreparedStatement对象替代了Statement对象。PreparedStatement防止SQL注入的本质即，把传递进来的参数当作字符，执行的时候参数会用引号包起来，假设存在转义字符就直接忽略，从而避免了参数也作为条件的一部分。
    • (B)PreparedStatement多了一个预编译的环节，先写SQL，然后不执行。需要在url部分开启参数useServerPrepStmts=true。
  • 3)步骤：
    • (A)获取PreparedStatement对象。使用?占位符代替参数，例如String sql = "select * from tb user where username = ? and password = ?"；通过Connection对象获取PreparedStatement对象，例如PreparedStatement ps = connection.prepareStatement(sql);。
    • (B)设置参数值。set某数据类型(参数1,参数2)方法，参数1表示占位符?的位置编号，从1开始，参数2表示占位符?的值。如setInt(2,"测试熊")。
    • (C)执行SQL。executeUpdate()和executeQuery()。这里的参数不用再传递sql。

4.SQL注入

  • 简称由Java操作数据库的过程中存在漏洞，导致一些非法操作可以直接获取/修改数据库信息，导致数据库信息泄露。
  • 例如select * from tb user where username = 'hfkisfhski' and password = ' ' or '1' = '1' ，由于有or '1' = '1'的存在，那么这个SQL语句前面的判断就会失效，直接判定为true，执行后续的代码。

5.数据库连接池

  • (1)用户每次请求都需要向数据库获得连接，而数据库创建连接/释放通常需要消耗相对较大的资源，由此出现池化技术，即准备一些预先的资源，使用时直接连接预先准备好的数据库，并释放空闲时间超过最大空闲时间的连接，来避免因为没有释放连接而引起的数据库连接遗漏。数据库连接池是个容器，负责分配、管理数据库连接(Connection)。
  • (2)编写连接池，只需实现java.sql.DataSource接口，并实现获取连接的方法getConnection()。市面上常见的实现类有DBCP、C3P0、Druid、Hikari（SpringBoot内置）。使用了这些数据库连接池之后，在项目开发中就不需要编写连接数据库的代码了（释放资源的代码依旧需要写明）。（而核心是导入对应的jar包）
