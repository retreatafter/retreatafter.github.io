1.MySQL

(1)概述

  • 1)数据库管理系统DBMS（Database Management System），MySQL就是一个数据库管理系统，我们需要这种软件来管理和操作数据库里的数据。
  • 2)MySQL由瑞典MySQL AB公司开发，目前属于Oracle旗下产品。是现在流行的开源的、免费的、关系型数据库，其使用SQL语言访问数据库。

(2)下载与使用

  • 1)官网：https://dev.mysql.com/downloads/mysql/
  • 2)mysql5.7版本64位压缩包下载地址：https://dev.mysql.com/get/Downloads/MySQL-5.7/mysql-5.7.19-winx64.zip
  • 3)添加环境变量
    • Win11系统为例：控制面板→系统和安全→系统→高级系统设置→环境变量→选择PATH，在编辑环境变量页面添加: 你的MySQL文件目录下面的bin文件夹的路径。
  • 4)如果是下载的压缩包版本，是没有配置文件的，因此需要新建配置文件。在你的MySQL文件目录下新建my.ini文件，重点在于后缀名是.ini。对my.ini文件进行编辑：

# 如果直接粘贴有问题请把注释删掉
[mysqld]
basedir=F:\java\MySQL # 修改成自己的MySQL文件所在目录路径
datadir=F:\java\MySQL\data\ # 只需要修改data前的目录路径，data文件夹会自动生成
port=3306 # 分配的端口号，无需修改
skip-grant-tables # 跳过密码验证
  • 5)用管理员模式进入CMD命令提示符，执行以下操作：
    • 注册：cd /d命令进入到你的MySQL文件目录下面的bin文件夹，执行命令mysqld –install安装MySQL，显示安装成功successfully installed即可。
    • 初始化：执行命令mysqld --initialize-insecure --user=mysql，这个时候可以看到MySQL文件目录下面多了一个data文件夹。
    • 启动：执行命令net start mysql，显示MySQL服务已经启动成功后，是可以在任务管理器-服务中看到MySQL服务正在运行的（不建议直接在任务管理器中操作）。
    • 账户：执行命令mysql –u root –p（–u root是root用户，-p是密码），显示输入密码，如未设置密码回车进入下一步，正式进入到mysql管理界面。
  • 6)修改密码，使用命令update mysql.user set authentication_string=password('root') where user='root' and Host = 'localhost';，此时root用户的密码将会修改为root。接着刷新权限，使用命令flush privileges;。
  • 7)由于此时已经修改了新密码，这时我们需要回到my.ini文件将skip-grant-tables这句注释掉或是删除。
  • 8)重启MySQL，可以先使用命令exit退出mysql管理界面，再使用命令net stop mysql停止服务，这个时候可以看到任务管理器-服务中MySQL服务已经停止（不建议直接在任务管理器中操作），最后，使用命令net start mysql，输入密码（可以直接在mysql –u root –p后直接写密码，注意-p后不要空格），启动MySQL服务。

2.客户端工具

(1)SQLyog

  • 1)SQLyog是可视化管理MySQL数据库的软件工具。这种软件有很多，像Navicat、DataGrip也是类似功能。
  • 2)官网： https://webyog.com/product/sqlyog/
  • 3)下载安装后需要注册码，成功注册后连接数据库SQL，SQL主机地址显示的localhost即127.0.0.1，端口号是新建my.ini文件时就确定下来的，一般都会选择用3306端口号，需要注意的是用户名和密码，取决于上一步安装MySQL时修改的用户名和密码。
  • 4)创建数据库操作
    • 为保证数据同步，通常会先刷新一次对象浏览器。基字符集选择utf8，数据库排序规则选择utf8_general_ci，这样能保证后续输入中文不乱码。
    • 但从历史记录中可以看到，这些操作本质上还是调用了SQL语句。也就是说每一个SQLyog的执行操作，本质就是对应了一个SQL语句，可以在软件的历史记录中查看。
  • 5)创建表操作
    • 同样的，注意修改表的引擎、字符集、核对。
    • 建议后续在新增每一列时都做好注释。

  • 1)DataGrip是JetBrains旗下的一款数据库管理工具。并且IDEA现版本中已直接集成了DataGrip，无需重复下载。
