1.方法的定义与调用

  • (1)方法是程序中最小的执行单元。重复的代码、具有独立功能的代码都可以抽取为方法，从而提高代码的复用性和可维护性。
  • (2)主方法Main
    • 主方法（Main Method）是程序的入口点。
    • 主方法的格式几乎固定。
    • 一个Java应用程序可以有一个且仅有一个主方法。
    • 格式：public static void main(String[] args){ }
    • System.out.println() 语句里，System是类，out是对象，println()是方法。
    • 上句翻译：调用系统类System里的标准输出对象out里的println方法。
  • (3)语法

  • 修饰符：修饰符，这是可选的，告诉编译器如何调用该方法。定义了该方法的访问类型。
  • 返回值类型：方法可能会有返回值。returnValueType是方法返回值的数据类型。有些方法执行所需的操作，但没有返回值。在这种情况下，returnValueType是关键字void。
  • 方法名：是方法的实际名称。方法名和参数表共同构成方法签名。
  • 参数类型：参数像是一个占位符。当方法被调用时，传递值给参数。这个值被称为实参或变量。参数列表是指方法的参数类型、顺序和参数的个数。参数是可选的，方法可以不包含任何参数。
    • 形式参数：在方法被调用时用于接收外界输入的数据。
    • 实际参数：调用方法时实际传给方法的数据。
  • 方法体：方法体包含具体的语句，定义该方法的功能。
  • 规则：编译看左边，运行看右边。例如下述代码，编译时：检查Animal类是否有eat()方法，通过则编译成功。运行时：根据实际对象Cat调用其重写的eat()方法。

  public void eat() { System.out.println("动物吃饭");}
}

class Cat extends Animal{
  @override
  public void eat() { System.out.printin("猫吃鱼");} // 重写基类方法
}

public class Main {
  public static void main(String[] args){
    Animal a = new Cat();//基类引用指向子类对象
    a.eat(); // 输出:猫吃鱼
  }
}

package Chapter5_method;

public class Demo02 {
    public static void main(String[] args) {

        int bigOne =max(10,20);		//实际参数10和20 
        System.out.println("bigOne = "+bigOne);

    }
    // 比较数字大小,写好以下流程，然后到main方法里套用并运行。
    public static int max(int num1,int num2){	//形式参数num1和num2
        int result = 0; //程序里必须要给初始值，不一定一定要写0，反正之后都会被结果覆盖
        if(num1 ==num2){
            System.out.println("num1 = num2");
            return 0;       //  return 0;此时是中止方法的作用，因为方法要求（int）有返回值，所以这里是return 0;而不是return;。
        }
        if( num1 > num2){
            result = num1;
        }else{
            result = num2;
        }
        return result;
    }
}
  • (4)调用方法：
    • 1)静态方法：方法上加了static关键字，可以直接调用。类名.方法名(实参列表)
    • 2)非静态方法：需要实例化new后才可以调用。类名 对象名 = new 类名;对象名.方法名(实参列表)
    • 3)在同一个包中的类可以相互调用。
  • (5)方法的特点：
    • 1)方法不调用就不执行。
    • 2)方法与方法之间是平级关系，不能互相嵌套。
    • 3)方法的编写顺序和执行顺序无关。
    • 4)方法的返回值类型为void，表示该方法没有返回值，没有返回值的方法可以省略return语句。

2.方法的重载&方法的重写

  • (1)方法的【重载】
    • 1)常用场景：计算器。
    • 2)方法重载是指在同一个类中，允许存在一个以上的【同名】方法，只要它们的参数列表不同即可。
    • 3)规则：
      • 方法名称必须相同。
      • 参数列表必须不同（个数不同、或类型不同、参数排列顺序不同等）。
      • 方法的返回类型可以相同也可以不相同。
      • 仅仅返回类型不同不足以成为方法的重载。
    • 4)原理：方法名称相同时，编译器会根据调用方法的参数个数、参数类型等去逐个匹配，以选择对应的方法，如果匹配失败，则编译器报错。

public class Calculator{
    public int add(int a, int b){
        return a+b;
    }
    //方法的重载：参数类型不同
    public double add(double a, double b){
        return a+b;
    }

    //方法的重载：参数数量不同
    public int add(int a, int b, int c){
        return a+b+c;
    }

    //方法的重载：参数类型不同2
    public double add(int a, double b){
        return a+b;
    }
}
  • (2)方法的【重写】
    • 1)方法重写是子类重新定义基类中已经定义过的方法。
    • 2)重写的方法必须具有相同的名称、返回类型、参数列表。
    • 3)重写方法的目的是提供子类特定的实现。

3.可变参数

  • (1)规则：在方法声明中，在指定参数类型后加一个省略号。格式：数据类型... 参数名称。可变参数在方法内部本质上就是一个数组。
    • 1)可以不传输参数。
    • 2)可以传输一个参数。
    • 3)可以传输多个参数。
    • 4)可以传输一个数组。
  • (2)一个形参列表中可变参数只能有一个，且可变参数必须放在形参列表的最后面。

package Chapter5_method;

public class Demo04 {
    public static void main(String[] args) {
        //  调用可变参数的方法
        printMax(34, 3, 7, 2, 56.5);
        printMax(new double[]{1,2,3});

    }
	  //需要比较大小但是不确定有多少个参数
    public static void printMax(double... numbers){ //sum(int...nums, int...nums1)会报错，sum(int...nums,String s)会报错
        if (numbers.length == 0){
            System.out.println("No argument passed");
            return;
        }
				//声明一个数组为返回值，因为...语法本质是定义了一个可变长数组，无需再重复定义new一次数组
        double result = numbers[0];

        // 排序
        for (int i = 1; i < numbers.length; i++) {
            if (numbers[i] > result){
                result = numbers[i];
            }
        }
        System.out.println("The Max Value is " + result);

    }
}

package Chapter5_method;

public class Demo06 {
    // 用递归 计算阶乘。
    public static void main(String[] args) {
        System.out.println(f(5));
    }

    public static int f(int n){
        // 2! = 2*f(1)=2*1
        // 3! = 3*f(2)*f(1)=3*2*1
        //此例题的递归头是n==1，递归体是n*f(n-1)
        if (n==1){
            return 1;
        }else{
            return n*f(n-1);	
        }
    }
}
