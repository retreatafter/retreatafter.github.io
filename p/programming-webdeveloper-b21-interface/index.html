1.概述

  • (1)关键字：
    • 定义：interface。格式public interface 接口名{}。
    • 实现：implements。格式public class 类名 implements 接口名{}。
  • (2)子类和基类的继承只能单继承，但接口可以多实现，即多重继承。
    • public class 类名 implements 接口名1,接口名2,接口名3 {}
    • 且可以在继承一个类的同时实现多个接口。public class 类名 extends 基类 implements 接口名1,接口名2,接口名3 {}

2.特点

  • (1)接口实现约束和实现分离。接口比抽象类更为抽象，只有抽象方法和常量。抽象类中可以存在普通方法，接口中只有抽象方法。（JDK1.8之前）
  • (2)接口不能被实例化，没有构造方法。
  • (3)接口的子类（实现类）要么重写接口中的所有抽象方法，要么是抽象类。
  • (4)接口可以嵌套接口。
  • (5)当一个类，既继承一个基类，又实现若干个接口时，基类中的成员方法与接口中的默认方法重名，子类就近选择执行基类的成员方法。

3.接口与抽象类

  • (1)关键字：接口→interface，抽象类→abstract
  • (2)方法：接口→抽象方法+默认/静态方法，抽象类→抽象方法+具体方法
  • (3)成员变量：接口→只能是常量，抽象类→可以是任意类型变量
  • (4)多继承：接口→支持多实现，抽象类→只能单继承

4.常量与接口

  • (1)接口中的常量前的修饰符：public static final，如果在接口中，可以省略public static final，约定俗成的规定，一般定义常量的时候名字全部大写例如：int AGE =18;
  • (2)抽象方法，在接口中public abstract可以省略，因为接口中方法默认都是抽象方法。例如：void say();

7.版本新增的方法

(1)默认方法

  • (1)JDK8新特性，接口可以通过 default 关键字为方法提供默认实现，这样即使实现类不重写该方法，也能直接使用它。格式：public default 返回值类型 方法名(参数列表) {}。
    • 默认方法不是抽象方法，所以不强制被重写。但是如果被重写，重写的时候需要去掉default关键字。
    • public可以省略，default不能省略。
    • 如果实现了多个接口，多个接口中存在相同名字的默认方法，子类就必须对该方法进行重写。

(2)静态方法

  • (1)JDK8后允许接口中有静态方法。用关键字static修饰，格式：public static 返回值类型 方法名(参数列表) {}。
    • 静态方法只能通过接口名调用，不能通过实现类名或者对象名调用，这点和抽象类有显著区别。
    • public可以省略，static不能省略。

(3)私有方法

  • (1)JDK9版本支持，包括普通私有方法和静态私有方法。是为了解决JDK8引进的默认方法和静态方法。
    • 普通私有方法，格式：private 返回值类型 方法名(参数列表) {}
    • 静态私有方法，格式：private static 返回值类型 方法名(参数列表) {}
