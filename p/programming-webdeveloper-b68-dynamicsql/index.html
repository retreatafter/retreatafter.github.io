1.概述

  • 1)随着用户的输入或外部条件的变化而变化的SQL语句，我们称为动态SQL。在接收用户多个参数时，我们应当考虑到实际业务中用户的实际操作需要我们的系统更灵活，尤其在有文字输入查询面板时，例如用户在输入AA公司和输入AA时都希望能查询到包含该信息的所有相关信息。而动态SQL就是解决这个问题的，SQL语句会随着用户的输入或外部条件的变化而变化。
  • 2)动态SQL的本质是添加了选择控制结构。

2.where标签

  • 1)<where>标签替换where关键字，Mybatis会动态地管理SQL语句是否要添加and或or。（原理等同于添加一个恒等式判断1=1，这样就能避免多个查询条件倘若第一个查询条件（不需要逻辑运算符）不实现，则后面的查询条件因为必须带逻辑运算符and而导致无法执行的情况）

3.if标签

  • 1)多用在多条件动态查询。用于判断条件是否成立，如果条件为true，则拼接SQL。格式：<if test="判断属性值">...sql语句...</if>。

				    and brand_name like #{brandName}
				</if>
		</where>
</select>

						    brand_name like #{brandName}

				</choose>
		</where>
</select>

		<choose> <!--类似于switch-->

						brand_name like #{brandName}
				</when>
				<otherwise> <!--类似于default，这里表示假设用户什么都没有筛选-->
				    1=1
				</otherwise>
		</choose>
</select>

6.foreach标签

  • 1)作用：对集合进行遍历。声明可以在元素体内使用的集合项（item）和索引（index）变量。它也允许指定开头与结尾的字符串以及集合项迭代之间的分隔符（separator）。常用属性：
    • collection：表示接口中的方法参数的类型，数组使用array，集合使用list。
    • item：遍历出来的元素。
    • separator：分隔符。
    • open：遍历开始前拼接的SQL片段。
    • close：遍历结束后拼接的SQL片段。
  • 2)示例：

		<foreach collection="list" item="myid" separator="," open="(" close=")">
				#{myid}
		</foreach>
</delete>

</select>
