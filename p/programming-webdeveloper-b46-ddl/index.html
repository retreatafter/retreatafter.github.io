1.前情提要

  • (1)以下所有操作均在可视化管理MySQL数据库的软件工具SQLyog中进行。重点是查看每个行为执行后的历史记录中的SQL语句。
  • (2)所有的数据库文件都保存在data目录下，一个文件夹对应着一个数据库，因此，数据库本质上仍然是文件的存储。

2.DDL核心操作

  • (1)主要操作：查询、创建、使用、删除。
    • 1)创建数据库：create database [if not exists] 数据库名;，其中括号表示可写可不写，创建数据库时加上if not exists可以在出现同名数据库时有警告提示。
    • 2)删除数据库：drop database [if exists] 数据库名;。
    • 3)使用/切换数据库 : use 数据库名;，如果表名或字段名是一个特殊字符，就需要带反引号，例如创建的school数据库下的student表中存在user列，但user其实是一个常见的特殊字符，这时要查询student表中的user列就建议用语句SELECT `user` FROM student;
    • 4)查看数据库 :
      • show databases;，显示所有数据库。
      • select database();，查询当前数据库。
    • 5)schema=database。

  • (1)数值类型
    • 关键字UnSigned无符号的（整数）：数值的取值范围包括有符号（存在负数）和无符号的两种，例如tinyint的有符号(SIGNED)范围为(-128，127)，无符号(UNSIGNED)范围为(0，255)。

    • 不要用NULL进行算术运算，否则得到的结果仍为NULL。

4.约束

  • (1)约束也称字段属性，约束作用于表中字段上的规则，用于限制存储在表中的数据，保证数据库中数据的正确性、有效性和完整性。
  • (2)类型：
    • 非空约束：限制该字段值不能为null。关键字：not null。对应的有允许NULL空值。
    • 唯一约束：保证字段的所有数据都是唯一、不重复的。关键字：unique。经常配合关键字Auto_InCrement自增使用，即每添加一条数据 , 自动在上一个记录数上加1（这个步长数值是可以设置的）。
    • 主键约束：主键是一行数据的唯一标识，要求非空且唯一。关键字：primary  key。
    • 默认约束：保存数据时，如果未指定该字段值，则采用默认值。关键字：default。
    • 外键约束：让两张表的数据建立连接，保证数据的一致性和完整性。关键字：foreign key。

6.数据表的类型

  • (1)引擎ENGINE，最常用InnoDB和MyISAM，InnoDB是现在比较常用的，MyISAM在以前常用，现在根据场合需要也会用到。其具体区别见下表。
    • MyISAM优点：节约空间，速度较快。
    • InnoDB优点：安全性高，支持事务处理，多用户操作数据表。
    • InnoDB类型数据表只有一个 [*.frm]表结构定义文件 , 以及上一级目录的[ibdata1]文件。
    • MyISAM类型数据表对应三个文件：[* . frm] 表结构定义文件、[. MYD] 数据文件 ( data )、[. MYI] 索引文件 ( index )。
功能 MyISAM InnoDB
事务处理 不支持 支持
数据行锁定 不支持 支持
外键约束 不支持 支持
全文索引 支持 不支持
表空间大小（内存占用） 较小 较大，约MyISAM的2倍
  • (2)字符集编码CHARSET，如果不设置，将会是MySQL默认的字符集编码，而最大的问题是这个字符集编码不支持中文。设定CHARSET一是可以在建表时通过命令设定，二也可以通过修改MySQL数据库配置文件[my.ini]中的参数设定character-set-server=utf8。

7.表操作ALTER与DROP

  • (1)修改表ALTER TABLE
    • 1)修改表名：ALTER TABLE `旧表名` RENAME AS `新表名` 或 RENAME TABLE `旧表名` TO `新表名`
    • 2)修改字段：
      • 修改约束：ALTER TABLE `表名` MODIFY `字段名` 列类型[新属性]
      • 字段重命名：ALTER TABLE `表名` CHANGE `旧字段名` `新字段名` 列属性[属性]
    • 3)添加字段：ALTER TABLE `表名` ADD `字段名` 列属性[属性]
    • 4)删除字段：ALTER TABLE `表名` DROP COLUMN `字段名`
    • 5)中括号[]表示根据需要可写可不写。

--示例代码
USE school;

CREATE TABLE `teacher`( 
    `id` INT(9) NOT NULL COMMENT '教师ID', 
    `name` VARCHAR(100) NOT NULL COMMENT '教师姓名', 
    `age` INT(3) NOT NULL COMMENT '教师年龄', 
    PRIMARY KEY (`id`)
) ENGINE=INNOBASE CHARSET=utf8 COLLATE=utf8_general_ci

-- 修改表名 ALTER TABLE `旧表名` RENAME AS `新表名`
ALTER TABLE teacher RENAME AS teacher1

-- 添加字段 ALTER TABLE `表名` ADD `字段名` 列属性[属性]
ALTER TABLE teacher1 ADD age INT(12)

-- 修改字段
ALTER TABLE teacher1 MODIFY age VARCHAR(12)	-- 修改约束，从原先的INT(3)属性改为了VARCHAR(12)属性
ALTER TABLE teacher1 CHANGE age age1 INT(12)    -- 字段重命名

-- 删除字段 ALTER TABLE `表名` DROP `字段名`
ALTER TABLE teacher1 DROP age1
  • (2)删除表
    • 语法：DROP TABLE [IF EXISTS] `表名`
    • 中括号[]表示根据需要可写可不写。
