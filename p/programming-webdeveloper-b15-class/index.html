1.概述

  • (1)思想：对于描述复杂的事物，为了从宏观上把握、从整体上合理分析，我们需要使用【面向对象】的思路来分析整个系统。但是，具体到微观操作，仍然需要【面向过程】的思路去处理。
  • (2)面向对象（OOP，Object-OrientedProgramming）编程本质：以类的方式组织代码，以对象的组织（封装）数据。
  • (3)类相当于我们创建的一种新的数据类型。

2.类

  • (1)类是一个抽象的数据类型。描述抽象特征，而非具体实例。类是一个模板，较抽象。定义一个类的格式：修饰符 class 类名{}。
  • (2)一个类中有且仅有以下五种成分：
    • 1)成员变量Filed，静态的表述（属性信息）。
    • 2)成员方法Method，动态的行为（方法）。
    • 3)构造器Constructor，初始化一个类的对象并返回引用。
    • 4)代码块。
    • 5)内部类。
  • (3)特点：
    • 1)在代码层面中，必须先有类，才能创建出对象。
    • 2)类名的首字母建议大写，满足驼峰模式。例如 StudentNameCode。
    • 3)一个Java代码文件中可以定义多个类。但是按照规范还是建议一个Java文件定义一个类。但是，一个Java代码文件中，只能有一个类是用public修饰的，而且public修饰的类名必须成为当前Java代码的文件名称。

3.对象

  • (1)对象是抽象概念的具体化实例。对象是通过引用来操作的，从栈到堆。
  • (2)对象的创建和使用，new来创造。

public class T006Class {
/*

public class 类的名称{
    // 成员变量-属性-名词
    // 成员方法-行为-动词

2.【创建&使用】对象
类名 对象名 =  new 类名();
给属性赋值：对象.属性名=值
使用成员属性： 对象.属性名
使用成员方法： 对象.方法名();

    public String name;
    public int age;

    public void eat() {
        System.out.println(name + "吃饭");
    }

    public void smile() {
        System.out.println(name + "微笑");
    }

    public static void main(String[] args) {

        System.out.println(g.name);
        System.out.println(g.age);
        // 使用成员方法： 对象.方法名(参数);
        g.eat();
    }
}

4.构造器/构造方法

  • (1)作用：给成员变量进行初始化。提供了一种方便的方式来设置对象的属性值，并且起到提醒作用，保障对象正确运行，尽量避免当属性值过多时在后续调用方法时报错。创建对象之后虚拟机就会默认调用构造方法，无法手动调用构造方法。且每一次创建对象都会调用构造方法。
    • 注. https://www.bilibili.com/video/BV1n5NBe1Enn
    • 注：属性也有初始化过程，因此方法里的对象也有初始化过程。
  • (2)规则：
    • 1)构造方法的方法名需要和类名完全一致。
    • 2)构造方法没有返回值类型，且不可以用void关键字。
    • 3)构造器尽量写明，在框架中如果没有构造器则会报错。
    • 4)构造器初始化对象的格式：类名 对象名称 = new 构造器;。new的其实是构造器。

5.JavaBean

  • (1)Javabean类和测试类：不写main()方法，用来描述一类事物的类，专业的叫法就为avabean类；编写main方法的类，叫做测试类，我们可以在测试类中创建javabean类的对象并进行赋值调用。（我们在这个阶段，一个Java程序只允许有1个入口，这个入口也就是main()方法）
  • (2)一个标准的Javabean类：
    • 成员变量使用private修饰。
    • 提供至少两个构造方法，即无参构造方法和带全部参数的构造方法。
    • 提供每一个成员变量对应的set()/get()方法。
    • 其它根据设计需求而必要的行为。
