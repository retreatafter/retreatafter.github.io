基础面板：游戏物体属性

1.游戏物体

  • (1)Unity内置提供了一些基础物体，可在层级面板Hierarchy空白处创建添加。
  • (2)物体创建后可以在Transform组件处先重置位置，再进行调整。

2.中心

  • (1)中心分为模型的中心和视觉的中心，pivot即模型创建时的中心，也是原点，一般不会改变；center是模型（组合）含碰撞体积在内视觉上的中心。常用center。

3.坐标

  • (1)每个游戏物体都有2个坐标，世界坐标和（相对）本地坐标。一般而言，物体的坐标显示的是世界坐标Global；位于层级下的物体显示的是局部（本地）坐标Local，相对于根层级物体。在旋转物体时也区分为全局Global和局部Local，一个相对于世界旋转，一个仅限于自身旋转。常用局部（本地）Local。
  • (2)旋转配合重力可以导致物体倒下，通过冻结游戏物体旋转的方式可以使游戏物体不再倒下。

4.透视关系

  • (1)视角可切换透视Perspective和正交Orthgraphic，简单来说，透视遵循近大远小，正交相当于固定相机内模型大小无论近远不做区别。3D游戏常选择透视Perspective，2D游戏常选择正交Orthgraphic。

5.材质

  • (1)Unity内置了一些材质，并且可以调整其平滑度Smoothness、金属属性Metallic等。

6.内置组件

  • (1)Transform用于控制对象的坐标（位置Position）、状态（旋转Rotation、缩放Scale）。Transform是一个“特殊”的组件，它是每个游戏物体必定有的，从调用位置上来说要修改Transform时可以直接使用transform对象去调用对应方法。而其它的非必要组件，要获取时都必须通过别的方法先进行连接，例如GetComponent<>()方法
  • (2)Cube代表网格形状，和网格渲染组件Mesh Render一并使用。网格，即保存了游戏物体顶点信息、顶点位置、三角面的朝向。之所以是三角形是因为最小的面就是三角形，模型本质是一个个最小的面组成的。
  • (3)BoxColider为碰撞“盒”组件，和MeshColider网格碰撞体组件一起使用。Convex凸面镜选项能够简化物理碰撞模型，一般会勾选。Unity中发生碰撞检测的条件：双方必须都有碰撞器，且一方有刚体组件。拥有刚体组件的最好是运动的一方，因为Unity为了性能的优化，刚体长时间不发生碰撞检测则会休眠。
  • (4)RigidBody刚体组件，通常和BoxColider一同使用，RigidBody使游戏物体能够获得重力，模拟施加力的效果，接受外界的受力和扭力功能的组件，可以为对象添加重力摩擦力等。Colider是静态碰撞器，如果想要实现操控物体撞倒另一个物体的物理效果，二者都需要开启刚体RigidBody组件，并按需调整质量Mess等设置。质量Mess涉及到碰撞后的碰撞效果，质量越大碰撞后效果越不明显。
  • (5)一个游戏物体GameObject的材质/外观由渲染组件ComponentRender决定，而渲染组件ComponentRender又由材料Material组成，材料Material又可更细分为贴图Textures、颜色、Shader。

7.模型关联

  • (1)图中2个Cube就是Plane的子级，这样可以对整个树状结构进行同步的操作。但更多时候是通过创建一个空对象来管理下属的对象。

8.动画状态机

  • (1)游戏物体通过动画组件设置参数的变化来实现动画的播放。

9.预制件Prefab

  • 预制体可以解决当一个模型多次复用且后期需要修改和同步修改时的问题，我们只需要修改预制件Prefab即可。
  • 已经做好的模型想要生成预制件，直接将该物体拖入Assets文件下即可，建议预制体建立专门的文件夹Prefabs。预制体在层级面板将会显示为蓝色。覆盖Override下RevertAll表示取消自身所有更改的特性，与原Prefab保持一致，ApplyAll表示将自身所有特性应用到Prefab上。

10.模型格式

  • (1)实际开发中，开发基本不会接触建模，更多是导入素材，常见的模型格式有：[.fbx]、静态模型[.obj]、maya专用格式[.ma]、Blender专用格式[.blend]，[.fbx]是通用格式，最为常用。
