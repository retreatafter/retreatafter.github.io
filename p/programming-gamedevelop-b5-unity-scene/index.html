1.概述

  • (1)通常，闯关类型的关卡游戏，会把一个关卡设置为一个场景。

2.天空盒

  • (1)Unity中天空盒SkyBox的概念本质是模拟现实场景，同样的还有坐标网格。
  • (2)天空盒也可以在Windows下Rendering渲染中进行材质修改。

3.光源

  • (1)Unity提供了四种光源。
    • 1)平行光Directional Light，对全部场景物体生效，无范围限制，即Position不影响对场景内所有物体的光源效果，而Rotation可以模拟一天中的光线，使阴影从长到短。
    • 2)点光源Point Light，类似模拟灯泡，从一个点四面八方发散光。有范围限制。
    • 3)聚光灯Spot Light，类似模拟手电筒，光的发散范围是一个锥形。
    • 4)区域光Area Light，渲染烘焙效果。

4.相机

  • (1)可以将游戏视为拍电影，相机就是提供给观众的视角。可以有多个相机。
  • (2)小技巧：Align With View将当前视野调整为相机视野，Align View to Selected调整到当前相机视野。
  • (3)按需设置相机的环境背景色Environment，这里的背景色仅涉及到我们调试时的观感，不影响实际游戏。
  • (4)按需设置相机的投影Projection方式，透视Perspective和正交Orthographic的区别在于，简单来说，正交相当于固定相机内模型大小无论近远不做区别，透视遵循近大远小。

5.音乐

  • (1)Unity自带了可以监听声音源的组件Audio Listener，且相机MainCamera下自带。而声音源可以给需要发音的物体添加组件AudioSource，在AudioResource下进行调整。其中PlayOnAwake表示游戏开始后即播放音效，Loop表示音效循环。
  • (2)开启SpatialBlend效果后，下方的曲线图可以调整出近大远小/无的声音3D变化效果。竖线表明当前位置对应的音效大小位置。

public class PlaySoundAtRandomIntervals : MonoBehaviour
{
    public float minSeconds = 5f; // Minimum interval to wait before playing sound.
    public float maxSeconds = 15f; // Maximum interval to wait before playing sound.

    private AudioSource audioSource;

    private void Start()
    {
        audioSource = GetComponent<AudioSource>();
        StartCoroutine(PlaySound());
    }

    private IEnumerator PlaySound()
    {
        while (true)
        {
            float waitTime = Random.Range(minSeconds, maxSeconds);
            yield return new WaitForSeconds(waitTime);
            audioSource.Play();
        }
    }
}
