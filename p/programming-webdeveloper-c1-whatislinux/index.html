1.概述

  • (1)Linux是一种开源操作系统，与Windows或madOS等操作系统不同，Linux允许用户自由地查看、修改和分发其源代码。Linux系统多用于服务器上。
    • Linux和windows一样是操作系统，操作系统本身也是一种软件。
  • (2)在实际软件开发中，通常服务器使用 LAMP（Linux + Apache + MySQL + PHP）或 LNMP（Linux + Nginx+ MySQL + PHP）组合。

2.Linux虚拟机

(1)概念

  • 1)想要安装Linux虚拟机，通常的安装方法：
    • 购买云服务器，在云服务器上搭建。
    • 本地搭建，本地双系统（占用内存量会增大），或使用虚拟机例如VMware，在虚拟机上运行Linux系统。

  • 2)安装Linux发行版本中的Centos7系统：
    • TIPS：Linux系统拥有众多的发行版，其中Centos是最常用于服务器的发行版之一，除此之外，还有Ubuntu、Debian等等。Linux发行版是指在相同的Linux内核的基础上，增加不同的系统工具和应用程序等，从而构成的一个完整的操作系统。

(3)常用设置

  • 1)系统快照：系统快照，即将操作系统的当前状态保存下来，若将来系统出现不可修复的故障，便可使用快照恢复操作系统。可对虚拟机系统右键开启快照选项，对快照进行管理。
  • 2)克隆虚拟机：当需要多个虚拟机时可以进行克隆，得到一台和原有虚拟机配置完全相同的虚拟机，从而省去重复安装系统的繁琐工作。关闭当前虚拟机后右键管理选择克隆，按照克隆向导引导即可。

(4)远程访问

  • 1)实际的开发环境中，服务器通常位于机房或云端，因此我们不能像操作个人电脑一样操作服务器，而是需要通过远程登录的方式来操作。这时就需要用到SSH服务，SSH（Secure Shell）使用一种网络协议，用于在计算机之间建立加密的连接，从而允许用户以安全的方式在远程的计算机中执行命令。
  • 2)Linux系统中都会预装SSH服务，因此我们只需在自己的个人电脑安装SSH客户端，然后配置连接即可。市面上存在许多SSH客户端，例如MobaXterm、Xshell、SecureCRT、FinalShell等等。

(5)网络配置

  • (A)桥接模式：在该模式下，虚拟机和主机位于同一网络中，因此在主机接入网络的前提下，虚拟机和物理机是可以互通的。
  • (B)NAT模式：该模式下，虚拟出了一个虚拟路由器。虚拟路由器通过主机的物理网卡连接到主机所在的网络，虚拟机则全部连接到虚拟路由器上，组成了一个子网。虚拟网卡连接到这个虚拟路由器中，实现主机和虚拟机的互通。最推荐的模式。
  • (C)仅主机模式：与NAT模式的区别在于虚拟路由器并未连接到主机所在的网络中，因此主机和虚拟机之间可以互通，但是虚拟机不能访问互联网。
