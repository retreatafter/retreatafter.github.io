2.技巧

  • (1)思路：
    • 1)关注给出的代码中有哪些类，类中有哪些成员变量（属性）、有哪些方法。
      • 只要被定义出来的属性或者方法一定会被调用。
    • 2)将被调用过的成员属性和方法排除。
    • 3)剩下没有被调用过的成员属性和方法就是需要填写的。
  • (2)类：
    • 1)类一定有初始化的地方，关键词new。
    • 2)抽象类abstract必须有实现，抽象类里面的抽象方法必须在子类里面实现。抽象类不必全是抽象方法，但一定有抽象方法。
    • 3)子类继承超类（基类），那么子类就具有超类（基类）的方法。
    • 4)对象属于哪个类是什么类型的对象很重要，决定了能调用哪些方法。
  • (3)属性：
    • 1)属性一般情况下是private，并且既需要被设置值set，也需要被获取值get
      • 属性设置值的位置：set()、构造函数
  • (4)方法：
    • 1)注意return返回值、参数。return也可以代表为结束当前方法。
    • 2)方法里面的参数一定在方法体里面被调用
    • 3)子类继承超类（基类），那么子类就具有超类（基类）的方法
    • 4)静态方法可以通过类名.方法名调用
  • (5)接口：
    • 有接口interface 就应当有实现 implements。
    • 定义接口后写方法，此处不实现，没有方法体。
