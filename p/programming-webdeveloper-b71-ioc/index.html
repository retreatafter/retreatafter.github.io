1.概述

  • (1)IOC是一种理论，DI是理论的技术实现，而底层是依靠反射机制。
    • 控制反转：使用Spring容器管理bean。控制反转IoC（Inversion of Control）是一种思想，将创建对象的方式由主动创建对象new转变为由外部提供对象（本质为set()注入），即对象的创建、赋值、管理转移给用户（第三方）处理，之后对象的工作不用再由我们主动控制，把主动权交由用户，因而称之“反转”。Spring容器用来充当IoC思想中的外部，由容器负责对象的创建、初始化等一系列工作，被创建或被管理的对象在容器中统称为Bean。
    • 依赖注入：在Spring容器内将有依赖关系的bean进行关系绑定。从MVC架构可以看到，层与层之间是存在依赖关系的，因此对象和对象之间也存在依赖关系，因此Spring接管了对象的这一系列工作，就避不开对象和对象之间存在的依赖关系（什么时候new？new哪些？），而在容器中建立bean与bean之间的依赖关系的整个过程，称为依赖注入DI（Dependency Injection）。

2.容器使用原理

  • (1)导入坐标GAV，在pom.xml文件中进行配置。
  • (2)存：根据MVC架构，我们需要Spring容器来管理Service业务层和Dao/Mapper数据层的对象，而我们要通过xml文件配置/使用注解的形式来通知容器我们需要管理哪些对象。涉及到标签bean，表示这是一个bean；属性id，我们设置的唯一标识；属性class，对应具体的类。
  • (3)取：Spring容器提供了对应的接口ApplicationContext，我们通过对应的接口方法来获取bean。获取容器固定写法：ApplicationContext ctx = new ClassPathXmlApplicationContext("配置文档.xml");。获取bean的方法：getBean(id);

3.实现DI原理

  • (1)在使用容器的基础上，根据set方法来让Dao/Mapper数据层的对象进入到Service业务层，从而实现原先代码解耦。
  • (2)在创建的Spring配置文件中描述Dao/Mapper数据层和Service业务层之间的关系，让Spring对两者的bean进行关系绑定。涉及到标签property，表示配置当前bean的属性；属性name，表示配置哪一个具体的属性（和哪个类关联，定义的对象名）；属性ref，表示参照哪一个bean（关联类的对应bean的id）；

(3)控制反转实现

1）目的

  • (A)目标：使用bean实现在测试类中Spring接管业务层对象的生成。

2）存bean

  • (A)配置bean：
    • a)新建Spring配置文件applicationContext.xml（没有硬性规定名称），注意，这里能新建其实是因为我们前一步在pom.xml中导入了Spring依赖。
    • b)spring-beans.xsd是约束文件的名称，扩展名是xsd，和mybatis中的dtd文件性质一样，用于限制，检查在当前文件中出现的标签，属性必须符合spring的要求。
    • c)<beans>为根标签，spring中将java对象称为bean。
    • d)声明bean，告诉Spring该创建某个类的对象，1个bean标签声明1个对象。标签格式：<bean id="" class=""/>，其中class对应具体的类的全限定名称（注意是实现类，Spring为反射机制创建对象，必须使用实现类），id为唯一值，相当于我们以前创建对象时给对象取的名字，见名知意即可。

3）取bean

  • (A)新建测试类，运行可看到结果，此时我们没有new业务层BookService类的对象，但程序是可以正常运行的。
    • ApplicationContext表示Spring容器，ApplicationContext是一个接口，其一个实现类为ClassPathXmlApplicationContext，传入参数为告知Spring要给哪些内容创建对象，即配置文件的类路径。其实在这一步读取配置文件后就会创建写在配置文件中所有bean的对象，后续属于取需要的bean的过程。Spring会将创建好的对象放在专门的map中。
    • 获取需要的bean的方法为getBean("配置文件中bean的id值")，并且需要强制类型转换。

    }
}

<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"

    <bean id="bookService" class="src.main.com.retreatafter.service.impl.BookServiceImpl">
        <property name="bookDao" ref="bookDao"/>
    </bean>
</beans>

5.容器创建方式

  • (1)三种方式：
    • 方式一：路径加载配置文件，例如：ApplicationContext ctx = new ClassPathXmlApplicationContext("applicationContext.xml");。
    • 方式二：文件路径加载配置文件，例如：ApplicationContext ctx = new FileSystemXmlApplicationContext("D:\\project\\applicationContext.xml");。
    • 方式三：读取web下的资源文件，例如：XmlWebApplicationContext ctx = new XmlWebApplicationContext();。
  • (2)加载多个配置文件，例如：ApplicationContext ctx = new ClassPathXmlApplicationContext("bean1.xml","bean2.xml"); 。

6.获取bean的方式

  • (1)三种方式：
    • 方式一：使用bean名称获取，并进行强制类型转换，例如：BookDao bookDao = (BookDao) ctx.getBean("bookDao");。
    • 方式二：使用bean名称获取并用字节码指定类型，例如：BookDao bookDao = ctx.getBean("bookDao",BookDao.class);。
    • 方式三：使用bean类型获取，但只能有一个bean。例如：BookDao bookDao = ctx.getBean(BookDao.class);。
