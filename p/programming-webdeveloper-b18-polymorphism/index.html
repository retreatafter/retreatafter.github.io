1.特点

  • (1)多态(Polymorphic)：同一个类型的对象，执行同一个行为，在不同的状态下会表现出不同的行为特征。一个对象的实际类型是确定的，可以指向的引用类型是不确定的，即：基类的引用允许指向子类。多态最直观的表现为基类的对象创建可以由子类创建，或者说，子类的形态（定义）既可以由子类定义，也可以由其基类定义，格式为基类类型 对象名 =子类对象;。例如有子类Student和基类Person，Student s = new Student();和Person p = new Student();。
  • (2)调用：
    • 1)变量调用为编译看左边，运行也看左边。编译看左边：javac编译代码的时候，会看左边的基类中有没有这个变量，如果有，编译成功，如果没有编译失败。运行也看左边：java运行代码的时候，实际获取的就是左边基类中成员变量的值。从原理上说，是因为多态仅展示在行为（方法）上，而不体现在变量上。
    • 2)方法调用为编译看左边，运行看右边。编译看左边：javac编译代码的时候，会看左边的基类中有没有这个方法，如果有，编译成功，如果没有编译失败。运行看右边：java运行代码的时候，实际上运行的是子类中的方法。
    • 3)多态(Polymorphic)是方法的多态，属性没有多态。
  • (3)示例：（规范写法：下述基类、子类、主方法各为一个文件)

       ((Mastodon) m).paint();// 强制类型转换，高（类）转低（类），且这里的前提是存在继承关系，因此可以实现转换

}

2.final关键字

  • (1)注意事项：
    • final修饰的变量是基本类型，那么变量存储的数据值不能发生改变。
    • final修饰的变量是引用类型，那么变量存储的地址值不能发生改变，对象内部的可以改变。
    • final修饰变量时有且仅能被赋值一次。

public class Demo {
    public static void main(String[] args) {
        // 1.买一部电脑
        Computer c = new Computer();
        // 2.买一个鼠标
        USB bear = new Mouse("小熊鼠标");
        c.install(bear);
        // 3.买一个键盘
        KeyBoard cherry = new KeyBoard("Cherry键盘");
        c.install(cherry);
    }
}

class Computer{
    // 提供一个安装USB设备的入口
    public void install(USB usb){ //基类USB作为形参
        usb.connect();

        // usb可能是鼠标，也可能键盘，instanceof进行判断，进行对应的类型转换后才能执行子类中独有的功能
        if(usb instanceof Mouse){
            Mouse m = (Mouse) usb;
            m.dbclick();
        }else if(usb instanceof KeyBoard){
            KeyBoard k = (KeyBoard) usb;
            k.keyDown();
        }

        usb.unconnect();
    }
}

// 定义2个USB设备：鼠标，键盘
class Mouse implements USB{
    private String name;

    public Mouse(String name) {
        this.name = name;
    }

    // 双击
    public void dbclick(){
        System.out.println(name+"进行了双击");
    }

    @Override
    public void connect() {
        System.out.println(name+"成功接入了设备");
    }

    @Override
    public void unconnect() {
        System.out.println(name+"成功拔出了设备");
    }
}

class KeyBoard implements USB{
    private String name;

    public KeyBoard(String name) {
        this.name = name;
    }

    // 按键
    public void keyDown(){
        System.out.println(name+"写下了一句话");
    }

    @Override
    public void connect() {
        System.out.println(name+"成功接入了设备");
    }

    @Override
    public void unconnect() {
        System.out.println(name+"成功拔出了设备");
    }
}

// 定义USB的规范，必须要完成接入和拔出的功能
interface USB{
    void connect();    // 接入
    void unconnect();  // 拔出
}
