3.基础语法

(1)书写规范

  • 1)JS中依旧严格区分大小写。
  • 2)结尾的分号可以不写。
  • 3)注释形式与Java中一致。

    • IDEA需要设置支持ES6语法，'use strict';必须写在JavaScript的第一行！

(2)输出语句

  • 1)类型：
    • window.alert()，浏览器弹出警告框。
    • document.write()，写入HTML，在浏览器输出内容。
    • console.log()，写入浏览器控制台Console。

(3)变量常量

  • 1)变量
    • 语法：变量类型 变量名 = 变量值;。JS中不区分变量类型，通用var关键字(variable)。ES6引入了let关键字。
    • 特点：
      • JavaScript是一门弱类型语言，变量可以存放不同类型的值。
      • var关键字声明的变量的作用于是全局的。let关键字声明的变量仅在所在的代码块内有效，且不允许重复声明，即局部变量。
1
2
3

var score = 77;
var z = 20;
z = "seven"; //JS是弱类型语言，允许赋值不同类型
  • 2)常量
    • 在ES6引入了常量关键字const。一旦声明，常量的值就不能改变。
1
2
3
4

const PI = '3.14';
console.log(PI);
PI = '123';	// 报错，不能重复声明 Uncaught SyntaxError: Identifier 'PI' has already been declared
console.log(PI);

(4)数据类型

  • 1)特点：
    • (A)JS中的数据类型分为原始类型和引用类型。在JS中需要考虑的数据类型包括了数值，文本，图形，音频，视频……
    • (B)由于JS是弱类型语言，因此想要知道变量属于什么类型，可以使用typeof()函数。
  • 2)数字：
    • (A)JS不区分小数和整数。
    • (B)浮点数存在精度损失的问题，尽量避免使用浮点数进行运算。例如console.log((1/3) === (1-2/3));将会判断为false。
1
2
3
4
5
6

123 // 整数123
123.1 // 浮点数123.1
1.123e3 // 科学计数法
-99 // 负数
NaN	// not a number
Infinity // 表示无限大
  • 3)字符串String：
    • (A)格式：字符串使用单引号或者双引号包裹，例如'a'或"a"都是允许的写法。
    • (B)特点：
      • 注意转义字符 \，常见的转义字符例如\n表示换行，\t表示制表符Tab。
      • 和Java不同的是，JS要在字符串里塞变量可以直接用${变量}。例如var msg='你好，${name}';
    • (C)常用API：
      • substring()方法，字符串截取。
      • toUpperCase toLowerCase()方法，大小写转换。
  • 4)布尔值：
    • (A)与Java相同：true false
  • 5)null和undefined：null表示空，undefined表示未定义，声明的变量未初始化时，变量的默认值为undefined。

(5)运算符

  • 1)算术运算符：+ , - , * , / , % , ++ , --。
  • 2)赋值运算符：= , += , -= , *= , /= , %=。
  • 3)比较运算符：&gt; , < , >= , <= , != , == , ===，注意，=表示赋值，==表示等于，会进行类型转换，当类型不一样值一样，也会判断为true，如：1与"1"也会判定为true，===表示绝对等于，不会进行类型转换，类型一样，值一样，结果才为true。
    • 尽量不要使用 ==比较。
    • NaN === NaN，会判定为false，因为这不是个值，因此与所有的数值都不相等，包括自己。
    • 只能通过 isNaN(NaN)来判断出这个数，这时才会显示true。
  • 4)逻辑运算符： && , \|\| , !，&&当两个都为真，结果为真；||当一个为真，结果为真；!当真即假，假即真。
  • 5)三元运算符： 条件表达式 ? true_value: false_value。

4.函数和方法

(1)定义函数

  • 1)定义函数（方法）：JS通过function关键字定义函数。
    • 因为JavaScript是弱数据类型的语言，形式参数不需要声明类型，也无需声明返回值。
1
2
3

function 函数名(参数1,参数2..){
    //要执行的代码
}

(2)函数作用域

  • 1)原则：在javascript中，var定义变量实际是有作用域的。
    • 假设在函数体中声明，则在函数体外不可以使用。

	var x = 1;
    x = x + 1;
}
x = x + 2; // Uncaught ReferenceError: x is not defined
