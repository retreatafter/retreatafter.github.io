1.概述

  • (1)单元测试是指使用测试代码给自己的类中的方法进行预期正确性的验证。 单元测试一般要使用框架进行，这里使用Junit。
    • 单元：在Java中，一个类就是一个单元。
  • (2)使用单元测试则不用再受main方法的限制（原本所有代码都需要执行），对于想要测试的部分代码可以更自由地进行测试。

2.Junit

  • (1)大多数版本的IDEA中已整合Junit框架。
    • （需要Maven知识）web项目可以选择.iml文件导入依赖：

<dependency>
    <groupId>junit</groupId>
    <artifactId>junit</artifactId>
    <version>4.12</version>

  • (2)使用步骤：
    • 1)先模拟业务代码。
    • 2)写测试类：
      • 测试类的命名规范：以Test开头，以业务类类名结尾，使用驼峰命名法。假设业务名称是：UserService，那么测试这个业务类的测试类命名：TestUserService/UserServiceTest。
    • 3)在测试类中写测试方法：
      • 测试方法的命名规则：以test开头，以业务方法名结尾。例如被测试业务方法名为：login，那么测试方法名就应该叫：testLogin。
    • 4)测试方法注意事项：
      • 必须是public修饰的，没有返回值，没有参数。
      • 必须使用注解@Test修饰。
  • (3)运行测试方法
    • 选中方法名 –> 右键 –> Run ‘测试方法名’ 运行选中的测试方法。
    • 选中测试类类名 –> 右键 –> Run ‘测试类类名’ 运行测试类中所有测试方法。
    • 选中模块名 –> 右键 –> Run ‘All Tests’ 运行模块中的所有测试类的所有测试方法。

    }

//测试类
public class UserServiceTest {
    //测试第1个方法
    @Test
    public void testLogin(){
        UserService userService = new UserService();
        String rs = userService.login("admin","123456");
        // 断言预期结果的正确性
        /**
         * 参数一：测试失败的提示信息
         * 参数二：期望值
         * 参数三：实际值
         */
        // public static void assertEquals(String message, Object expected, Object actual)
        Assert.assertEquals("登录业务功能方法有错误，请检查！","success",rs);
    }

    //测试第2个方法
    @Test
    public void testChu(){
        UserService userService = new UserService();
        userService.chu(10 , 0);
    }
}

3.常用注解

  • @Test：测试方法。
  • @BeforeEach（Junit4之前为@Before）：用来修饰实例方法，该方法会在每一个测试方法执行之前执行一次。
  • @AfterEach（Junit4之前为@After）：用来修饰实例方法，该方法会在每一个测试方法执行之后执行一次。
  • @BeforeAll（Junit4之前为@BeforeClass）：用来静态修饰方法，该方法会在所有测试方法之前只执行一次。
  • @AfterAll（Junit4之前为@AfterClass）：用来静态修饰方法，该方法会在所有测试方法之后只执行一次。

//测试类
public class UserServiceTest {
    // @Before：用来修饰实例方法，该方法会在每一个测试方法执行之前执行一次
    @Before
    public void before(){
        System.out.println("===before===");
    }
    // @After：用来修饰实例方法，该方法会在每一个测试方法执行之后执行一次
    @After
    public void after(){
        System.out.println("===after===");
    }

    // @BeforeClass：用来静态修饰方法，该方法会在所有测试方法之前只执行一次
    @BeforeClass
    public static void beforeClass(){
        System.out.println("===beforeClass===");
    }

    // @AfterClass：用来静态修饰方法，该方法会在所有测试方法之后只执行一次
    @AfterClass
    public static void afterClass(){
        System.out.println("===afterClass===");
    }

    @Test
    public void testLogin(){
        UserService userService = new UserService();
        String rs = userService.login("admin","123456");
        // 断言预期结果的正确性
        /**
         * 参数一：测试失败的提示信息
         * 参数二：期望值
         * 参数三：实际值
         */
        // public static void assertEquals(String message, Object expected, Object actual)
        Assert.assertEquals("登录业务功能方法有错误，请检查！","success",rs);
    }

    @Test
    public void testChu(){
        UserService userService = new UserService();
        userService.chu(10 , 0);
    }
}
