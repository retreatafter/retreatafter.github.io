1.概述

  • (1)注入：给bean的属性赋值。
  • (2)依赖注入方式
    • 1)怎么传：Java中，要向一个类传递数据，只有一个方式，即通过方法传递数据，而方法又分为普通方法和构造方法。
    • 2)传什么：引用数据类型和基本数据类型。

4.自动装配

  • (1)在上述的引用类型的注入过程中，我们需要对bean中每一次引用进行操作，spring框架根据某些规则自动给引用类型赋值的过程称之为自动装配，通过属性autowire实现。
    • 自动装配用于引用类型依赖注入，不能对简单类型进行操作。
    • 使用按类型装配时（byType）必须保障容器中相同类型的bean唯一，推荐使用。
    • 使用按名称装配时（byName）必须保障容器中具有指定名称的bean，因变量名和配置耦合，不推荐使用。
    • 自动装配优先级低于setter注入和构造器注入，同时出现时自动装配失效。
  • (2)按类型装配时（byType）：java类中引用类型的数据类型和spring容器中（配置文件）<bean>的class属性是同源关系，此时spring能够赋值给引用类型。同源关系是指：
    • java类中引用类型的数据类型和bean的class的值一致。
    • java类中引用类型的数据类型和bean的class的值为继承关系。
    • java类中引用类型的数据类型和bean的class的值是接口和实现类的关系。

//Dao层实现
public class BookDaoImpl implements BookDao {

		//变量定义
		private int[] array;

    private List<String> list;

    private Set<String> set;

    private Map<String,String> map;

    private Properties properties;

    //构造方法
    public void setArray(int[] array) {
        this.array = array;
    }

    public void setList(List<String> list) {
        this.list = list;
    }

    public void setSet(Set<String> set) {
        this.set = set;
    }

    public void setMap(Map<String, String> map) {
        this.map = map;
    }

    public void setProperties(Properties properties) {
        this.properties = properties;
    }

    //方法
    public void save() {
        System.out.println("book dao save ...");

        System.out.println("遍历数组:" + Arrays.toString(array));

        System.out.println("遍历List" + list);

        System.out.println("遍历Set" + set);

        System.out.println("遍历Map" + map);

        System.out.println("遍历Properties" + properties);
    }
}
