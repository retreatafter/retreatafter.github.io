1.概述

  • (1)Web服务器是一个应用程序（软件），对HTTP协议的操作进行封装，使得程序员不必直接对协议进行操作，简单来说，我们将Web项目放在Web服务器上，就可以在浏览器上通过特定url进行访问。
  • (2)Tomcat服务器是一个免费的开源的轻量级Web应用服务器，遵循最新的Servlet和JSP规范，Tomcat也被称为Web容器、Servlet容器，Servlet程序需要依赖于Tomcat才能运行。有三大功能：
    • web服务器。
    • jsp容器。
    • Servlet容器。

2.Tomcat安装

  • (1)官网地址： http://tomcat.apache.org/
  • (2)启动停止：Tomcat下载后是压缩包，解压后即可使用，启动Tomcat进入到bin目录下的startup.bat文件，关闭Tomcat可以直接关闭运行窗口（强制关闭）/使用bin目录下的shutdown.bat文件（正常关闭）/快捷键Ctrl+C（正常关闭）。
  • (3)配置：
    • 1)Tomcat的正常运行前提是已经做好了Java环境配置。
    • 2)Tomcat的默认占用端口号为：8080。conf文件夹下核心配置文件可以修改相关设置：
      • 注意，HTTP协议默认端口号为80，如果将Tomcat端口号改为80，将来访问Tomcat时则不用输入端口号。
    • 3)Tomcat控制台会出现中文乱码的问题，修改conf/ logging.properties文件，在java.util.logging.ConsoleHandler.formatter = org.apache.juli.OneLineFormatter下增加此行java.util.logging.ConsoleHandler.encoding = GBK。
  • (4)部署：将项目放置到webapps目录下即部署完成。

3.集成开发环境IDEA中配置Tomcat

  • 应用程序上下文（Aapplication context）可写可不写，如果不写：默认访问路径为localhost:8080，如果写了路径，则为localhost:8080/对应路径。这个过程叫做虚拟路径映射。
  • 可能遇到的问题：(1)Tomcat的版本与JDK版本的支持有关，Tomcat10之后的版本需要JDK9及以上，如使用的是JDK1.8版本，建议使用Tomcat9。(2)Maven项目如没有web文件夹的，会在配置Tomcat部署时发现无法添加工件Aartifact，需要在设置project structure中给Maven项目添加web application:Eexploded。
  • 在以后，基于Springboot开发Web应用程序，其中已内置了Tomcat服务器，而无需我们再进行上述安装过程。
