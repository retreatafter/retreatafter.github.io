1.参数传递

  • (1)这里的参数传递是指当我们用代码写入数据时，如何传递给mapper文件。
  • (2)类型对应parameterType：dao接口中方法参数的数据类型。值为java的数据类型全限定名称或者是mybatis定义的别名。事实上，mybatis通过反射机制能够发现接口参数的数据类型，因此parameterType属性一般无需使用。

<!--示例-->
    <select id="selectStudents" parameterType="int" resultType="com.retreatafter.domain.Student" >
        select id,name,email,age from student order by id
    </select>
  • (3)一个简单参数：在mybatis中简单参数是指基本数据类型及String，方式为在mapper文件中使用占位符#{任意字符}。
    • 以下示例文件表示，当我们传入参数id时，在mapper文件就会对应到#{id}。这里由于只有一个参数，#{id}可以是任意字符，例如#{StudentId}，但规范来说对应参数名。

//dao接口示例
public interface StudentDao{
    public Student selectStudentsById(Integer id);
}

        select id,name,email,age from student where id=#{id}

  • (4)多个参数，散装参数：使用注解@Param("SQL中的参数占位符名称")命名参数。

  • (5)多个参数，对象参数：如果这些参数同属于一个对象，那么将这些参数进行封装成一个实体类，使用java对象的属性值作为参数实际值。SQL中的参数名和实体类属性名对应，即可设置成功。
    • mapper文件占位符完整语法：#{属性名,javaType=java数据类型名称，jdbcType=数据库数据类型}。mybatis能通过反射获取javaType和jdbcType的值，因此更常用简化方式：#{属性名}。

2.参数格式比较

  • 1)在Mybatis中，书写Mapper文件中的SQL语句部分时，参数的书写格式：
    • #{}：执行SQL时，会将#{}替换为占位符?，生成预编译SQL，将来自动设置参数值。通常参数传递都使用#{}。
    • ${}：不使用占位符，直接将参数拼接在SQL语句中，会存在SQL注入问题。如果要对表名、列名进行动态设置，只能使用${}进行sql拼接。
  • 2)优缺点比较：
    • #{}使用PrepareStatement对象执行sql，效率高；${}使用Statement对象执行sql，效率低。
    • #{}能避免sql注入的问题，${}无法避免。

<!-- resultType -->
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
        
<mapper namespace="com.retreatafter.pojo.BrandMapper">

    <!--select查询语句，id是以下这条SQL语句的唯一标识，不要重复；resultType为类路径-->
    <select id="selectAll" resultType="com.retreatafter.pojo.Brand">
       select * from tb_user;
   </select>

</mapper>

(2)resultMap

  • 1)当数据库表的字段名称和实体类的属性名称不一样时，则不能自动封装数据（无法对应上），现通用解决方案为使用<resultMap></resultMap>标签。
  • 2)例如有Brand类下属性brandName和companyName，和数据库对应列brand_name、company_name的名称无法完全对应，在对应的BrandMapper.xml进行修改：
    • resultMap的属性：id唯一标识，自定义名称；type为全限定名称。
    • id标签实现主键的映射，result标签实现一般字段的映射。
    • column表示sql中的列名。
    • property表示java代码中类型的属性名。

<!-- resultMap -->
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
        
<mapper namespace="com.retreatafter.pojo.BrandMapper">

		<resultMap id="brandResultMap" type="Brand">
		    <id column="brand_name" property="brandName" />
		    <result column="company_name" property="companyName" />
		</resultMap>

    <!--select查询语句，id是以下这条SQL语句的唯一标识，不要重复；resultMap放入对应id值-->
    <select id="selectAll" resultMap="brandResultMap">
       select * from tb_user;
   </select>

</mapper>
