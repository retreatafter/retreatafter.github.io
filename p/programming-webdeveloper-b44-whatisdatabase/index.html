1.概述

  • (1)数据库DB（Database），作为安装在操作系统上的数据仓库软件，可以储存超500万的庞大数据。数据库本质也是文件，是(.sql)格式文件。
  • (2)SQL是操作关系型数据库的编程语言，MySQL是可视化软件，通过SQL语句在MySQL上访问数据库。而基于可视化界面的需求，又出现了可视化管理MySQL数据库的各种软件工具。

2.分类

  • (1)关系型数据库SQL(Structured Query Language)
    • 常见软件：MySQL、Oracle、Sql server 、DB2、SQLlite……
    • 特点：通过表和表之间，行和列之间的关系进行数据的存储。（和excel很类似）
  • (2)非关系型数据库NoSQL（not only SQL）
    • 常见软件：Redis、MongDB……
    • 特点：对象存储，通过对象的自身属性来决定，需要动态更新。

3.SQL基本语句

  • (1)SQL下的四大语言
    • 数据定义语言(DDL definition)：定义和管理数据对象，如数据库、数据表等。涉及到的命令：CRATE、DROP、ALTER。
    • 数据操作语言(DML manipulation)：用于操作数据库对象中所包含的数据。涉及到的命令：INSERT、UPDATE、DELETE。
    • 数据查询语言(DQL query)：用于查询数据库数据。涉及到的命令：SELECT。
    • 数据控制语言(DCL control)：用于管理数据的语言，包括权限及数据更改。涉及到的命令：GRANT、COMMIT、ROLLBACK。
  • (2)数据库的操作本质上是一种递进的过程：操作数据库→操作数据库中的表→操作数据库表中的字段数据。
  • (3)注释：单行注释-- 注释内容（注意存在空格），多行注释/**/。
  • (4)MySQL关键字并不区分大小写，建议用小写，视觉角度上来说更适宜。
  • (5)语法规范
    • 1)和Java使用大括号{}类似，字段属性在括号()内书写。
    • 2)每个语句结束用逗号,，除了最后一个语句可以不用逗号。
    • 3)表的名称和字段尽量用反引号``括起来。
    • 4)字符串使用单引号''或是双引号""包裹。
