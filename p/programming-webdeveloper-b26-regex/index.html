正则表达式

1.概述

  • (1)特点：
    • 正则表达式本质是一种规则。
    • 正则表达式是一个一个字符进行匹配。
  • (2)作用：
    • 校验字符串是否满足规则。
    • 在一段文本中查找满足要求的内容。应用场景：爬虫、校验。
  • (3)关于正则表达式可在Pattern类查看详情。

2.类型

  • (1)字符类：
    • “[]“表示一个字符在某个范围。例如，[abc]表示一个字符/字符串一定要在abc之内，且只能出现一个，即出现a或出现b或出现c。如果用ab去适配，会得到false。
    • “()“表示分组。例如，a(b|c)就表示bc为一组。
    • “^“表示取反、不在这个范围。例如，[^abc]表示除了a、b、c以外的任何字符。
    • “-“表示在某个范围内，包含头尾，一定要用”[]“包起来。例如，[a-d]表示a到d。
    • “[ []]“表示两个范围取或。例如，[a-d[m-p]]表示a到d，或m到p的字符，都是合法的。可以不用双括号，即a-dm-p也表示a到d，或m到p的字符。
    • “&&“取交集，”[ &&[]]“表示前后两个范围取交集。例如，[a-z && [def]]表示a到z，和def的交集，结果显然为def。注意，如果写的是”&"，那么这里不代表取交集，而是指&这个符号。
    • “[ &&[^ ]]"，表示两个范围（后非）取交集。例如，[a-z && [^m-p]]表示a到z，和除了m到p的交集，等同于a-lq-z。
    • “|“取并集。
  • (2)预定义字符类：
    • “．“表示任意字符。但不表示回车符号\n。
    • “\d"表示一个数字，即”[0-9]"。
    • “\D"表示一个非数字，即”[^0-9]"。
    • “\s"表示一个空白字符，即”[\t\n\x0B\f\r]"。
    • “\S"表示一个非空白字符，即”[^\s]"。
    • “\w"表示英文字符、或数字字符、或下划线字符，即”[a-zA-Z_0-9]"。
    • “\W"表示一个非单词字符，即”[^\w]"。 注意：在Java中，""有自己的含义，即转义字符的意思，所以在实际写代码时，比如”\s"应写成”\s”，其它类似。
    • 注：\转义字符，改变后面那个字符原本的含义。\\前面的\是一个转义字符，改变了后面\原本的含义，把它变成一个普普通通的\。
  • (3)数量词，表示多个字符：
    • ?：0次或1次
    • *：0次到多次
    • +：1次或多次
    • {n}：恰好n次
    • {n,}：至少n次
    • {n,m}：n到m次（包含n和m)
    • (?i)：忽略后面字符的大小写。例如a(?i)bc，aBC也可以匹配。
    • a((?i)b)c：仅忽略b的大小写。

3.分组

  • (1)"()"表示分组，每组在底层都有组号/序号，其规定为：
    • 从1开始，连续不间断。
    • 以左括号为基准，最左边的是第一组，其次为第二组，以此类推。例如(\\d+(\\w+))(\\D)，(\\d+(\\w+))为第一组，(\\w+)为第二组，(\\D)为第三组。
  • (2)捕获分组：重复使用，把第x组的内容再重复一次。：
    • 如果在正则内部，使用”\组号x”。例如(.).+\\1表示了三个字符，第一个字符是任意字符(.)第二个字符为任意字符且最少出现一次.+，第三个字符和第一组字符的规则一样，表示为\\1。
    • 如果在正则外部，使用”$组号x”。
  • (3)非捕获分组：分组之后不需要再用本组数据，仅仅把数据括起来，不占组号。
    • (? : 正则)，表示获取所有。
    • (? = 正则)，表示获取前面部分。
    • (? ! 正则)，表示获取不是指定内容的前面部分。

/**观察关注给出数据的规律，分为三部分
*@的左边，允许任意的字母数字下划线，至少出现一次 表示为`\\w+`
*必然有一个且只有一个@ 表示为`@`
*@的右边，有至少一个.，可以将.之前的划为一部分，.之后的划为一部分，.之前可以是任意的字母加数字但不能有下划线，共出现2-6次（这里是简单处理） 表示为`[\\w&&[^_]]{2,6}`，.和右侧直到下一个.之前可以看作一组一共出现1-2次，表示为`(\\.[a-zA-Z]{2,3}){1,2}`
*/
String regex = "\\w+@[\\w&&[^_]]{2,6}(\\.[a-zA-Z]{2,3}){1,2}";
System.out.println("dileieee99@pci.com.cn".matches(regex);
