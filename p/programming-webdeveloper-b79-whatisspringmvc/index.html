1.概述

  • (1)SpringMVC是一种基于Java实现MVC模型的轻量级Web开发框架，是Sping框架的一部分，能够使用Spring的IoC及AOP。SpringMVC技术与Servlet技术功能相同（即底层实现依旧是Servlet），均属于web层（视图层/表现层/表示层）开发技术，但SpringMVC技术更简洁，能用更少的代码进行开发。
    • 原理：springmvc中有一个DispatcherServlet中央调度器对象，这个对象负责接收用户的所有请求，再将其转发给Controller对象，最终将请求的处理结果显示给用户。
    • springmvc请求处理的流程：用户发起请求（以some.do为例），tomcat根据请求的路径来源（将会查找web.xml中url-pattern信息）将合理请求（映射规则，这里以*.do为例）转发给DispatcherServlet中央调度器，中央调度器根据springmvc.xml配置文件分派some.do给对应的控制器Controller方法，将其转发，到此请求就会被框架相应的处理。

2.第一个程序-请求处理

(1)步骤

  • 1)搭建环境。
    • 创建maven项目。
    • pom.xml文件导入Spring-mvc依赖，这其中就间接包括了Spring依赖。导入jsp、servlet依赖。
  • 2)配置文件。
    • web.xml文件中注册中央调度器（前端控制器）对象DispatcherServlet。
    • 编写Springmvc主配置文件，声明类的信息，由Spring负责创建和管理。
      • 声明组件扫描器，指定@Controller所在包名位置。
      • 声明视图解析器，处理视图。
  • 3)测试代码业务实现。
    • 创建控制器类Controller。控制器类Controller使用到@Controller注解声明为Bean由Spring创建管理对象和@RequestMapping注解绑定请求地址和方法。
    • 创建发起请求的页面jsp和作为显示请求处理结果的jsp。

         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"

    <!--  项目信息 web项目的打包方式为war -->

	  <artifactId>Spring-01</artifactId>
	  <packaging>war</packaging>

    <!--  导入依赖  -->
    <dependencies>
		    <!--  servlet，注意设置<scope>否则会和Tomcat插件冲突  -->

					<version>3.1.0</version>
					<scope>provided</scope>
				</dependency>
				<!--  springmvc  -->
				<dependency>
					<groupId>org.springframework</groupId>
					<artifactId>spring-webmvc</artifactId>
					<version>5.2.10.RELEASE</version>
				</dependency>
    </dependencies>

		<!--  Tomcat插件  -->
		<build>
			<plugins>
				<plugin>
					<groupId>org.apache.tomcat.maven</groupId>
					<artifactId>tomcat7-maven-plugin</artifactId>
					<version>2.1</version>
					<configuration>
						<port>80</port>
						<path>/</path>
					</configuration>
				</plugin>
			</plugins>
		</build>
</project>

(3)配置文件

  • 1)配置web.xml文件，注册中央调度器（前端控制器）对象DispatcherServlet。
    • 需要在Tomcat服务器启动时就创建DispatcherServlet对象是因为DispatcherServlet对象创建过程中同时将创建springmvc容器对象，当用户发起请求时就可以直接使用该对象。
    • load-on-startup标签表示服务器Tomcat启动后创建对象的顺序，取值为整数（大于等于0），数值越小，Tomcat创建对象的时间越早。
    • url-pattern有两种值，扩展名*.xxxx和斜杠/。

<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns="http://xmlns.jcp.org/xml/ns/javaee"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://xmlns.jcp.org/xml/ns/javaee http://xmlns.jcp.org/xml/ns/javaee/web-app_4_0.xsd"
         version="4.0">

    <!-- 自定义springmvc读取的配置文件的位置，若这里不进行设置，则固定读取路径/WEB-INF/<servlet-name>-servlet.xml -->
    <init-param>
        <!-- springmvc的配置文件的位置的属性 -->
        <param-name>contextConfigLocation</param-name>
        <param-value>classpath:springmvc.xml</param-value>
    </init-param>


    <!-- 声明注册springmvc核心对象DispatcherServlet，并在服务器启动时就创建DispatcherServlet对象 -->
    <servlet>
        <servlet-name>springmvc</servlet-name> <!--类名，自己能看懂即可-->
        <servlet-class>org.springframework.web.servlet.DispatcherServlet</servlet-class> <!--类具体位置，包名+类名-->
        <load-on-startup>1</load-on-startup>
    </servlet>

    <!--Servlet的请求路径-->
    <servlet-mapping>
        <servlet-name>myweb</servlet-name> <!--路径名，自己能看懂即可-->
        <url-pattern>*.do</url-pattern> <!--访问路径，这里访问路径只要是do结尾的请求都接收-->
    </servlet-mapping>

</web-app>

//定义表现层控制器bean
@Controller
public class MyController {
    //请求映射注解@RequestMapping，绑定请求地址和方法，表示该地址传来的请求由该方法处理
    @RequestMapping("/some.do")
    public ModelAndView dosome(){
        ModelAndView mv = new ModelAndView();
        //添加数据
        mv.addObject("msg","dosome方法执行了")
        //显示视图
        mv.setViewName("/show.jsp");
        //返回
        return mv;
    }
}
