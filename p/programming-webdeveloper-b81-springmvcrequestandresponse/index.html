1.概述

  • (1)请求：处理请求即处理各类请求参数的接收及封装。通过处理器方法的形参接收请求中的参数。
  • (2)响应：处理请求后返回给客户端的HTTP数据。
  • (3)访问路径：Spring系列框架使用@ResquestMapping注解设置当前控制器方法请求访问路径，并且可以实现设置该类的请求访问路径前缀。
  • (4)整个的处理过程其实是方法的执行过程对应了不同了动作，方法对应了接收请求后要执行的内容，方法的形参用于接收客户端传来的数据，方法的返回值是返回给客户端并在客户端上体现的内容。

@Controller
@RequestMapping("/user") //设置统一前缀
public class UserController {

    @RequestMapping("/save") //访问路径为/user/save
    @ResponseBody
    public String save(){
        System.out.println("user save ...");
        return "{'module':'user save'}";
    }
    
    @RequestMapping("/delete")//访问路径为/user/delete
    @ResponseBody
    public String save(){
        System.out.println("user delete ...");
        return "{'module':'user delete'}";
    }
}

2.形参-接收请求数据

(1)简单参数

  • 1)简单参数是指请求服务端时传递的是普通的请求数据。
  • 2)原始方式：通过HttpServletRequest对象调用getParameter(参数名)方法手动获取。（不推荐，仅作了解，方式与Servlet部分写法类似）
  • 3)Springboot方式：对于简单参数，方法形参名称与请求参数名称相同，定义形参即可接收参数，且会进行自动的类型转换。
  • 4)如果参数映射不一致，可以采用@RequestParam("xxx")注解来进行对应。需要注意的是，注解@RequestParam中的required属性默认为true，代表该请求参数必须传递，如果不传递将报错。 如果该参数是可选的，可以将required属性设置为false，例如(@RequestParam(name = "name", required = false) 。

(2)POJO实体参数

  • 1)在上述简单参数的情况中，前端传递了多少请求参数，后端就需要在方法中声明对应数量的形参进行接收，这在需要接收参数数量巨大的情况下显然是繁琐、不便于后期维护的。我们将所有的请求参数封装到一个实体类中，来解决这个问题。
  • 2)实体参数分为简单实体对象与复杂实体对象：
    • 简单POJO实体对象：请求参数名与形参对象属性名相同，定义POJO（实体类）接收即可。
    • 复杂/嵌套POJO实体对象：复杂情况即参数中存在嵌套等情况。请求参数名与形参对象属性名相同，按照对象层次结构关系即可接收嵌套POJO属性参数。

(3)数组集合参数

  • 1)数组类型参数：请求参数名与形参数组名称相同且请求参数为多个，定义数组类型形参即可接收参数。
  • 2)集合类型参数：请求参数名与形参集合对象名相同且请求参数为多个，因为默认会使用数组类型，因此需要使用@RequestParam注解绑定参数关系。

(4)日期时间参数

  • 1)常见的日期时间类型参数有用户的生日、操作时间，前端传递的日期参数由于存在很多种格式，因此需要使用@DateTimeFormat注解完成日期参数格式转换。

(5)Json参数

  • 1)页面发送请求传递Json格式的请求参数，服务端接收时，JSON数据键名与形参对象属性名相同，定义POJO类型形参即可接收参数，需要使用注解@RequestBody标识。

(6)路径参数

  • 1)路径参数是一种特殊的参数，是指参数已经成为了url的一部分。通过请求URL直接传递参数，使用{…}来标识该路径参数，需要使用注解@PathVariable获取路径参数进行绑定。

    @RequestMapping("/arrayParam")
    public String arrayParam(String[] hobby){
        System.out.println(Arrays.toString(hobby));
        return "OK";
    }

    @RequestMapping("/listParam")
    public String listParam(@RequestParam List<String> hobby){
        System.out.println(hobby);
        return "OK";
    }

    //4. 日期时间参数
    @RequestMapping("/dateParam")
    public String dateParam(@DateTimeFormat(pattern = "yyyy-MM-dd HH:mm:ss") LocalDateTime updateTime){
        System.out.println(updateTime);
        return "OK";
    }

    //5. json参数
    @RequestMapping("/jsonParam")
    public String jsonParam(@RequestBody User user){
        System.out.println(user);
        return "OK";
    }

    //6. 路径参数
    @RequestMapping("/path/{id}")
    public String pathParam(@PathVariable Integer id){
        System.out.println(id);
        return "OK";
    }

    @RequestMapping("/path/{id}/{name}")
    public String pathParam2(@PathVariable Integer id , @PathVariable String name){
        System.out.println(id);
        System.out.println(name);
        return "OK";
    }
}

3.返回值-设置响应数据

  • (1)处理器方法的返回值表示请求的处理结果。在上述接收请求数据的过程中，我们编写的return "OK";实际上就属于响应的内容，而我们能进行响应，都与注解@ResponseBody息息相关。
  • (2)@ResponseBody作用：将方法的返回值序列化输出，直接响应，如果返回值类型是实体对象/集合，将会转换为JSON格式后响应。注意，@RestController = @Controller + @ResponseBody。
  • (3)实际业务中考虑到项目的管理及后续维护，应当统一响应给前端的数据格式，因此通常会设置一个统一响应结果封装类。测试代码：

/**
 * 测试响应数据
 */
@RestController
//@RestController = @Controller + @ResponseBody
public class ResponseController {

		//设置统一的响应格式Result类

    //返回字符串
    @RequestMapping("/hello")
    public Result hello(){
        System.out.println("Hello World");
        return Result.success("Hello World"); //静态方法，类名直接调用
    }

    //响应对象数据，会转换为Json格式
    @RequestMapping("/getAddr")
    public Result getAddr(){
        Address addr = new Address();
        addr.setProvince("广东");
        addr.setCity("深圳");
        return Result.success(addr);
    }

    //响应集合数据，会转换为Json格式
    @RequestMapping("/listAddr")
    public Result listAddr(){
        List<Address> list = new ArrayList<>();

        Address addr = new Address();
        addr.setProvince("广东");
        addr.setCity("深圳");

        Address addr2 = new Address();
        addr2.setProvince("陕西");
        addr2.setCity("西安");

        list.add(addr);
        list.add(addr2);
        return Result.success(list);
    }
}

/**
 * 统一响应结果封装类
 */
public class Result {
    private Integer code ;//响应码 1 成功 , 0 失败
    private String msg; //提示信息
    private Object data; //返回的数据 date

    public Result() {
    }
    public Result(Integer code, String msg, Object data) {
        this.code = code;
        this.msg = msg;
        this.data = data;
    }
    public Integer getCode() {
        return code;
    }
    public void setCode(Integer code) {
        this.code = code;
    }
    public String getMsg() {
        return msg;
    }
    public void setMsg(String msg) {
        this.msg = msg;
    }
    public Object getData() {
        return data;
    }
    public void setData(Object data) {
        this.data = data;
    }

    //一些静态方法
    public static Result success(Object data){
        return new Result(1, "success", data);
    }
    //成功标识，无数据
    public static Result success(){
        return new Result(1, "success", null);
    }
    public static Result error(String msg){
        return new Result(0, msg, null);
    }

    @Override
    public String toString() {
        return "Result{" +
                "code=" + code +
                ", msg='" + msg + '\'' +
                ", data=" + data +
                '}';
    }
}
