1.概述

(1)流

  • Java 中的流（Stream）、文件（File）和 IO（input输入output输出）是处理数据读取和写入的基础设施，它们允许程序与外部数据（如文件、网络、系统输入等）进行交互。此外，Stream流是用来简化集合类库或者数组API的弊端。
  • java.io 包是 Java 标准库中的一个核心包，提供了用于系统输入和输出的类，它包含了处理数据流（字节流和字符流）、文件读写、序列化以及数据格式化的工具。
  • 一个流可以理解为一个数据的序列。输入流表示从一个源读取数据，输出流表示向一个目标写数据。

(2)作用

  • 1)文件操作：流可用于读取和写入文件，进行文件复制、文件查找和文件操作。
  • 2)网络通信：流用于建立网络连接，接收和发送数据，如HTTP请求和响应。
  • 3)数据处理：流可用于处理数据，如解析XML、JSON、处理图像和音频等。

(3)流的通用使用步骤

  • 1)得到一条流水线Stream，并放上数据，不同类型的数据用到不同的方法：
    • 对于单列集合Collection，可以使用Collection中的默认方法stream()获取。
    • 对于双列集合Map，无法直接使用stream流，必须先通过keySet()方法或是entrySet()方法先转换成单列集合，在获取流。
    • 对于数组，可以使用Arrays工具类中的静态方法stream()获取。
    • 对于零散数据，可以使用Stream接口中的静态方法public static<T> Stream<T> of(T...values)获取。

2.IO流

(1)概念

  • 1)IO流即存储和读取数据的解决方案，用于读写本地文件、网络等的数据。应用场景：游戏存档。

(2)分类

  • 1)根据方向（均以内存为参照物）：
    • 输入流Input：数据从其它地方读到内存。
    • 输出流Output：数据从内存写到其它地方。
  • 2)根据单位：
    • 字节流：用于处理二进制数据，适用于处理图像、音频等（字符流能处理的数据，字节流都能处理）。以Stream结尾的通常都是字节流。
    • 字符流：字符流=字节流+字符集。用于处理字符数据，适用于处理纯文本文件（字节流能处理的数据，字符流不一定能处理）。以Reader、Write结尾的通常都是字符流。纯文本文件：用windows系统自带的记事本打开并且能读懂的文件，例如txt文件，md文件，xml文件，Irc文件等。
  • 3)根据功能：
    • 节点流：具有读写数据的功能。
    • 过滤流：对节点流的封装，进行了功能增强，比如对象转换，数据缓存等。

//实现需求：把D:\project\movie.mp4拷贝到当前项目模块下
public class Copy {
    public static void main(String[] args) throws IOException {
        // 1.创建流对象
        FileInputStream fis = new FileInputStream("D:\\project\\movie.mp4");
        FileOutputStream fos = new FileOutputStream("copy.mp4");

        // 边读边写
        int len; //当前读取到的字节个数
        byte[] b = new byte[1024]; //长度为1024的数组，接下来我们一次读取就会尽量读取到1024字节的数据
        
        while ((len = fis.read(b)) != -1) { //没到文件结尾则继续循环
            fos.write(b, 0 , len); //每一次读取都往外写，参数0表示从0索引开始，本次能读取到len个元素，这样能避免残余数据
        }

        // 关闭资源，先开启的后关闭
        fos.close();
        fis.close();
    }
}

4.缓冲流

(1)概念

  • 1)缓冲流能够提高读写的概率，在字节节点流的基础之上，添加了缓冲区的功能，底层自带了长度为8192的缓冲区提高性能，提高IO效率。因为加入了缓冲，所以能减少访问磁盘的次数。
  • 2)真正工作的依旧是基本流。

6.对象操作流

(1)概念

  • 1)序列化流与反序列化流是针对字节流的，用以读写Java中的对象。
    • 序列化是将对象转换为字节流的过程，以便将对象保存到文件、数据库或在网络上传输。序列化使对象的状态可以被保持和还原。序列化流也称对象操作输出流。
    • 反序列化是将字节流转换回对象的过程，以便还原对象的状态。反序列化允许从文件、数据库或网络接收的字节流中还原对象。反序列化流也称对象操作输入流。
  • 2)作用：
    • 对象持久化：序列化允许将对象保存到文件或数据库，以便下次程序运行时还原对象。
    • 网络通信：序列化对象可用于在网络上传输数据，如分布式系统中的远程调用。
    • 缓存：序列化对象可用于将对象存储在缓存中，以提高性能和减少计算。

(2)ObjectOutputStream序列化流

  • 注意事项：
    • 一个对象要想序列化，该类必须实现java.io.Serializable接口。
    • 该类的所有属性必须是可序列化的。如果有一个属性不需要可序列化的，则该属性必须注明是瞬态的，使用transient 关键字修饰。
    • 序列化流写到文件中的数据是不能修改的，一旦修改就无法再次读取。
  • 写出的方法为writeObject()。

public class ZipStreamDemo {
    public static void main(String[] args) throws IOException {

        //1.创建一个File表示要解压的压缩包
        File src = new File("D:\\aaa.zip");
        //2.创建一个File表示解压的目的地
        File dest = new File("D:\\");

        //调用方法
        unzip(src,dest);

    }

    //定义一个方法用来解压
    public static void unzip(File src,File dest) throws IOException {
        //创建一个解压缩流用来读取压缩包中的数据
        ZipInputStream zip = new ZipInputStream(new FileInputStream(src));
        //要先获取到压缩包里面的每一个zipentry对象
        //表示当前在压缩包中获取到的文件或者文件夹
        ZipEntry entry;
        while((entry = zip.getNextEntry()) != null){
            System.out.println(entry);
            if(entry.isDirectory()){
                //文件夹：文件夹不存在拷贝，而是判断什么位置新创建文件夹
                File file = new File(dest,entry.toString());
                file.mkdirs();
            }else{
                //文件：需要读取到压缩包中的文件，并把它存放到目的地dest文件夹中（按照层级目录进行存放）
                FileOutputStream fos = new FileOutputStream(new File(dest,entry.toString()));
                int b;
                while((b = zip.read()) != -1){
                    //读取到的数据写到目的地
                    fos.write(b);
                }
                fos.close();
                //表示在压缩包中的一个文件处理完毕
                zip.closeEntry();
            }
        }
        zip.close();
    }
}

public class ZipStreamDemo2 {
    public static void main(String[] args) throws IOException {
        //1.创建File对象表示要压缩的文件
        File src = new File("D:\\a.txt");
        //2.创建File对象表示压缩包的位置
        File dest = new File("D:\\");
        //3.调用方法用来压缩
        toZip(src,dest);
    }

    public static void toZip(File src,File dest) throws IOException { //参数一：表示要压缩的文件;参数二：表示压缩包的位置
        //1.创建压缩流关联压缩包
        ZipOutputStream zos = new ZipOutputStream(new FileOutputStream(new File(dest,"a.zip")));
        //2.创建ZipEntry对象，表示压缩包里面的每一个文件和文件夹，但此时放进来的是文件，不包括文件里的数据
        ZipEntry entry = new ZipEntry("a.txt");
        //3.把ZipEntry对象放到压缩包当中
        zos.putNextEntry(entry);
        //4.把src文件中的数据写到压缩包当中
        FileInputStream fis = new FileInputStream(src);
        int b;
        while((b = fis.read()) != -1){
            zos.write(b);
        }
        zos.closeEntry();
        zos.close();
    }
}

//压缩多个文件，把D:\\aaa文件夹压缩成一个压缩包
public class ZipStreamDemo3 {
    public static void main(String[] args) throws IOException {
        //1.创建File对象表示要压缩的文件夹
        File src = new File("D:\\aaa");
        //2.创建File对象表示压缩包放在哪里（压缩包的根级路径）
        File destParent = src.getParentFile();
        //3.创建File对象表示压缩包的路径
        File dest = new File(destParent,src.getName() + ".zip");
        //4.创建压缩流关联压缩包
        ZipOutputStream zos = new ZipOutputStream(new FileOutputStream(dest));
        //5.获取src里面的每一个文件，变成ZipEntry对象，放入到压缩包当中
        toZip(src,zos,src.getName());//aaa
        //6.释放资源
        zos.close();
    }

    /*
    *   作用：获取src里面的每一个文件，变成ZipEntry对象，放入到压缩包当中
    *   参数一：数据源
    *   参数二：压缩流
    *   参数三：压缩包内部的路径
    * */
    public static void toZip(File src,ZipOutputStream zos,String name) throws IOException {
        //1.进入src文件夹
        File[] files = src.listFiles();
        //2.遍历数组
        for (File file : files) {
            if(file.isFile()){
                //3.判断-文件，变成ZipEntry对象，放入到压缩包当中
                ZipEntry entry = new ZipEntry(name + "\\" + file.getName());//aaa\\no1\\a.txt
                zos.putNextEntry(entry);
                //读取文件中的数据，写到压缩包
                FileInputStream fis = new FileInputStream(file);
                int b;
                while((b = fis.read()) != -1){
                    zos.write(b);
                }
                fis.close();
                zos.closeEntry();
            }else{
                //4.判断-文件夹，递归
                toZip(file,zos,name + "\\" + file.getName());
            }
        }
    }
}
