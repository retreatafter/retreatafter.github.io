1.概述

  • (1)Java服务器端页面Java Server Pages，和Servlet一样，用于动态Web技术。
  • (2)JSP本质上就是一个Servlet，通过查看服务器内部工作，IDEA中使用Tomcat时，会在IDEA的tomcat中生产一个work目录，在这个目录下可以看到jsp源码，通过查看源码可以验证这一点。
    • 用户请求服务器，服务器中存在web容器，其中存在JSP页面，对JSP页面进行转换为Java文件，Java文件编译为.class文件，最后这个格式为xxx_jsp.class文件返回给服务器主机，用户真正拿到的是服务器处理完毕的class对象，即Servlet。
1

response.setContentType("text/html");       // jsp转换为html底层原理，在这一步设置响应的页面类型
  • (3)在JSP页面中只要是JAVA代码就会原封不动的输出；如果是HTML代码，就会被转换为out.write("内容");形式。
  • (4)JSP由于其前后端不分离的缺陷，已基本退出市场。

<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"

        </dependency>

            <version>1.1.2</version>
        </dependency>
        
    </dependencies>

</project>
  • (3)JSP表达式：<%= 变量或者表达式%>。作用：用来将程序的输出，输出到客户端。

4.内置对象

  • (1)pageContext，request，session，application这四个对象都可以用来存数据，区别在于：pageContext保存的数据只在一个页面中有效；request保存的数据只在一次请求中有效，请求转发会携带这个数据；session保存的数据只在一次会话中有效，从打开浏览器到关闭浏览器；application保存的数据只在服务器中有效，从打开服务器到关闭服务器。

5.EL表达式与JSP标签与JSTL标签

  • (1)当JSP前后端代码不分离的弊端暴露后，出现了以下表达式和标签，”包装“/替代原本的Java代码，从而不让原生的Java代码出现在JSP页面中。
  • (2)EL（Expression Language）表达式：是一种简化JSP页面数据访问和操作的语言，可以用于获取数据、执行运算、获取web开发的常用对象。格式：${}
    • EL（Expression Language）表达式本质是替换了Java中获取数据相关的代码。

<%--c:choose和c:when标签--%>
<%@ page contentType="text/html;charset=UTF-8" %>
<%--引入jstl核心标签库--%>
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
<html>
<head>
    <title>core-for</title>
</head>
<body>

<%--定义一个变量score，值为85--%>
<c:set var="score" value="65"/>

<c:choose>
    <c:when test="${score>=90}">
        你的成绩为优秀
    </c:when>
    <c:when test="${score>=80}">
        你的成绩为一般
    </c:when>
    <c:when test="${score>=70}">
        你的成绩为良好
    </c:when>
    <c:when test="${score<=60}">
        你的成绩为不及格
    </c:when>
</c:choose>

</body>
</html>

<%--c:forEach标签--%>
<%@ page import="java.util.ArrayList" %>
<%@ page contentType="text/html;charset=UTF-8" %>
<%--引入jstl核心标签库--%>
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
<html>
<head>
    <title>core-foreach</title>
</head>
<body>

<%

    ArrayList<String> people = new ArrayList<>();
    people.add(0,"张三");
    people.add(1,"李四");
    people.add(2,"王五");
    people.add(3,"赵六");
    people.add(4,"田七");
    request.setAttribute("list",people);
%>

<%--
var , 每一次遍历出来的变量
items, 要遍历的对象
begin,   哪里开始
end,     到哪里
step,   步长
--%>
<c:forEach var="people" items="${list}">
    <c:out value="${people}"/> <br>
</c:forEach>

<hr>

<c:forEach var="people" items="${list}" begin="1" end="3" step="1" >
    <c:out value="${people}"/> <br>
</c:forEach>

</body>
</html>
