1.概述

  • 网络编程即在网络通信协议下，不同计算机上运行的程序，进行的数据传输。
  • 网络编程的目的，即多台计算机及外部设备，实现传播交流信息、进行通信和数据交换。具体来说，即在程序本身这个进程内，连接别的服务器进程的通信端口进行通信。
  • 常见软件架构：
    • C/S(Client/Server 客户端/服务器)：需要开发客户端，也需要开发服务端；用户需要下载和更新的时候太麻烦；画面可以做的非常精美，用户体验好。
    • B/S(Browser/Server 浏览器/服务器)：不需要开发客户端，只需要开发服务端；用户不需要下载，打开浏览器就能使用；如果应用过大，用户体验会受到影响，因此画面普遍不精美。

2.网络通信

  • (1)进行网络通信的必要条件，定位到网络上的目的主机，传输数据。
  • (2)三要素：
    • ip：设备在网络中的地址，唯一定位一台网络上的计算机。
    • 端口号：应用程序在设备中唯一的标识。
    • 协议：网络通信协议，数据在网络中传输的规则，常见的协议有UDP、TCP、http、https、ftp。

4.端口

  • 抽象地说，端口表示计算机上一个程序的进程。不同的进程有不同的端口号，用来区分软件，因此软件间不会存在相同的端口号。
  • 端口分配
    • 公有端口：0~1023，内置的进程使用。
    • 程序注册端口：1014-49151，分配给用户和程序。
    • 动态、私有端口：49152~65535。

5.通信协议

  • 协议：约定，可类比于中国人之间能基本交流无阻是约定了说普通话。计算机为了联网，就必须规定通信协议，早期的计算机网络，都是由各厂商自己规定一套协议，IBM、Apple和Microsoft都有各自的网络协议，互不兼容，为了把全世界的所有不同类型的计算机都连接起来，就必须规定一套全球通用的协议，为了实现互联网这个目标，互联网协议簇（Internet Protocol Suite）就是通用协议标准。
  • TCP/IP协议簇：实际上是一组协议
    • 传输层：
      • TCP：用户传输协议，稳定，不允许内容丢失。
      • UDP：用户数据报协议，不稳定，允许（容忍）内容部分丢失。
    • 网络层
      • IP：网络互连协议。
  • TCP的三次握手四次挥手，次数表示响应最低次数，可简单记忆为：

6.TCP

(1)概念

  • TCP特点：
    • 面向连接的协议，基于通信管道，通过三次握手建立连接，连接成功形成数据传输通道，通过四次挥手断开连接。只能由客户端主动发送数据给服务器端，服务器端接收到数据之后，可以给客户端响应数据。速度慢，但是是可靠的协议。
    • 基于IO流进行数据传输，传输数据大小没有限制。
  • 2)应用场景：文件上传和下载，邮件发送和接收，远程登录。
  • 3)TCP协议相关的两个类：Socket和ServerSocket。TCP通信也叫Socket网络编程。

(2)Socket

  • 1)概念：一个该类的对象就代表一个客户端程序。
  • 2)构造方法：Socket(String host, int port)，根据ip地址字符串和端口号创建客户端Socket对象。
  • 3)常用API：
1
2

OutputStream getOutputStream()                               // 获得字节输出流对象
InputStream getInputStream()                                 // 获得字节输入流对象
  • 4)开发流程：
    • 客户端要请求于服务端的Socket管道连接。
    • 从Socket通信管道中得到一个字节输出流。
    • 通过字节输出流给服务端写出数据。

(3)ServerSocket

  • 1)概念：一个该类的对象就代表一个服务器端程序。
  • 2)构造方法：public ServerSocket(int port)，port为注册端口，指定用哪个端口接收数据。
  • 3)常用API：
1

public Socket accept()                           //等待接收一个客户端的Socket管道连接请求，连接成功返回一个Socket对象
  • 4)开发流程：
    • ServerSocket注册端口。
    • 接收客户端的Socket管道连接。
    • 从Socket通信管道中得到一个字节输入流。
    • 从字节输入流中读取客户端发来的数据。

import java.io.IOException;
import java.io.OutputStream;
import java.net.InetAddress;
import java.net.Socket;

// 客户端
public class TCPClientDemo01 {
    public static void main(String[] args) {
        Socket socket = null;
        OutputStream os = null;

        try {
            // 1.要知道服务器的地址
            InetAddress serverIP = InetAddress.getByName("127.0.0.1");
            int port = 9999; // 定义要连接的端口号
            // 2.创建一个socket连接
            socket = new Socket(serverIP,port); // 可以通过看Socket()构造器类型选择传参方式，这里是输入IP和端口号
            // 3.运用IO流发送信息
            os = socket.getOutputStream(); // 输出流
            os.write("你好，是否接收到消息？".getBytes()); // 输出流往外写，并使用getBytes()方法用于将字符串转换为字节序列
        }catch (Exception e){
            e.printStackTrace();
        } finally {
            // 关闭资源，标准写法中，关闭时还需要进行一次判断写明捕获异常
            if(os != null){
                try {
                    os.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
            if(socket != null){
                try {
                    socket.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
        }
    }
}

import java.io.ByteArrayOutputStream;
import java.io.IOException;
import java.io.InputStream;
import java.net.ServerSocket;
import java.net.Socket;

// 服务端
public class TCPServerDemo01 {
    public static void main(String[] args) {

        ServerSocket serverSocket = null;
        Socket socket = null;
        InputStream is = null;
        ByteArrayOutputStream baos = null;

        try{
            // 1.端口注册
            serverSocket = new ServerSocket(9999); // 参数也即这里的端口号9999是我们定义的
            // 2.等待客户端连接过来
            socket = serverSocket.accept(); // 这里接收的实际上就是客户端代码中创建socket连接中`socket = new Socket(serverIP,port);`的serverIP和port
            // 3.读取客户端的消息
            is = socket.getInputStream();
            // 使用管道流，把读取到的消息通过管道流写出来
            baos = new ByteArrayOutputStream();

            byte[] buffer = new byte[1024]; // 设置一个缓冲区
            int len = 0;
            while ((len = is.read(buffer)) != -1) { // 输入流对象从缓冲区里读的数据赋值给len，判断这个长度来确定是否有值
                baos.write(buffer, 0, len); //使用write()方法将数据写出去，拼接buffer，从0拼接到len
            }
            System.out.println(baos.toString()); // 全部内容输出后转换为字符串

        } catch (IOException e) {
            e.printStackTrace();
        } finally {
            // 关闭资源，标准写法中，关闭时还需要进行一次判断写明捕获异常
            if (baos != null) {
                try {
                    baos.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
            if (is != null) {
                try {
                    is.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
            if (socket != null) {
                try {
                    socket.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
            if (serverSocket != null) {
                try {
                    serverSocket.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
        }
    }
}

public class ServerDemo {
    public static void main(String[] args) throws Exception {
        System.out.println("----服务端启动----");
        // 1.注册端口: public ServerSocket(int port)
        ServerSocket serverSocket = new ServerSocket(9999);
        // 2.定义一个循环不断的接收客户端的连接请求
        while(true){
            // 3.开始等待接收客户端的Socket管道连接
            Socket socket = serverSocket.accept();
            // 4.每接收到一个客户端必须为这个客户端管道分配一个独立的线程来处理与之通信
            new ServerReaderThread(socket).start();
        }
    }
}

//一个类想要是线程类必须继承Thread
class ServerReaderThread extends Thread{
    private Socket socket ;
    public ServerReaderThread(Socket socket){
        this.socket = socket;
    }

    @Override
    public void run() {
        try{
            // 3.从socket通信管道中得到一个字节输入流
            InputStream is = socket.getInputStream();
            // 4.把字节输入流转换成字符输入流
            Reader isr = new InputStreamReader(is);
            // 5.把字符输入流包装成缓冲字符输入流
            BufferedReader br = new BufferedReader(isr);
            // 6.按照行读取消息 
            String line ;
            while((line = br.readLine())!=null){
                System.out.println(socket.getRemoteSocketAddress()+"说："+line);
            }
        }catch (Exception e){
            System.out.println(socket.getRemoteSocketAddress()+"下线了");
        }
    }
}

//客户端上传图片给服务端保存起来
public class ClientDemo {
    // 本地图片路径
    public static void main(String[] args) throws Exception {
        // 1.请求于服务端的Socket管道连接
        Socket socket = new Socket(Constants.SERVER_IP , Constants.SERVER_PORT);
        // 2.从socket管道中得到一个字节输出流包装成缓冲字节输出流
        BufferedOutputStream bos = new BufferedOutputStream(socket.getOutputStream());
        // 3.提取本机的图片上传给服务端
        // 4.得到一个缓冲字节输入流与本地图片接通
        BufferedInputStream bis =
                new BufferedInputStream(new FileInputStream(Constants.SRC_IMAGE));
        // 5.定义一个字节数组
        byte[] buffer = new byte[1024];
        int len;
        while((len = bis.read(buffer)) != -1) {
            bos.write(buffer, 0 ,len);
        }
        bos.flush(); // 刷新图片数据到服务端
        socket.shutdownOutput(); // 告诉服务端我的数据已经发送完毕
        bis.close(); // 可以关闭

        // 6.等待着服务端的响应数据
        BufferedReader  br = new BufferedReader(new InputStreamReader(socket.getInputStream()));
        System.out.println("收到服务端响应："+br.readLine());
    }
}

class ServerReaderThread extends Thread{
    private Socket socket ;
    public ServerReaderThread(Socket socket){
        this.socket = socket;
    }

    @Override
    public void run() {
        try{
            // 1.从socket通信管道中得到一个字节输入流读取客户端发来的图片数据
            InputStream is = socket.getInputStream();
            // 2.包装成高级的缓冲字节输入流
            BufferedInputStream bis = new BufferedInputStream(is);
            // 3.定义一个缓冲字节输出流通向目标路径（服务端路径）
            BufferedOutputStream bos =
                    new BufferedOutputStream(new FileOutputStream(Constants.SERVER_DIR+ UUID.randomUUID().toString()+".jpg"));
            byte[] buffer = new byte[1024];
            int len ;
            while((len = bis.read(buffer)) != -1) {
                bos.write(buffer, 0 ,len);
            }
            bos.close();
            System.out.println("服务端接收完毕了！");

            // 4.响应数据给客户端
            PrintStream ps = new PrintStream(socket.getOutputStream());
            ps.println("您好，已成功接收您上传的图片！");
            ps.flush();

            Thread.sleep(100000); // 等消失发送完毕被客户端接收后死亡
        }catch (Exception e){
            System.out.println(socket.getRemoteSocketAddress()+"下线了");
        }
    }
}

(5)Tomcat

7.UDP

(1)概念

  • 1)UDP特点：
    • 面向无连接的协议，发送端只管发送，不确认对方是否能收到。速度快，但是不可靠。会丢失数据。
    • 基于数据包进行数据传输，且发送数据的包的大小限制64KB以内。
  • 2)应用场景：在线视频，网络语音电话。
  • 3)UDP协议相关的两个类：DatagramPacket和DatagramSocket。

(2)DatagramPacket

  • 1)构造方法
    • 发送端：new DatagramPacket(byte[] buf, int length, InetAddress address, int port)，buf表示要发送的内容，字节数组；length表示要发送内容的长度，单位是字节；address表示接收端的IP地址对象；port表示接收端的端口号。
    • 接收端：new DatagramPacket(byte[] buf, int length)，buf表示用来存储接收到内容；length表示能够接收内容的长度。
  • 2)常用API：
1

int getLength()                                 //获得实际接收到的字节个数

(3)DatagramSocket

  • 1)构造方法
    • 发送端：DatagramSocket()，创建发送端的Socket对象，系统会随机分配一个端口号。
    • 接收端：DatagramSocket(int port)，创建接收端的Socket对象并指定端口号。
  • 2)常用API：
1
2

void send(DatagramPacket dp)                    //发送数据包
void receive(DatagramPacket p)                  //接收数据包

import java.io.IOException;

import java.net.DatagramSocket;
import java.net.SocketException;

public class TalkReceive implements Runnable{
    DatagramSocket socket = null;
    private int port;
    private String msgFrom;

		// 构造器
    public TalkReceive(int port, String msgFrom) {
        this.port = port;
        this.msgFrom = msgFrom;
        try {
            socket = new DatagramSocket(port);
        } catch (SocketException e) {
            e.printStackTrace();
        }
    }

    @Override
    public void run() {
        //开放端口

        // 接收包
        while (true){
            try {
                byte[] container = new byte[1024];
                DatagramPacket packet = new DatagramPacket(container,0,container.length);

                // 接收
                socket.receive(packet);

                byte[] data = packet.getData();
                String receiveData = new String(data);
                System.out.println(msgFrom + ":" + receiveData);

                if (receiveData.equals("bye")){ //自行设置了一个结束条件，当输入bye之后结束线程
                    break;
                }
            } catch (IOException e) {
                e.printStackTrace();
            }
        }

        socket.close();
    }
}

// 4.线程
class ServerReaderThread extends Thread{
    private Socket socket;
    public ServerReaderThread(Socket socket) {
        this.socket = socket;
    }

    @Override
    public void run() {
        try {
            // 响应消息数据给浏览器显示
            // 浏览器是基于HTTP/HTTPS协议通信，响应格式必须满足HTTP协议数据格式的要求，浏览器才能够识别
            PrintStream ps = new PrintStream(socket.getOutputStream()); //响应，是输出流
            ps.println("HTTP/1.1 200 OK"); // 响应数据的响应头数据
            ps.println("Content-Type:text/html;charset=UTF-8");//响应数据的类型。网页或者文本内容
            ps.println(); // 必须换一行
            // 以下开始响应真实的数据
            ps.println("<span style='color:green;font-size:100px;'>测试数据<span>");
            Thread.sleep(4000); //延时
            ps.close();

        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
