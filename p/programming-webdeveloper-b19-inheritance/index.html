1.概述

  • (1)核心：关键字：extends。
  • (2)继承是类和类之间的一种关系，在Java中继承是 “is a” 的关系，一个为child子类（派生类），一个为parent超类（基类），子类会拥有基类的所有方法。除此之外，类和类之间的关系还有依赖、组合、聚合等……
    • 1)继承可以提高代码的复用性，相同代码可以定义在超类中。
    • 2)子类能继承基类的非私有的成员变量和成员方法。
    • 3)构造方法无法继承。
    • 4)子类可以继承超类的私有成员（通过反射获得）。
    • 5)子类可以访问超类的静态成员，但其本质是共享访问，共享并非继承。
  • (3)构造方法的访问特点：子类中所有的构造方法默认先访问基类中的无参构造，再执行自己的构造方法，即子类初始化之前，会先完成基类数据空间的初始化。这是因为子类在初始化的时候，有可能会使用到基类中的数据，如果基类没有完成初始化，子类将无法使用基类的数据。而其代码底层中，实际上子类的构造器的第一行默认有一个super()调用基类的无参数构造器，写不写都存在。
  • (4)Java仅支持单继承，但支持多层继承。
  • (5)格式：

3.关键字this和super

(1)this

  • 1)this代表了当前对象的引用。this关键字可以用在实例方法和构造器中：
    • this用在方法中，谁调用这个方法，this就代表谁。
    • this用在构造器，代表了构造器正在初始化的那个对象的引用。
  • 2)this作用：区分成员变量和局部变量，this.变量名指的是该类中的成员变量，在代码数据就近原则的前提下，使用this关键字可以让机器明白我们需要的是成员变量。

	private String name;
	private Integer age;

	public void setName(String aName) {
	//不冲突而无需使用this关键字的一般写法
		name=aName；
	}

	public void setAge(Integer age) {
		this.age=age； //等号右侧的age就近原则会去找setAge()方法里外界传进来的Integer age值，然后再赋值给等号左侧，等号左侧的this.age指的是Person类里我们上方定义的private Integer age的成员变量age值
	}
}

	public Person() {

	public Person(Integer age) { 
		this("匿名",age);

	public Person(String name) {
		this(name,18);

	public Person(String name, Integer age) {
		this.name = name;
		this.age = age;
	}
}

  • 1)super关键字可以用来调用基类的构造方法、成员方法和属性，以及区分子类和基类中同名的变量和方法。

(3)区别

  • 1)super和this都能调用成员属性、成员方法、构造方法。super出现在继承基类的子类里，this是在本类进行。
  • 2)super调用基类的构造方法时，必须写在构造方法的第一个。this调用本类其它构造器时，必须写在构造方法的第一个。
  • 3)super必须只能出现在子类的方法或构造方法中。
  • 4)this(…)和super(…)必须放在构造器的第一行，因此super(…)和this(…)不能同时调用构造方法。
  • 5)this VS super
/ 代表的对象 前提 构造方法
this 代表本身这个对象 没有继承也可以使用 this()调用当前类的构造
super 代表基类对象的应用 必须在继承条件下才能使用 super()调用了基类的构造

4.方法的重写Override

  • 1)概念：在继承体系中，子类出现了和基类中一模一样的方法声明，就称子类的这个方法是重写的方法。重写的本质是覆盖了虚方法表内对应方法（这个方法是继承过来的）。
  • 2)规则：
    • 方法名必须相同；参数列表必须相同；修饰符访问权限范围可以扩大。public > Protected > Default > Private；返回值类型范围可以一样，否则必须缩小；抛出异常：范围可以被缩小，但是不能被扩大，常见异常ClassNotFoundException。
    • 在重写方法的上方应写有注解@Override，和注释稍有不同，注解会被虚拟机JVM扫描，并自动校验是否存在语法问题等。
  • 3)非静态方法的重写
    • public共有的可以重写，private私有的无法重写。
    • static静态方法无法重写。
