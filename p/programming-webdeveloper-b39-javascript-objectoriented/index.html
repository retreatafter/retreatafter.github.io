1.基础对象

(1)Array

  • 1)JS中的数组类似于Java中的集合，类型可变，长度可变。
  • 2)数组定义：
    • 方式一：var 变量名 = new Array(元素列表);。
    • 方式二（简化了方式一）：var 变量名 = [ 元素列表 ];。

arr[9] = "A";
arr[8] = true;

console.log(arr); //[1,2,3,4,empty×4,true,'A',50]，empty即undefined
  • 3)Array的属性与常用API
    • 属性：length，设置或返回数组中元素的数量。
    • 方法：
      • forEach()方法，遍历数组中的每个有值的元素（无值的不会显示），并调用一次传入的函数。
      • push()方法，将新元素添加到数组的末尾，并返回新的长度。
      • splice()方法，从数组中删除元素。

(2)String

  • 1)字符串定义：
    • 方式一：var 变量名 = new String("字符串内容") ;。
    • 方式二（简化了方式一）：var 变量名 = "字符串内容";。
1
2

var str = new String("Hello String"); //方式一
var str = 'Hello String'; //方式二
  • 2)String的属性与常用API
    • 属性：length，返回字符串的长度。
    • 方法：
      • charAt()方法，返回在指定位置的字符。
      • indexOf()方法，检索字符串。
      • trim()方法，去除字符串两边的空格。
      • substring(start,end)方法，提取字符串中两个指定的索引号之间的字符，范围含头不含尾。

(3)JSON

  • 1)自定义对象
    • (A)格式：JS中用{…}表示一个对象，属性由多个键值对构成，多个属性之间用逗号隔开，最后一个属性不加逗号。
    • (B)特点：
      • 定义对象是大括号，定义数组是中括号。
      • 这里的对象并不是面向对象里的对象。

	属性名: 属性值,
	属性名: 属性值
	函数名称: function(形参列表){}
}
  • 2)JSON
    • (A)JSON(JavaScript Object Notation, JS 对象标记法)是通过JavaScript标记法书写的文本。
    • (B)格式：
      • '{"key1": value1,"key2": value2}';。例如var jsonStr = '{"name":"Tom", "age":18, "addr":["北京","上海","西安"]}';。
      • 整个内容用单引号包裹。
      • 数据为键值对，key:value，且key用双引号包裹。
      • 如果value为数组，用[]；为对象，用{}。
  • 3)JSON字符串不是对象，想要使用方法需要转换成JS对象，JSON字符串和JS对象互相转化：
    • parse(userStr)方法，JSON字符转化为JS对象。
    • stringify(jsObject)方法，JS对象转化为JSON字符。

2.BOM对象

(1)定义

  • 1)BOM(Browser Object Model)浏览器对象模型，即JavaScript将浏览器的各个组成部分封装成了对象。

(2)类型

  • 1)window对象，代表浏览器窗口。
    • (A)window是JavaScript的全部对象，所以对于window对象，可以直接使用，例如window.alert('hello');，且可以简写为alert('hello')。
    • (B)属性：
      • history，用于获取History对象。
      • location，用于获取Location对象。
      • navigator，用于获取Navigator对象。
    • (C)方法：
      • alert()方法，显示带有一段消息和一个确认按钮的警告框。
      • comfirm()方法，显示带有一段消息以及确认按钮和取消按钮的对话框。
      • setInterval()方法，定时器，按照指定的周期（以毫秒计）来调用函数或计算表达式。
      • setTimeout()方法，定时器，在指定的毫秒数后调用函数或计算表达式，只会调用一次。
  • 2)screen对象，代表屏幕对象。
  • 3)location对象，代表地址栏对象，即当前页面的URL信息。
    • (A)对于location对象，可以直接使用例如window.location.属性;，且可以简写为location.属性。
    • (B)属性：
      • href，获取或者设置浏览器的url地址信息。
  • 4)history对象，代表历史记录对象。
  • 5)navigator对象，代表浏览器对象。

3.DOM对象

(1)概念

  • 1)DOM(Document Object Model)文档对象模型，HTML文档被浏览器加载解析之后就会将各个组成部分封装为对象。
    • 浏览器网页是DOM树形结构，HTML本质是一棵树，HTML文档的主干是标签(tag)，每个HTML标签都是一个对象，所有这些对象都可以通过 JavaScript 来访问，即JS通过DOM，可以实现改变HTML元素的内容、改变HTML元素的样式（CSS）、对HTML的DOM事件作出反应、添加和删除HTML元素。
    • 例如，可以通过DOM来实现从上图到下图的动态效果：
  • 2)DOM是W3C（万维网联盟）的标准，定义了访问HTML和XML文档的标准，分为3个不同的部分：
    • Core DOM，所有文档类型的标准模型：
      • Document：整个文档对象。
      • Element：元素对象。
      • Attribute：属性对象。
      • Text：文本对象。
      • Comment：注释对象。
    • XML DOM，XML文档的标准模型。
    • HTML DOM，HTML文档的标准模型，对每一个标签都封装成了一个对象。

(2)获取DOM节点

  • 1)通过Document对象获取。常用API：
    • document.getElementById()方法，根据id属性值获取，返回单个Element对象。
    • document.getElementsByTagName()方法，根据标签名称获取，返回Element对象数组。
    • document.getElementsByName()方法，根据name属性值获取，返回Element对象数组。
    • document.getElementsByClassName()方法，根据class属性值获取，返回Element对象数组。

(3)增删改DOM节点

  • 1)更多的操作可以参考JS手册，最重要的是第一步先获取到对象，获取到对象后根据提供的方法来实现增删改操作。
  • 2)更新：
    • (A)操作文本，例：
      • id1.innerText='456'; 修改文本的值。
      • id1.innerHTML='<strong>123</strong>'; 可以解析HTML文本的标签。
    • ()操作CSS，例：
      • id1.style.color = 'blue'; 修改文本颜色；
      • id1.style.fontSize='22px'; 修改文字大小；
      • id1.style.padding='2em'; 修改文本位置；
  • 3)删除:
    • 先获取根节点，再通过根节点删除自己，方法removeChild(self)。
  • 4)插入：
    • 原dom节点为空：获得该Dom节点后，通过innerHTML()就可以增加一个元素。
    • 原dom节点不为空：此时修改会产生元素覆盖。

4.事件监听

  • (1)事件与事件监听：按钮被点击、鼠标移到元素上、输入框失去焦点等等都属于事件，对这些事件绑定函数，当事件触发时，可以自动的完成对应的功能，这就是事件监听。
  • (2)常见事件：
    • onclick，鼠标单击事件。
    • onblur，元素失去焦点。
    • onfocus，元素获得焦点。
    • onload，某个页面或图像被完成加载。
    • onsubmit，当表单提交时触发该事件。
    • onkeydown，某个键盘的键被按下。
    • onmouseover，鼠标被移到某元素之上。
    • onmouseout，鼠标从某元素移开。
  • (3)事件绑定：
    • 方式一：HTML文件与JS代码处于同一文件时，可通过html标签中的事件属性进行绑定，但耦合性高。
    • 方式二：通过DOM中Element元素的事件属性进行绑定。
