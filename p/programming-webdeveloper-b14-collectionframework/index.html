1.集合概述

(1)基本概念

  • 1)集合（Collection和Map）是一种用于存储和操作一组对象的数据结构，长度可变。
  • 2)数组与集合：
    • 数组结果表示为{}，如{1,2,4,6}；集合结果表示为[]，如[1,2,3,4,5,6]。
    • 数组可以直接存储基本数据类型或引用数据类型；集合可以存储引用数据类型，存储基本数据类型必须使用包装类。
  • 3)Java集合框架提供了一组接口和类，用于实现和操作各种类型的集合。可以简单分为两类，单列集合Collection（每次添加一个元素）和双列集合Map（每次添加一对元素）。

(2)包装类

  • 1)包装类是 Java 中一组与基本数据类型对应的类，用于将基本数据类型转换为对象（引用数据类型）。JDK5后引入了自动装箱、自动拆箱概念，即自动完成这8种基本数据类型和对应包装类对象之间的转换。
    • 自动装箱：可以直接把基本数据类型的值或者变量赋值给包装类。
    • 自动拆箱：可以把包装类的变量直接赋值给基本数据类型。
  • 2)对应关系：
    • int对应Integer。
    • char对应Character。
    • byte对应Byte。
    • short对应Short。
    • long对应Long。
    • float对应Float。
    • double对应Double。
    • boolean对应Boolean。
  • 3)常用API：valueOf("字符串类型的数值")把字符串类型的数值转换成对应的基本数据类型的值。

2.Collection

(1)Collection概念

  • 1)Collection下又分为List接口和Set接口。
    • List系列的特点为有序（元素存和取的顺序一样，和元素之间的排序没有关系）、可重复、有索引；
      • ArrayList：添加的元素，是有序，可重复，有索引的。
      • LinkedList：添加的元素，是有序，可重复，有索引的。
    • Set系列的特点为无序（元素存和取的顺序不一样，和元素之间的排序没有关系）、不重复、无索引。
      • HashSet：添加的元素，是无序，不重复，无索引的。
      • TreeSet：按照大小默认升序排序，不重复，无索引。
      • LinkedHashSet：添加的元素，是有序，不重复，无索引的。
  • 2)应用场景：
    • 如果希望元素可以重复，又有索引，查询要快用ArrayList集合。（用的最多）
    • 如果希望元素可以重复，又有索引，增删要快要用LinkedList集合。（适合查询元素比较少的情况，经常要首尾操作元素的情况）
    • 如果希望增删改查都很快，但是元素不重复以及无序无索引，那么用HashSet集合。
    • 如果希望增删改查都很快且有序，但是元素不重复以及无索引，那么用LinkedHashSet集合。
  • 3)Collection是单列集合的根接口，它的方法是全部单列集合都可以继承使用的：

(2)ArrayList

1）基本概念

  • ArrayList 类是一个可以动态修改的数组，与普通数组的区别就是它是没有固定大小的限制，我们可以添加或删除元素。
  • ArrayList 继承自 AbstractList ，并实现了 List 接口。

2）创建

  • 1)导入类：import java.util.ArrayList;
  • 2)创建对象：
    • 使用无参构造函数创建一个空的ArrayList：ArrayList<String（泛型）> list = new ArrayList<>();，这里的泛型即限定集合中存储数据的类型
    • 使用带初始容量的构造函数创建ArrayList：ArrayList<String> list = new ArrayList<>(cap);

3）常用API增删改查CRUD

  • 1)添加元素：使用add()方法添加ArrayList中的元素。
  • 2)删除元素：使用remove()方法删除ArrayList中的指定位置或指定元素。
  • 3)更新元素：使用set()方法更新ArrayList中的指定位置的元素。
  • 4)访问元素：使用get()方法获取ArrayList中的指定位置的元素。
  • 5)计算大小：使用 size() 方法计算ArrayList中的元素数量，也即集合的长度。

import java.util.ArrayList; //导包

public class ListTest {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>(); //创建一个ArrayList集合对象，这种多态的写法更常见，ArrayList继承自List
        list.add("A");
        list.add("A");
        list.add("C");
        System.out.println(list); // 输出结果：[A,A,C] 允许重复
        // 在某个索引位置插入元素
        System.out.println(list.add(2,"MySQL")); //输出结果：[A,A,MySQL,C] 在2号索引添加元素，其它元素后移
        // 根据索引删除元素，并返回被删除元素
        System.out.println(list.remove("MySQL")); //会有返回的输出结果MySQL
        // 根据索引获取元素
        System.out.println(list.get(2)); // C
        // 修改索引位置处的元素，并返回更新前的元素值
        list.set(2,"D"); //序号从0开始，设置位置为2的元素为D，此时会覆盖掉之前的C
        System.out.println(list); // 输出结果：[A,A,D]
        System.out.println(list.size()); // 输出结果：3
    }
}

public class ListDemo {
    public static void main(String[] args) {
        List<String> lists = new ArrayList<>(); //创建一个ArrayList集合对象，这种多态的写法更常见，ArrayList继承自List
        lists.add("A");
        lists.add("B");
        lists.add("C");

        /** 1.for循环 */
        for(int i = 0 ; i < lists.size() ; i++ ) {
            String ele = lists.get(i);
            System.out.println(ele);
        }
        System.out.println("-----------------------");

        /** 2.迭代器 */
        Iterator<String> it = lists.iterator();
        while(it.hasNext()){
            System.out.println(it.next());
        }
        System.out.println("-----------------------");

        /** 3.foreach */
        for(String ele : lists){
            System.out.println(ele);
        }
        System.out.println("-----------------------");

        /** 4.JDK 1.8开始之后的Lambda表达式*/
        lists.forEach(s -> {
            System.out.println(s);
        });
    }
}

(3)LinkedList

1）基本概念

  • 链表（Linked list）并不会按线性的顺序存储数据，而是在每一个节点里存到下一个节点的地址。链表可分为单向链表和双向链表。
  • 与ArrayList相比，LinkedList的增加和删除的操作效率更高，而查找和修改的操作效率较低。LinkedList是对链表的包装，ArrayList是对数组的包装。

2）创建

  • 1)导入类：import java.util.LinkedList;
  • 2)创建对象：
    • 使用无参构造函数创建一个空的LinkedList：LinkedList<String> list = new LinkedList<>();

3）常用API增删改查CRUD

  • 1)添加元素：使用add()方法添加LinkedList中的元素。addFirst() 在头部添加元素，addLast()在尾部添加元素。
  • 2)访问元素：使用get()方法获取LinkedList中的指定位置的元素。
  • 3)更新元素：使用set()方法更新LinkedList中的指定位置的元素。
  • 4)删除元素：使用remove()方法删除LinkedList中的指定位置或指定元素。removeFirst() 移除头部元素，removeLast()移除尾部元素。

public class ListDemo {
    public static void main(String[] args) {
        // 1.用LinkedList做一个队列:先进先出，后进后出
        LinkedList<String> queue = new LinkedList<>(); //这里不能用多态的写法
        // 入队
        queue.addLast("1号");
        queue.addLast("2号");
        queue.addLast("3号");
        queue.addLast("4号");
        System.out.println(queue); // [1号, 2号, 3号, 4号]
        // 出队
        System.out.println(queue.removeFirst());
        System.out.println(queue.removeFirst());
        System.out.println(queue);

        // 2.做一个栈
        LinkedList<String> stack = new LinkedList<>();
        // 压栈
        stack.push("第1颗子弹");
        stack.push("第2颗子弹");
        stack.push("第3颗子弹");
        stack.push("第4颗子弹");
        System.out.println(stack); // [第4颗子弹, 第3颗子弹, 第2颗子弹, 第1颗子弹]
        // 弹栈
        System.out.println(stack.pop()); //pop()方法看源码可以知道本质就是remove()
        System.out.println(stack.pop());
        System.out.println(stack);


    }
}

(4)HashSet

1）基本概念

  • 1)HashSet基于哈希表（HashMap）来实现，是JAVA集合框架中的一种无序集合，即一个不允许有重复元素的集合。
    • 去重复：
      • 对于有值特性的，Set集合可以直接判断进行去重复。
      • 对于引用数据类型的类对象，Set集合会让两两对象，先调用自己的hashCode()方法得到彼此的哈希值（所谓的内存地址），然后比较两个对象的哈希值是否相同，如果不相同则直接认为两个对象不重复。如果哈希值相同，会继续让两个对象进行equals比较内容是否相同，如果相同认为真的重复了，如果不相同认为不重复。
      • 如果希望Set集合认为两个对象只要内容一样就重复了，必须重写对象的hashCode和equals方法。
    • 无序：
      • Set系列集合添加元素无序的根本原因是因为底层采用了哈希表存储元素。
      • JDK 1.8之前：哈希表 = 数组 + 链表 + （哈希算法）
      • JDK 1.8之后：哈希表 = 数组 + 链表 + 红黑树 + （哈希算法）
  • 2)HashSet实现了Set接口。

2）创建

  • 1)导入类：import java.util.HashSet;
  • 2)创建对象：
    • 使用无参构造函数创建一个空的HashSet：HashSet<String> set = new HashSet<>();
    • 使用带初始容量的构造函数创建HashSet：HashSet<String> set = new HashSet<>(cap);

3）常用API增删改查CRUD

  • 1)添加元素：使用add()方法添加HashSet中的元素。注意，HashSet是无序的，即插入的顺序和实际顺序并不保持一致。被添加了两次的元素在集合中也只会出现一次，因为集合中的每个元素都必须是唯一的。
  • 2)访问元素：哈希表没有下标，因此要通过特定方法来访问，例如增强for循环遍历、contains()方法来判断元素是否存在于集合当中。
  • 3)删除元素：使用remove()方法删除HashSet中的元素。
  • 4)计算大小：使用 size() 方法计算HashSet中的元素数量。

public class HashSetDemo {
    public static void main(String[] args) {
        Set<Integer> sets = new HashSet<>(); //创建一个HashSet集合对象，这种多态的写法更常见，HashSet继承自Set
        sets.add(1);
        sets.add(1);
        sets.add(2);
        sets.add(2);
        System.out.println(sets); //会去掉重复的1和2

        // 存储一些自定义类型数据:无序不重复
        Set<Apple> apples = new HashSet<>();
        Apple a1 = new Apple("红富士",59.9 ,"红色");
        Apple a2 = new Apple("阿克苏",39.9 ,"青红色");
        Apple a3 = new Apple("阿克苏",39.9 ,"青红色");
        System.out.println(a1.hashCode()); // 哈希值，相当于是内存地址
        System.out.println(a2.hashCode()); // 哈希值，相当于是内存地址
        System.out.println(a3.hashCode()); // 哈希值，相当于是内存地址
        apples.add(a1);
        apples.add(a2);
        apples.add(a3); //a3和a2内容一样，但本质上是两个对象，内存地址不同，因此a2和a3都会成功添加进集合中，当然，可以重写hashCode()方法
        System.out.println(apples); //输出结果（因为无序，顺序不会和示例结果完全一样）：[Apple{name=阿克苏,price=39.9,颜色=青红色},Apple{name=阿克苏,price=39.9,颜色=青红色},Apple{name=红富士,price=59.9,颜色=红色}]

    }
}

(6)TreeSet

1）基本概念

  • TreeSet是JAVA集合框架中的一种有序集合，但这里的有序是指数据本身的大小上的有序，如数字序列 99 75 35 12。
  • TreeSet基于红黑树数据结构，能够按照元素的自然顺序或指定的比较器进行排序。红黑树是一种自平衡的二叉树，所谓的自平衡是指在插入和删除的过程中，红黑树会采取一定的策略对树的组织形式进行调整，以尽可能的减少树的高度，从而节省查找的时间。
  • TreeSet用于存储不重复的元素，并按照顺序对它们进行排序。它支持高效的插入、删除和查找操作，适用于需要有序元素集合的情况。

4.Map

(1)Map概念

  • 1)特点：
    • (A)双列集合一次需要存一对数据，分别为键和值，键不能重复，值可以重复。键和值是一一对应的，每一个键只能找到自己对应的值。Map集合的特点都是由键决定的。键+值这个整体我们称之为“键值对”或者“键值对对象”，在Java中叫做Entry对象。
    • (B)Map集合的键是无序，不重复，无索引的。
    • (C)Map集合的值无要求。Map集合的键值对都可以为null。
    • (D)Map集合后面重复的键对应的元素会覆盖前面的整个元素。
  • 2)类型：
    • HashMap：元素按照键是无序，不重复，无索引，值不做要求。
    • LinkedHashMap：元素按照键是有序，不重复，无索引，值不做要求。

(2)HashMap

1）基本概念

  • HashMap是一个散列表，它存储的内容是键值对(key-value)映射，用于存储和操作数据。它允许将键与值关联起来，以便通过键来查找和管理与之关联的值。
  • HashMap用于解决需要高效查找、插入和删除数据的问题。它提供了快速的键值查找能力，适用于各种数据映射需求。
  • HashMap 是无序的，即不会记录插入的顺序。

2）创建

  • 1)导入类：import java.util.HashMap;
  • 2)创建对象：
    • 使用无参构造函数创建一个空的HashMap：HashMap<String,Integer> map = new HashMap<>();

  • 6)获取键集合和值集合：使用keyset()方法获取HashMap中的所有键，使用values()方法获取所有值。

import java.util.TreeMap;
import java.util.Comparator;

class Main {
    public static void main(String[] args) {

        //使用自定义比较器创建treemap
        TreeMap<String, Integer> numbers = new TreeMap<>(new CustomComparator());

        numbers.put("First", 1);
        numbers.put("Second", 2);
        numbers.put("Third", 3);
        numbers.put("Fourth", 4);
        System.out.println("TreeMap: " + numbers);
    }

    //创建一个比较器类
    public static class CustomComparator implements Comparator<String> {

        @Override
        public int compare(String number1, String number2) {
            int value =  number1.compareTo(number2);

            //元素以相反的顺序排序
            if (value > 0) {
                return -1;
            }
            else if (value < 0) {
                return 1;
            }
            else {
                return 0;
            }
        }
    }
}
