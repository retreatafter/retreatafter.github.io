1.概述

  • (1)springboot是spring家族(Spring Boot、Spring Framework、SpringData ，Spring Security,Spring Batch , Spring Shell, Spring for Apache Kafka…)的一个子项目，Springboot可以看做是Spring 框架的扩展，SpringBoot 是包含了Spring 、SpringMVC的高级的框架，用于快速构建应用程序，简化开发、提高效率。特点为开箱即用和约定优于配置。
    • 开箱即用：Spring Boot 应用无需从 0 开始，使用脚手架即可创建项目。基础配置已经完成，并且集成了大部分第三方库对象，无需配置就能使用。
    • 约定优于配置：Spring Boot 定义了常用类，包的位置和结构，默认的设置。例如启动类在根包的路径下，使用@SpringBootApplication 注解；创建了默认的测试类Test；controller、service、dao 应该放在根包的子包中；application 为默认的配置文件。
  • (2)脚手架：软件工程中的脚手架是用来快速搭建一个小的可用的应用程序的骨架，将开发过程中要用到的工具、环境都配置好，同时生成必要的模板代码。例如Spring Initializr 是创建 Spring Boot 项目的脚手架。
  • (3)微服务：微服务(Microservices Architecture)是一种架构和组织方法，微服务是指单个小型的但有业务功能的服务，每个服务都有自己的处理和轻量通讯机制，可以部署在单个或多个服务器上。
  • (4)SDK：Software Development Kit 的缩写，软件开发工具包，包括辅助软件开发的依赖（jar包）、代码示例等，都可以叫做SDK。

2.第一个SpringBoot

  • (1)实现需求：基于SpringBoot的方式开发一个web应用，浏览器发起请求/hello后，给浏览器返回字符串 “Hello World”。
    • 创建SpringBoot工程项目，并勾选web开发相关依赖。
      • IDEA中继承了Spring Initializr工具，我们在IDEA中创建SpringBoot项目的时候本质上是使用了Spring Initializr，因此如果IDEA中无法进行创建，可以进入到Spring Initializr 脚手架的 web 地址： https://start.spring.io/ 进行创建。
    • 定义HelloController类，添加方法hello，并添加注解。
    • 测试运行。

package com.seven.controller;

import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

//请求处理类
@RestController
public class HelloController {
    //表示进入/hello这个页面后调用hello()方法，注意如不修改默认占用8080端口
    @RequestMapping("/hello")
    public String hello(){
        System.out.println("Hello World");
        return "Hello World";
    }
}
