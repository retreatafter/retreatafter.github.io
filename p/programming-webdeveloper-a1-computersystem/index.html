1.硬件

  • (1)中央处理器CPU
    • 1)定义：CPU：Central Processing Unit 中央处理单元，负责获取程序指令，对指令进行译码并加以执行。CPU主要由运算器、控制器、寄存器组、内部总线等部件组成。
    • 2)结构：
      • 控制器，作用：控制整个CPU工作，包括运算器。
      • 运算器，作用：算数。
    • 3)双核处理器中所指的双核是指在一个 CPU 中集成两个运算核心以提高运算能力。
  • (2)存储器
  • (3)外设
  • CPU只负责运算，内存只负责数据临时存储，硬盘只负责数据存储。

2.运算器

  • (1)功能：
    • 执行。
    • 算术运算（+、-、×、÷）
    • 逻辑运算（与、或、非）
  • (2)类型：
    • 算术逻辑单元ALU：Arithmetic and logical Unit，作用：运算，实现对数据的算术运算和逻辑运算。
    • 累加寄存器AC：Accumulator Register，作用：工作区，暂存算术运算或逻辑运算的中间运算结果。运算器中至少要有1个累加寄存器AC。
    • 数据缓冲寄存器DR，作用：暂存指令或数据字或操作数。
    • 状态条件寄存器PSW，作用：保存指令执行后的状态。主要是标志作用，像是标志进位、溢出等情况。
  • (3)流程：
    • 例如需要运算3-2，2``3是地址，存储在内存中，需要计算时，累加寄存器AC提供工作区，会将被减数3取出，再从内存储器中取出减数2，得到的结果送回到累加寄存器AC中。

3.指令

  • (1)指令=操作码+地址码
    • 地址码：例如2+3，其中数字2和3为地址，因实际上数据会以地址形式保存，因此这里的数字被称为地址码。
    • 操作码：例如2+3，+为操作码。

4.控制器

  • (1)功能：
    • 控制。
    • 运算器只能完成运算，控制器用于控制整个CPU的工作。不仅要保证程序的正确执行，而且能够处理异常事件。
  • (2)类型：
    • （可访问）指令寄存器IR：Instruction Register，作用：存放当前操作码和地址码。存放的是从内存中取的指令。特点：IR对用户完全透明，即一般用户无法访问。
    • 程序计数器/指令计数器PC：Program Counter，作用：存放/跟踪指令的地址，存放的是指令的地址，还有计数的功能。由于流水线架构的存在，执行指令时，CPU会自动修改PC的内容，使之保持的总是将要执行的下一条指令的地址。注意，是指令的地址而不是指令的地址码，也就是说，PC相当于在判定要走的下一条指令。
    • 地址寄存器AR：Address Register，作用：存放的是cpu访问内存单元的地址。是考虑到内存和CPU之间存在着操作速度上的差异。
    • 指令译码器ID：Instruction Decoder，作用：识别操作码是什么，来判断接下来需要做什么（例如运算，需要判断是+-×/||!中的哪一种），把操作码解析成对应的指令操作。
  • (3)运算顺序：数据缓冲寄存器DR→（可访问）指令寄存器IR→指令译码器ID→运算

5.寻址方式

  • (1)立即寻址：操作数就包含在指令中。
  • (2)寄存器寻址：操作数存放在某一寄存器中，指令中给出存放操作数的寄存器。
  • (3)直接寻址：操作数存放在内存单元中，指令中直接给出操作数所在的存储单元的地址。
  • (4)寄存器间接寻址：操作数存放在内存单元中，操作数所在存储单元的地址在某个寄存器中。
  • (5)间接寻址：指令中给出操作数地址的地址。
  • (6)相对寻址：指令地址码给出的是一个偏移量（可正可负)，操作数地址等于本条指令的地址加上该偏移量。
  • (7)变址寻址：操作数地址等于变址寄存器的内容加偏移量。
  • (8)寻址效率：立即寻址＞寄存器寻址＞直接寻址

问题：存储容量为32K×8bit的芯片构成地址从A0000H到DFFFFH的字节编址(单位b)的内存，至少需要多少块芯片？

(4×16^4)/(2^10)=2^8kb=2^8K × 8bit
需要的芯片数=(2^8K × 8bit)/(32K × 8bit) = 8

7.机器数

  • (1)来源：我们需要得到二进制机器数中负数的相反数来便于计算。存入负数时计算机将存入其补码。
  • (2)原码：8位数，最高位0表示正，1表示负。
  • (3)反码：正数的反码等于原码。负数的反码除符号位（最高位）以外，其余位按位取反。反码出现是为了解决原码不能计算负数的问题，相当于将数轴反向。然而反码存在弊端，负数运算的时候，一旦结果跨0，跟实际结果会有1的偏差。
  • (4)补码：补码出现是为了解决负数计算时跨0的问题，会出现1的偏差是因为在二进制中0 0000000和1 0000000都表示了0，相当于一个数占据了两个位置，解决这个问题，在其反码1 1111111 之上+1，1 1111111 溢出而变成0 0000000，来解决这个问题。
    • 正数（最高位0）的补码与原码和反码相同。
    • 负数补码等于其反码的末尾加1。
    • [ ±0 ]补 = 0 0000000
  • (5)移码：
    • 补码的符号位（最高位）取反。
    • [ ±0 ]移 = 1 0000000
  • (6)特点：补码的补码等于其本身：[ (x)补 ]补=(x)原。
  • (7)二进制 n=8，原码和反码的取值范围为[-127, +127]，也即[-2^(n-1) -1, 2^(n-1) -1];补码和移码的取值范围为[-128, +127]，也即[-2^(n-1) , 2^(n-1) -1]。
  • (1)运算小技巧：十六进制=4位二进制，如 F= 1 1 1 1，其原理是转换成10进制F为15，而二进制每一位代表的分别是 _(8) _(4) _(2) _(1)，也即1+2+4+8=15。

//例题
求某整数16位补码为FFFH，其十进制数为？
解答：首先，正数的原反补相同，负数不相同，所以要先判断该整数是正数还是负数
先将这个十六进制转换为二进制来看，FFFF → 1111 1111 1111 1111，最高位为1，表示这是一个负数
根据特性[ (x)补 ]补=(x)原，1111 1111 1111 1111的反码即除符号位（最高位）以外，其余位按位取反 1000 0000 0000 0000，负数补码等于其反码的末尾加1，因此1000 0000 0000 0001就是原码，其十进制为-2^0=-1（注意，最高位的1表示负，不参与表示的数值）

8.浮点数表示

  • (1)对阶
    • 二进制数N=2^E×F，E称之为“阶”级，F称为“尾数”且是纯小数，如11=0.11×2^2
    • 对阶是小阶向大阶对齐，同时将尾数右移n位。本质是数值小的向数值大的对阶，例0.11×2^2和0.11×2^3对阶时是0.11×2^2转化为0.011×2^3再和0.11×2^3对阶，这样可以降低精度损失。而尾数右移实际上是对应着小数点左移，同样的，0.11×2^2和0.11×2^3对阶，转化为0.011×2^3和0.11×2^3对阶，从0.11×2^2到0.011×2^3是尾数右移了1位（右移的是数），从小数点的角度看是左移。
  • (2)特点：
    • 浮点数的阶码用R位的移码表示，尾数用M位的补码表示，（包括1位阶符和数符），能表示的数值范围为[-1×2^(2(R-1)-1), +(1-2^(-M+1))×2^(2(R-1)-1)]。
    • 阶码E的位数决定数的表示范围，位数越多范围越大；尾数F的位数决定数的有效精度，位数越多精度越高。
  • (3)浮点数的加减法运算顺序：
    • 零操作数检查：当加减0时就无需再进行下述操作，因此是第一步
    • 对阶操作
    • 尾数加减法运算（在这一步中会可能出现阶码溢出）
    • 规格化及舍入处理：使用浮点数时指数经常是负数，后续增加了偏移bias
  • (4)常见的浮点数表示例如1.0001，这个.其实没有任何数学上的含义，仅作为一个视觉上提升观感的标识符，意味着在这之前的数表示正负。
  • (5)规格化：数符与尾数小数点后第一位数字相异为规格化数。数符为0，这个数就是正数，正数补码就是其本身，其最高有效位(阶码使用标准移码的话规格化后尾数最高有效位就是小数点后第一位)必定为1，数符0和最高有效位的1相异。数符为1，这个数就是个负数，求负数的补码有一步叫按位取反(一般来说浮点数可以存储的有效位不会小于6位)，原本最高有效位的1变成了0，所以数符1和最高有效位的0相异。

9.校验

  • (1)码距
    • 码距=2，有检验能力。
    • 码距≥3，才可能有纠错能力。
  • (2)奇偶校验码：在编码中增加一位校验位来使编码中1的个数为奇数（奇校验）或者为偶数（偶校验），目的是使码距变为2。
    • 奇校验：增加一个校验位使1的个数为奇。
    • 偶校验：增加一个校验位使1的个数为偶。
    • 奇偶校验只能检错不能纠错。
    • 若有奇数个数据位出错，能检测出该错误但无法纠正；若有偶数个数据位出错，则无法检验出该错误。
  • (3)海明码：利用多组数位的奇偶性来检错和纠错，既可以检测也可以纠正错误。数据位n，校验位k，公式2^k-1 ＞= n+k成立时说明即可校验。
    • 原理：n数据位数，k校验位数，n+k整个编码长度，k个校验位最多能表示2^k种状态，除去全零状态，实际可用状态为2^k-1。 因此，只有当2^k-1≥n+k时，才能确保每个数据位和校验位在出现错误时都有唯一对应的位置标识。
  • (4)循环冗余校验码CRC：
    • 原理：模2运算，k个数据位后跟r个校验位。
    • 码距必定为2，可检错但但不能纠错。

10.指令集系统计算机

  • (1)精简RISC(Reduce)
    • 研制周期：短
    • 指令种类：少，精简
    • 指令复杂度：低（简单）
    • 指令长度：固定
    • 寻址方式：少
    • 实现（译码）方式：硬布线控制逻辑（组合逻辑控制器）
    • 通用寄存器数量：多，大量（—→是精简RISC的特色，引入了寄存器）
    • 流水线技术：支持
  • (2)复杂CISC(Complex)
    • 研制周期：长
    • 指令种类：多，复杂
    • 指令复杂度：高（复杂）
    • 指令长度：变化
    • 寻址方式：复杂多样
    • 实现（译码）方式：微程序控制技术
    • 通用寄存器数量：一般
    • 流水线技术：支持
  • (3)CISC出现得更早，而后大量发生指令浪费的现象，RISC则在此期间崭露头角，尤其是它的硬布线控制逻辑大幅提高了计算机性能。

11.指令流水线

  • (1)定义：I为输入(Input)，C为计算，O为输出(Output)
  • (2)流水线状态下公式：
    • 流水线时间=第1条的执行时间 + (n-1)×(最长时间段)
    • 加速比=不采用流水线/采用流水线
    • 操作周期，一个完整的指令运行过程。操作周期=最长时间段
    • 吞吐率，单位时间内系统处理的请求数或数据量。吞吐率=1/最长时段，也可以看出，最大吞吐率取决于流水线中最慢一段所需的时间。
    • 执行n条指令的吞吐率=n/(第1条的执行时间 + (n-1)×(最长时间段))
  • (3)指令周期：计算机取出并执行完一条指令所需的全部时间。
  • (4)相似概念-机器周期：指CPU完成某一个规定操作所需的时间。
  • (5)相似概念-时钟周期：定义为主频的倒数，也称节拍，是计算机中最基本的、最小的时间单位。

//例题
某指令流水线由5段组成，第1、3、5段所需时间为Δt，第2、4段所需时间分别为3Δt、2Δt。那么连续输入n条指令时的吞吐率（单位时间内执行的指令个数）TP为？
解答：根据公式，执行n条指令的吞吐率=n/(第1条的执行时间 + (n-1)×(最长时间段))=n/((3Δt+3Δt+2Δt)+(n-1)3Δt)

12.存储器

  • (1)电脑对于数据的存储有短期的存储数据也有长期的固定存储器保存。
  • (2)存储器包括主存、辅存、闪存、缓存。
  • (3)注意区分：常用的虚拟存储器由 “主存-辅存” 两级存储器组成。
  • (4)随机存储器RAM：由于程序指令必须处理迅速且不断进行，短期记忆区的所有定位点以任意顺序被访问，又名随机访问存储器。它们都只能用来存短期数据。
    • 主存：由动态随机存储器DRAM(Dynamic)构成，需要周期刷新。称之为动态正是因为它只能在没电断电之前短暂保留数据。虽然需要周期刷新，但DRAM的功耗较小。
    • 由于存在充电这一“延迟”，静态随机存储器SRAM(Static)应运而生，而它常用于缓存Cache。静态随机存储器是计算机系统中最快的存储器。SRAM的功耗较大。
  • (5)按存储器工作方式区分：
    • 读/写存储器(RAM)(Random Access Memory)：既能读取数据也能存入数据。内存=主存，外存=辅存。硬盘是常见的外存储器，存储类别即辅存。
    • 固定只读存储器(ROM)(Read-Only Memory)：内容只能读出，不能改变。
    • 可编程的只读存储器(PROM)：其中的内容可以由用户一次性地写入，写入后不能改变。
    • 可擦除可编程的只读存储器(EPROM)：其中的内容既可以读出，也可以由用户写入，写入后还可以修改。
    • 电擦除可编程的只读存储器(EEPROM)：与EPROM相似，既可以读出，也可以写入，只不过这种存储器采用电擦除的方式进行数据的改写。
    • 闪速存储器(FM)(Flash Memory)：简称闪存，其特性介于EPROM和EEPROM之间，类似于EEPROM。最常见的例子是U盘。掉电后信息不会丢失，属于非易失性存储器。以块为单位进行删除操作。
  • (6)高速缓冲存储器Cache：链接在主机（主存）和CPU之间的缓冲地带，部分用来存放主存的部分拷贝信息，CPU需要信息时会询问是否存在缓冲中，如果存在则对Cache进行寻址。Cache设计思想是在合理成本下提高命中率，但需要注意的是命中率并不随其容量增大线性地提高。由静态随机存储器SRAM(Static)构成。因Cache是对于程序员透明的，Cache与主存地址的映射/转换是由硬件自动完成。
    • Cache地址映像方式包括全相联、组相联、直接映像，其中全相联映像发生块冲突次数最小。且全相联方式可以实现主存任意一块装入Cache中任意位置，只有装满才需要替换。
  • (7)相联存储器CAM按访问方式分类，是按内容访问的存储器。
  • (8)CPU访问速度从快到慢：CPU内部通用寄存器＞缓存Cache＞主存储器（主存）＞联机磁盘存储器＞脱机光盘、磁盘存储器。简单来说，寄存器直接在CPU内部所以读取最快，IO设备是“外来”的因此慢，所以CPU与I/O接口交换信息采用异步传输方式。

13.中断

  • (1)计算机在执行程序过程中，当遇到急需处理的事件时，暂停当前正在运行的程序，转去执行有关服务程序，处理完后自动返回源程序，这个过程称为中断。
  • (2)特点：
    • 中断向量提供中断服务程序的入口地址。这些中断向量最终会汇集为中断向量表。
    • 中断响应时间是指发出中断请求开始，到进入中断服务程序。
    • 对于主程序，会有一个保存现场的行为，处理完中断事务后，返回执行的源程序。这也是中断的目的。
    • 实现多级中断嵌套，使用堆栈保护断点和现场最有效。
  • (3)中断分类
    • 1)软中断和硬中断
      • 硬中断是由外部硬件设备生成的信号，如键盘、鼠标、网络适配器、磁盘驱动器，主要用于处理实时事件，具有较高的优先级。同样的，寄存器溢出、电源故障也属于硬中断。也有将硬中断默认为中断的。
      • 软中断是由正在运行的程序或操作系统内部生成的特殊事件，（与CPU有关），通常用于请求操作系统的服务和功能。如除零异常、INT指令便是软中断。也有将软中断称为异常的。
    • 2)可屏蔽中断和不可屏蔽中断
      • 不可屏蔽中断源一旦提出请求，cpu必须无条件响应。电源掉电是不可屏蔽中断。
      • 可屏蔽中断源的请求，cpu可以响应，也可以不响应。由I/O设备提出的中断请求是可屏蔽中断。
  • (4)可剥夺方式与中断方式的区分：在计算机系统中，若 P1 进程正在运行，操作系统强行撤下 P1 进程所占用的 CPU，让具有更高优先级的进程 P2 运行，这种调度方式称为可剥夺方式。

14.输入输出(I/O)控制方式

  • (1)定义：此处所指I/O即外设与主机的交互方式。
  • (2)程序查询方式
    • 1)CPU和I/O（外设）只能串行工作，CPU需要一直输询检查，长期处于忙等状态，CPU利用率低。
    • 2)一次只能读/写一个字。
    • 3)由CPU将数放入内存。
    • 4)例子：会使用while循环一直查询，即便设备未在使用也在工作。
  • (3)中断驱动方式
    • 1)I/O设备通过中断信号主动向CPU报告I/O操作已完成。
    • 2)CPU和I/O可并行工作。
    • 3)CPU利用率得到提升。
    • 4)一次只能读/写一个字。
    • 5)CPU每次会检查数据，CPU参与数据传输过程，由CPU将数据放入内存。
    • 6)例子：键盘，当每一次输入完成后会发出中断信号。
  • (4)直接存储器存取方式DMA
    • 1)CPU和I/O可并行工作。
    • 2)仅在传送数据块的开始和结束时才需CPU干预，其余过程CPU不参与。
    • 3)由I/O（外设）直接将数据放入内存（主存）或者相反。DMA在主存和外设之间建立了直接的数据通路。
    • 4)一次读写的单位为“块”。
    • 5)发出的数据地址是主存物理地址。
    • 6)CPU是在一个总线周期结束时响应DMA请求的。采用DMA方式传送数据时，每传送一个数据都需要占用一个存储周期。
    • 7)例子：磁盘。

15.总线结构

  • (1)定义：用于CPU、主存、外设部件（类似u盘硬盘） 的连接。一般来说，任何连接两个以上电子元器件的导线都可以称为总线。总线结构便于实现系统的积木化构造，同时可以减少信息传输线的数量。
  • (2)类型：数据总线、地址总线、控制总线。
    • 数据总线（DB）：用来传送数据信息，是双向的。
    • 地址总线（AB）：用于传送CPU发出的地址信息，是单向的。
    • 控制总线（CB）：用来传送控制信号、时序信号和状态信息等，双向线表示。
  • (3)并行总线与串行总线
    • 并行总线——多车道，并行总线适合近距离高速数据传输：PCI（Peripheral Component Interconnect 允许在计算机中安装多个扩展卡）、SCSI（Small Computer System Interface 通用的I/O总线标准）
    • 串行总线——单车道，串行总线适合长距离数据传输：USB、以太网、SATA（Serial Advanced Technology Attachment 主要用于硬盘和固态硬盘）
  • (4)单总线和专用总线
    • 单总线结构在一个总线上适应不同种类的设备，设计简单但性能低。
    • 专用总线在设计上可以与连接设备实现最佳匹配。

16.计算机安全

  • (1)安全威胁：
    • 拒绝服务：对信息或其它资源的合法访问被无条件地拒绝，或者推迟与时间密切相关的操作。
    • 授权侵犯：为某一特权使用一个系统，却将该系统用作其它未授权的目的。
  • (2)加密技术
    • 1)对称加密/私有/共享密钥加密：（因为是同一把钥匙所以这把钥匙算是私有的）
      • 特点：适合对大量明文消息加密传输，加密和解密是同一把密钥。速度快。
      • 加密算法：DES（数据加密标准，异或轮函数，置换块加密分组加密，主要采用替换和移位的方法加密）、AES（高级加密标准，升级版DES，基于排列和置换运算。排列是对数据重新进行安排，置换是将一个数据单元替换为另一个数据单元）、3DES（又称TDEA，3轮DES，效果相当于将密钥的长度加倍）、IDEA（国际加密算法，在DES算法的基础上发展起来的，类似于3重DES）、RC4（流密码，字节加密，S表非线性变换）、RC-5（RC-5是在RCF2040中定义的，RSA数据安全公司的很多产品都在使用RC-5）。
    • 2)非对称加密/公开密钥加密：（从行为上来说是公钥加密后私钥才解密，也是为了和对称加密区分，因此叫做公开密钥加密）
      • 特点：有公钥和私钥两把密钥。用公钥加密只能私钥解密，私钥加密公钥解密。速度慢。两者是一对，如果公开密钥对数据进行加密，只有用对应的私有密钥才能解密；如果用私有密钥对数据进行加密，只有用对应的公开密钥才能解密。
      • 加密算法（RED）：RSA（质数）、ECC（椭圆曲线）、DSA（digital数字签名，离散对数）
      • 公钥体系中，私钥用于解密和签名，公钥用于加密和认证。简单来说谁需要“证明”自己就用私钥，因为公钥所有人都有，私钥则只有己方有。
    • 3)其它重要加密算法
      • 摘要算法MD5：128位散列值。
      • 安全散列算法SHA-1，属于哈希算法

  • (3)认证技术
    • 报文摘要，将发送的明文进行Hash算法后得到摘要放在密文后一起发送过去，与接收方解密后的明文进行相同的Hash算法得到的摘要进行对比。作用：防止内容的篡改。
    • 数字签名，数字签名是用私钥签名，公钥验证，一般是对信息摘要进行签名。发送方用自己的私钥对摘要进行签名（加密）得到数字签名放在密文后一起发送过去，接收方用发送方的公钥对数字签名进行验证（解密）。作用：防止对象的假冒。保护了对象的真实性。
    • 数字证书，可以视作数字签名多出一个中间方负责监管。用户向CA机构（权威机构）申请数字证书将个人信息和公钥发给CA机构，CA机构颁给用户数字证书，数字证书用CA的私钥进行签名（加密），用CA的公钥验证（解密）数字证书得到用户的公钥。
    • 数字证书主要是用来对用户身份进行认证，而数字签名主要用于确保消息不可被否认。
    • 加密技术，公钥可用于加密和认证，私钥可用于解密和签名。

17.可靠度R

  • 串联系统R = R1·R2· … Rn
  • 并联系统R = 1-(1-R1)(1-R2) … (1-Rn)
