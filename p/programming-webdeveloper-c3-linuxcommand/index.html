1.概述

  • (1)“程序”在Windows叫做"服务"（service），在Linux叫做"守护进程"（daemon）。
  • (2)使用Linux系统，在实际工作中，都会选用命令行来执行操作，而不选用图形化界面，在VMware上，我们可以使用快捷键Ctrl+ALT+f2切换至命令行交互界面，也可以使用VMware中带有的“终端”系统工具模拟器使用命令行。
  • (3)命令语法：命令 [[-短选项参数]/[--长选项参数]] 其它。
  • (4)操作系统提供了命令对应的手册，命令：man [有疑问的命令]（Manual）；非系统命令也可以使用命令本身提供的帮助信息命令：[有疑问的命令] --h或[有疑问的命令] --help。
  • (5)可使用快捷键Ctrl+C中断任何命令。

2.开关机

  • (1)Linux开机后将进入到用户登录界面，不同的用户拥有不同的权限，最高权限账户为 root。
  • (2)Linux大多是在云服务器上部署，很少会需要关机。关机指令为shutdown。
    • 防止数据的丢失，在关机前执行数据同步指令sync。

3.磁盘管理

(1)概念

  • 1)命令语法：df [-参数] [目录或文件名]
    • 功能：列出文件系统的整体磁盘使用量。
    • 参数- h：以GBytes，MBytes，KBytes等格式显示已用、可用容量（如不使用，默认单位Byte）。
  • 2)命令语法：du [-参数] 文件或目录名称
    • 功能：检查磁盘空间使用量。
    • 参数- h：以GBytes，MBytes，KBytes等格式显示已用、可用容量（如不使用，默认单位Byte）。

(2)特点

  • 系统初期，使用量最大的是用户目录，因为很多文件和程序都在这里面。

(3)磁盘挂载

  • Linux 没有提供设备管理器，使用软驱、光驱、磁盘、打印机等外部设备都需要用户使用命令进行手动挂载。
  • 挂载命令语法：mount [-参数] 外部设备位置 挂载点位置。
  • 卸载命令语法：umount [-参数] 挂载点位置。
  • 参数- f（force）：不会出现警告信息，强制移动。

4.目录管理

  • 1)绝对路径与相对路径：
    • 绝对路径，由根目录 / 写起，例如：/usr/share/doc
    • 相对路径，相对于当前，./为当前目录，..为上一级，../..表示上上一级目录，以此类推。cd命令发起返回目录，cd ..为返回上一级目录。例如由 /usr/share/doc 要到 /usr/share/man 底下时，可以看出需要返回上一级，这时可以由命令：cd ../man完成。
    • Windows以磁盘符开头，Linux中以/开头，因此看到/开头的路径可判断为绝对路径，例如/home/retreatafter。
  • 2)列出目录 ls（list）
    • 命令语法：ls [-参数] [目录或文件名称]。
    • 参数- a（all）：查看全部的文件，包括隐藏文件（开头为 . 的文件）。
    • 参数- l（long）：列出所有的文件包含文件的属性和权限，不包括隐藏文件。
    • 命令可以组合使用，命令- al相当于命令a + 命令l。
  • 3)切换目录 cd（Change Directory）
    • 命令语法：cd [相对路径或绝对路径]。

  • 4)显示当前用户所在的目录 pwd（Print Working Directory）
  • 5)创建一个新的目录（文件夹） mkdir（Make Directory）
    • 命令语法：mkdir [-参数] 目录名称。
    • 单纯的rmdir命令仅能创建一个空目录。
    • 参数- p（parent）：创建多层目录。将指定的目录（文件夹）及其上一级目录一并显示，类似于递归，例如mkdir test1/test2/test3/test4就可以直接创建文件夹1~4，其中文件夹4的上一级是文件夹3，文件夹3的上一级是文件夹4，文件夹2的上一级是文件夹1。如果不加入- p参数，则无法直接创建多层目录。
  • 6)删除一个空的目录（文件夹） rmdir（Remove Directory）
    • 命令语法：rmdir [-参数] 目录名称。
    • 单纯的rmdir命令仅能删除空目录，如果目录（文件夹）内存在文件，需要删除文件，再删除清空的目录，或使用递归删除目录参数- p。
    • 参数- p（parent）：删除多层目录。
  • 7)复制文件或目录 cp（Copy）
    • 命令语法：cp 来源档(source) 目标档(destination)。
    • 参数- r（roll）：递归复制目录。
    • 如果文件重复，将出现覆盖询问，y(yes)确认，n(no)拒绝。
  • 8)移除文件或目录 rm（Remove）
    • 命令语法：rm [-参数] 文件或目录。
    • 参数- f（force）：忽略不存在的文件，不会出现警告信息，相当于强制删除。
    • 参数- r（roll）：递归删除目录。
    • 参数- i（）：互动模式，在删除前会询问使用者。
    • 删库：rm -rf /，将删除系统中所有文件。
  • 9)移动文件或目录及重命名mv（Move）
    • 命令语法：mv 来源档(source) 目标档(destination)。
    • 参数- f（force）：不会出现警告信息，强制移动。
    • 参数- u（）：只替换已经更新过的文件。

5.文件基本属性

(1)查看内容

  • 1)由第一行开始显示文件内容cat
    • 使用示例：cat /etc/sysconfig/network-scripts/ifcfg-eth0
    • 参数- n（number）：控制显示内容的行数。
  • 2)由最后一行开始显示文件内容tac
  • 3)显示行号nl
    • 命令语法：nl [-参数] 文件。
  • 4)一页一页翻动more
    • 命令语法：more [-参数] 文件。
    • 参数- f ：实时显示出档名以及目前显示的行数。
  • 5)一页一页翻动且允许向前翻动less
    • 命令语法：less [-参数] 文件。
    • 出现“END”后需要按“q”退出。
  • 6)仅显示文件前面几行head
    • 命令语法：head [-n number] 文件。
    • 参数- n（number）：控制显示内容的行数。
    • 使用示例：head -n 20 /etc/csh.login，其中20表示显示20行。
  • 7)仅显示文件最后几行tail
    • 命令语法：tail [-n number] 文件。
    • 参数- n（number）：控制显示内容的行数。
    • 参数- f ：实时显示最新追加的内容，监控文件变化

(2)Linux中的“链接”概念

  • 1)硬链接
    • 多个文件名指向同一个文件，例如B 是 A 的硬链接，则A 和 B 对文件系统来说是完全平等的，删除其中任何一个都不会影响另外一个的访问。
    • 使用示例：ln f1 f2，即创建文件f1的一个硬链接文件f2。
  • 2)软链接/符号链接
    • 类似于Windows中的“快捷方式”，例如B 是 A 的软链接，则删除B后，A虽然存在，但指向的是一个无效的链接。
    • 使用示例：ln -s f1 f2，即创建文件f1的一个软链接文件f2。

6.文本编辑Vim

(1)概念

  • 1)编辑器的核心行为即：查看内容，编辑内容，保存内容。在命令行界面下，最常用的文本编辑是Vi/Vim，其中Vi是 Linux操作系统中最通用的文本编辑器，Vim编辑器是Vi的增强版，相较于Vi，提供了代码高亮等功能，两者用法上完全兼容。几乎所有的Linux发行版都已经预装了Vi编辑器。
  • 2)基础语法：vim 文件名。需要注意的是，如果这个文件存在，会继续修改这个文件，如果（此路径下）不存在这个文件，将新建新文件。
  • 3)Vim编辑器有不同的工作模式，在不同模式下，可执行不同的操作。

(2)工作模式

  • 1)命令模式Command Mode
    • 启动Vim后默认进入到命令模式。
    • 功能：此状态下键盘动作会被Vim识别为命令，而非输入字符。例如此时按下“i”，并不会输入一个字符，而是会执行命令i。
    • 常用命令：i或a或o切换到输入模式，:或/切换到底线命令模式。
  • 2)输入模式Insert Mode
    • 功能：编辑文件。键盘动作代表输入文本或代码。
    • 常用按键：
      • 模式切换：
        • Insert：切换光标为输入/替换模式，光标将变成竖线/下划线。
        • ESC：退出输入模式，切换到命令模式。
      • 基本操作：
        • 字符按键以及Shift组合：输入字符
        • ENTER：回车键，换行。
        • 上下左右方向键：在文本中移动光标。
        • Page Up/Page Down：上/下翻页
      • 光标操作：
        • HOME/END或shift+6(^)/shift+4($)：移动光标到行首/行尾。
        • shift+g/gg：移动光标到页首/页尾。
      • 复制粘贴：
        • yy：复制光标当前行。
        • yw：复制光标当前词。
        • p：粘贴。
      • 删除：
        • BACK SPACE：删除光标前一个字符。
        • DEL：删除键，删除光标后一个字符
        • dd：删除光标当前行。
        • d n d：删除当前光标所处行及其以下共n行。
        • x：删除当前光标处的一个字符。
  • 3)底线命令模式（Last line mode）
    • 功能：命令模式只有一些最基本的命令，因此仍要依靠底线命令行模式输入更多命令。
    • 如果当前正处于输入模式，需要ESC退出输入模式。
    • 常用命令：q退出程序（quit），w保存文件（write）。

(3)按键说明

  • Vim的按键对应的功能有很多，有需要的时候再查询即可。

7.权限系统

(1)用户管理

1）概念

  • 任何一个要使用系统资源的用户，都必须首先向系统管理员申请一个账号，然后以这个账号的身份进入系统。
  • 每个用户账号都拥有一个唯一的用户名和各自的口令。

2）增

  • Linux中一切皆文件，添加用户的本质是往某一个文件中写入用户的信息。
  • 添加用户命令语法：useradd -参数 用户名。
  • 参数- m（）：自动创建这个用户的主目录 例如添加用户retreatafter，则会自动创建retreatafter文件夹用于放该目录文件，位置默认/home/retreatafter。
  • 参数- G（group）：分配用户的组。

3）删

  • 删除用户命令语法：userdel -参数 用户名。
  • 参数- r（）：将用户主目录一并删除。

4）改

  • 功能：修改用户有关属性，如用户号、主目录、用户组、登录Shell等。
  • 删除用户命令语法：usermod [-参数] 用户名。（Modified）

5）切换用户

  • 切换用户命令语法：su 用户名。
  • #表示超级用户（root）。
  • $表示普通用户。

6）账号管理

  • 一般来说仅超级用户root账号能够有创建账号权限。
  • 设置密码命令语法：passwd [-参数] 用户名。
  • 参数- l（lock）：锁定口令，即禁用账号。

(2)用户组管理

1）概念

  • 组的增加、删除和修改实际上就是对/etc/group文件的更新。

2）增

  • 命令语法：groupadd 用户组名。
  • 参数-g（groupID）：用于指定用户组id。
  • 使用实例：groupadd -g 77 groupa，进入到/etc/group可以看到组goupa的id是77。

3）删

  • 命令语法：groupdel 用户组名。

4）改

  • 功能：修改用户组的权限、信息、名称等。
  • 命令语法：groupmod [-参数] 用户组。
  • 参数- g（groupID）：指定新的id。使用示例 groupmod -g 新id 用户组。
  • 参数- n（name）：修改用户组名字。使用示例 groupmod -n 新名称 旧名称。

(3)文件权限

1）属

  • Linux中，可以使用ll或者ls –l命令来显示一个文件的属性以及文件所属的用户和组。
  • 文件均用10个字符表示。
    • 第一个字符（第0位）代表这个文件是目录、文件或链接文件等等，如果为“d”，表示这是目录；为“l”，表示为链接文档。
    • 接下来的9个字符每3个字符为一组，且均为“rwx”三个参数的固定组合。其中，“r"代表可读(read)、“w"代表可写(write)、“x"代表可执行(execute)，如果没有相应权限的，用减号“-”表示。
    • 第一组（2-4）（第1-3位）字符表示属主权限，该文件的所有者的权限，相当于ROOT账户权限；第二组（5-7）（第4-6位）字符表示属组权限，所有者的同组用户的权限，在Linux系统中，用户是按组分类的，一个用户属于一个或多个组；第三组（8-10）（第7-9位）字符表示其它用户权限。三组权限对一个用户而言，结果取并集。

2）修改属

  • 1)更改文件属组chgrp（Change Group）
    • 命令语法：chgrp [-R] 属组名 文件名
    • 参数- R（）：递归更改文件属组。
  • 2)更改文件属主/更改文件属组chown（Change Own）
    • 命令语法：chown [–R] 属主名 文件名
  • 3)更改文件9个属性chmod（Change Mode）
    • Linux文件属性有两种设置方法，一种是通过数字，一种是通过符号。数字来代表各个权限，r:4 w:2 x:1，例如770就表示rwxrwx—。
    • 示例：chmod 770 filename

8.进程管理

(1)概念

  • 和Windows系统一样，Linux的每一个进程也都拥有进程号（PID）。且每一个进程之上有一个家长进程。
    • USER：启动该进程的用户。
    • PID：进程ID。
    • %CPU：该进程占用CPU资源的百分比。
    • %MEM：该进程占用物理内存的百分比。
    • COMMAND：产生此进程的命令名。

  • 进程的存在方式有两类：前台进程和后台进程，前台进程一旦关闭服务后进程则停止，一般来说，基本的程序都是前台运行的，服务都是后台运行的。

(2)查看进程

  • 1)查看当前系统中正在执行的各种进程的信息。
    • 命令语法：ps [-参数]。（Process Status）
    • 参数- a：显示当前终端所有的前台进程信息。
    • 参数- u：以用户友好的方式打印进程信息。
    • 参数- x：显示后台运行进程的参数。
    • 通常连用- aux参数查看所有进程，且运用管道符|和命令grep（查找文件中符合条件的字符串）实现查看特定进程，命令语法：ps -aux|grep 字符串。使用示例：ps -aux|grep mysql，即可查看mysql相关进程。
  • 2)查看进程的家长进程PPID。
    • 命令语法：pstree [-参数]。
    • 参数- p：显示家长进程号PPID。
    • 参数- u：显示用户组。
  • 3)结束进程/杀掉进程
    • 一般来说很少会需要手动结束进程，通常是运行代码出现死循环等问题时才会需要手动结束进程。
    • 命令语法：kill -9 进程号。

9.压缩归档

(1)zip文件压缩

  • 命令语法：zip [-参数] XXX.zip 文件或路径
  • 参数-r（recursive）：压缩整个目录。

(2)zip文件解压缩

  • 命令语法：unzip [-参数] XXX.zip
  • 参数-d（directory）：指定解压后文件的存放目录。

(3)tar文件压缩与解压缩

  • 压缩打包命令语法：tar [-参数] -c -f 包名 文件1 文件2 文件3 ...
  • 解压缩命令语法：tar [-参数] -x -f 包名 -C 指定目录
  • 参数-c（create）：打包。
  • 参数-x（extract）：解包。
  • 参数-z（gzip）：打包的同时进行压缩（解包的时候进行解压）。
  • 参数-v（verbose）：打包或解包时显示正在处理的文件信息。
  • 参数-f（file）：指定打包后的文件名后者要解包的文件名。
  • 参数-C：解包到指定目录。

10.安装应用

(1)RPM离线安装

  • 1)RPM（RedHat Package Manager）是RedHat软件包管理工具，在基于 RedHat 的 Linux 发行版中广泛使用。软件包以.rpm结尾，类似于Windows系统中的exe文件。
  • 2)安装软件包命令语法：rpm [-参数] 软件包路径
    • 参数-i（install）：安装。
    • 参数-v（verbose）：显示详细信息。
    • 参数-h（hash）：进度条。
  • 3)查看软件包命令语法：rpm [-参数]
    • 参数-q（query）：查询模式。
    • 参数-a（all）：查看所有。
  • 4)卸载软件包命令语法：rpm -e 软件包名

(2)Yum在线安装

  • 1)YUM（Yellowdog Updater Modified）是一个Linux软件包管理器。基于RPM包管理，能够从指定的服务器自动下载RPM包并且安装，并且可以自动处理依赖关系，并且一次安装所有依赖的软件包，无须繁琐地一次次下载、安装，该功能类似在JAVA中使用Maven工具从远程仓库中下载依赖一样,可以自动处理依赖关系。
  • 2)安装软件包命令语法：yum [-参数] install 软件包名
    • 参数-y（yes）：对所有提问都回答“yes”。
    • 在线安装时，还需要配置对应的远程仓库。
  • 3)卸载软件包命令语法：yum remove 软件包名
