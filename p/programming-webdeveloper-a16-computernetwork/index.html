1.网络

  • (1)计算机网络是由多台计算机组成的系统，它实现了远程通信、远程信息处理和资源共享。

2.OSI七层网络参考模型

(1)网络互连设备

  • 1)OSI概念：OSI(Open System Interconnection Reference Model)，开放式通信系统互联参考模型，是国际标准化组织提出的一个试图使各种计算机在世界范围内互连为网络的标准框架。
  • 2)物理层：数据单元为比特(0和1)，硬件设备为中继器(Repeater)、集线器(Hub)。
    • 集线器(Hub)：可以看作是一种特殊的多路中继器。集线器将多个主机连接在同一段物理介质下，功能为信息转发，具体为接收一个主机发来的信息，将此信息转发给所有连接的设备。缺点在于转发给所有，但并不是所有接收到信息的设备实际上都需要这个信息。
  • 3)数据链路层：数据单元为帧，硬件设备为网桥(Bridge)、交换机(Switch)。
    • 交换机(Switch)：交换机是多端口的网桥。与MAC地址相关。根据信息自带的MAC地址来判断信息该发给哪些主机。（交换机被归类到数据链路层属于早期分类问题，因其涉及传输数据）
    • 以太网交换机：根据数据帧中的mac地址进行数据帧转发。
    • 交换机VLAN：广播域、划分内外网、内网互访。
    • 附：MAC地址(Media Access Control Address)也称为物理地址、硬件地址，用来唯一标识一个网卡，就像电脑的身份证，在命令行(cmd)中通过命令ipconfig /all找到物理地址行就能看到本机的MAC地址。
  • 4)网络层：数据单元为数据包，硬件设备为路由器(Router)。
    • 路由器(Router)：与IP地址相关。集线器和交换机都属于在小范围网络内工作，即局域网络LAN，而路由器查看IP地址来判断信息是否属于自己负责的LAN，如果是，交换机再按照MAC地址来分发数据，如果不是，则继续转发。因此路由器的工作范围在广域网WAN。
  • 5)（了解）调制解调器光猫：功能为信号转换，与信号转发无关。路由器之间传输的是光信号，主机能够读取的是电信号，因此需要一个“转换器”，也就是光猫，将光信号和电信号互相转换。
  • 6)上述设备在WAN网络中具体的作用流程为，例如发送方电脑A需要发送信息给接收方电脑B，首先信息转发给A连接的中继器/交换机，再转发给A连接的路由器，路由器将信息转发给光猫a，将信号转换为光信号，光猫b将信息转换，B连接的路由器识别信息判断到信息属于自己负责的LAN，信息转到B连接的交换机，交换机再按照MAC地址来分发数据给接收方电脑B。
  • 7)传输层：数据单元为数据段。
  • 8)应用层：数据单元为协议数据单元PDU()。

(2)广播域和冲突域

  • 1)冲突域：同一时间内只能有一台设备发送信息的范围。集线器的所有端口组成一个冲突域。
  • 2)广播域：如果站点发出一个广播信号，所有能接收收到这个信号的设备范围称为一个广播域。交换机的各个端口形成一个广播域。
  • 3)物理层无法隔离冲突域和广播域，数据链路层可以隔离冲突域，无法隔离广播域，网络层可以隔离冲突域和广播域。

                   路由器

解答：根据性质，物理层无法隔离冲突域和广播域，数据链路层可以隔离冲突域，无法隔离广播域，故集线器连接的所有主机有1个广播域，1个冲突域，交换机连接的所有主机有1个广播域，4个冲突域（每一个端口都是1个冲突域）

(3)TCP/IP协议簇及端口

  • 1)分割线——传输层：TCP(Transmission Control Protocol)与UDP(User Datagram Protocol)
    • (A)UDP协议：无连接，不可靠，因为数据传输只管发送，不用对方确认，因此可能会有丢包现象。一般用于视频、音频数据传输。UDP不够可靠但是快速，开销较小。基于IP协议。
    • (B)TCP协议：可靠连接，因为有验证机制,每发送一个数据包，都要求对方回复确认；初始建立连接，有三次握手机制。基于IP协议。
      • TCP运用的流量控制协议是可变大小的滑动窗口协议。
      • TCP的序号单位是字节，传输格式为报文。
  • 2)更上层——应用层：
    • (A)安全相关
      • (a)HTTP(Hypertext Transfer Protocol)超文本传输协议：超文本传输协议，用于上网。使用SSL加密后的安全网页协议为HTTPS。功能为Web服务调用，传输网页数据，属浏览器与服务器的交互。也就是说，WEB服务调用使用的端口号是HTTP使用的端口号，为80。
        • HTTP的一次请求过程：在浏览器中输入URL（网址），并按下回车键 → 浏览器向DNS服务器发出域名解析请求并获得结果（IP地址） → 根据目的IP地址和端口号，与服务器建立TCP连接 → 浏览器向服务器发送数据请求 → （数据处理）服务器将网页数据发送给浏览器 → 通信完成，断开TCP连接 → 浏览器解析收到的数据并显示。
    • (B)远程登录或访问相关：
      • (a)Telnet(Telecommunication Network)远程登陆协议：远程连接协议。在远程计算机上运行程序，将相应的屏幕显示传送到本地机器，并将本地的输入送给远程计算机。
      • (b)DNS(Domain Name System)域名系统（域名和IP地址相互映射分布式数据库）：域名解析协议，将域名解析为IP地址。
      • (c)DHCP(Dynamic Host Configuration Protocol)动态主机配置协议：动态分配IP地址协议。
        • DHCP客户端可从DHCP服务器获得本机IP地址、DNS服务器地址、DHCP服务器地址、默认网关地址。
        • 无响应主机获取的IP地址属于网络169.254.x.x，即169.254.x.x是Windows系统在DHCP信息租用失败时自动给客户机分配的IP地址。对应的，Linux无效地址：0.0.0.0。
      • (d)SNMP(Simple Network Management Protocol)简单网络管理协议：用于网络设备的管理和监控，必须以管理员的身份登录才能完成配置。
        • 其报文封装在UDP中传送。
    • (C)文件传输相关
      • (a)FTP(File Transfer Protocol)文件传输协议：可靠的文件传输协议，持双向传输，提供用户认证功能。
        • 默认情况下，FTP服务器的控制端口为21，上传文件时的端口为20。
      • (b)TFTP(Trivial File Transfer Protocol)简单文件传输协议：不可靠的小文件传输协议，通常用于小型设备或系统的引导过程中。
    • (D)电子邮件相关
      • (a)SMTP(Simple Mail Transfer Protocol)电子邮件协议：邮件传输协议，邮件报文（文本）采用ASCII格式表示。发送邮件。
        • MIME(Multipurpose Internet Mail Extensions)，能够弥补SMTP的缺点即不能用来传送非ASCII码文本和非文字性附件，可以使电子邮件附加多媒体数据。
      • (b)POP3(Post Office Protocol - Version 3)电子邮件协议：邮件传输协议，邮件报文采用ASCII格式表示。用于从邮件服务器下载邮件，即接收邮件。
      • (c)IMAP(Internet Message Access Protocol)：电子邮件存储协议，它允许用户从邮件服务器上访问和管理邮件。
  • 3)更底层——网络层：
    • (A)IP(Internet Protocol)互联网协议：用于屏蔽下层物理网络的差异，为上层提供统一的IP数据报。
      • 网络连接不可用时通常使用的目的主机IP地址为127.0.0.1。
      • 关于IP数据报文的传输，有广播、单播、组播、任播4种方式。单播(Unicast) 是一种一对一的传输方式，数据从单一源发送到唯一的目的地。广播(Broadcast) 是一种一对多的传输方式，数据被发送至局域网内的所有主机。组播/多播(Multicast) 是一种介于单播和广播之间的传输方式。它允许数据在一对一组的基础上传输，即数据被发送至预先定义的多个接收者（可视为拉挑选过的受众小群）。任播(Anycast) 是将一个数据包发送到一个指定的设备集合（通常是距离发送端最近的设备），而不指定任何目的地地址（可视为公司大群）。
    • (B)RIP(Routing Information Protocol)路由信息协议。
    • (C)ICMP(Internet Control Message Protocol)互联网控制报文协议：因特网控制信息协议，用来检测网络通信是否顺畅。由于IP传送的数据报可能丢失、重复、延迟或乱序，因此IP需要一种避免差错并在发生差错时报告的机制。ICMP就是一个专门用于发送差错报文的协议，其数据单元封装在IP数据报中传送 。著名的ping工具就是利用ICMP报文进行目标是否可达测试。
    • (D)IGMP(Internet Group Management Protocol)网际组管理协议。
    • (E)ARP(Address Resolution Protocol)地址解析协议：将IP地址转换为物理地址（MAC地址）。
    • (F)RARP(Reverse Address Resolution Protocol)反向地址解析协议：将物理地址（MAC地址）转换为IP地址。
  • 4)更更底层——数据链路层：
    • (A)CSMA/CD(Carrier Sense Multiple Access With Collision Detection) ，载波监听多点接入 / 碰撞检测

(4)协议间区分

  • 1)分割线——传输层：TCP与UDP
    • TCP端口号6，UDP端口号17
    • 作用：建立连接进行可靠通信。
    • 共有的功能：端口寻址。
    • 差异：TCP(Transmission Control Protocol)，会进行3次握手，慢但是稳定。UDP(User Datagram Protocol) 不稳定但是快，即便损失一点数据也不会有很大影响，例如视频通话VoIP。
  • 2)更上层——应用层：
    • 1)SMTP与POP3
      • 作用：电子邮件。都采用TCP端口（不允许数据丢失）。也即如果一台服务器开放了25和110端口，那么这台服务器可以提供E-Mail电子邮件服务。
      • 差异：SMTP(Simple Mail Transfer Protocol)，用于发送邮件，发送的报文采用ASCII格式表示，缺点为不能传递非ASCII码文本和非文字性附件。POP3(Post Office Protocol - Version 3)，用于接收邮件，不同步其它设备。
      • 共性：电子邮件(E-mail)系统基于客户端(Client)/服务器(Server)模式。
  • 3)更底层——网络层：
    • 1)ARP与RARP
      • 差异：ARP(Address Resolution Protocol)，属于网络层协议，作用为实现IP地址转换成Mac地址。广播传送请求(Request)，单播传送响应(Response)。RARP(Reverse Address Resolution Protocol)，将Mac地址转换成IP地址。

3.URL

  • (1)URL(Uniform Resource Locator)统一资源定位符格式：协议名://主机名.域名.域名后缀.域名分类/目录/网页文件，可简记为协议://ip地址:端口号/项目名/资源例如https://www.ruankao.org.cn/sign/welcome，www是主机名，ruankao是域名，org是组织模式的域名后缀，cn是地理模式的域名分类（.org.cn都是域名的一部分）。
  • (2)域名分类
    • 组织模式
      • com 商业组织
      • edu 教育机构
      • gov 政府机构
      • mil 军事部门
      • net 主要网络支持中心
      • org 各类组织机构/非盈利组织
      • int 国际组织
    • 地理模式
      • cn 中国
      • mo 澳门

4.浏览器

  • (1)本地主机DNS域名查询的次序：本地hosts文件 → 本地DNS缓存 → 本地DNS服务器 → 根域名服务器。
  • (2)主域名服务器查询域名的次序：本地缓存 → 本地hosts文件 → 本地数据库 →转发域名服务器。

5.Internet地址

  • (1)IP地址
    • 作用：终端节点的逻辑定位。
    • IP地址分四段，每段八位，共32位二进制数组成（平常看到的例如192.168.1.1是由二进制转换成十进制方便人类辨别但本质是二进制）。IP地址分为两部分：网络位+主机位。
    • ABC类地址
      • A类地址是格式为0xxxxxxx.xxxxxxxx.xxxxxxxx.xxxxxxxx的IP地址，因此可以算出第一个字节（1字节=8位）的范围为0000000001111111，转换为十进制即0127。默认A类地址网络号占8位，剩下的24位为主机号。由于主机号为全0的网络地址和全1的广播地址已有特定用途，因此能分配的主机个数为2^24 -2个。A类地址常用于大型网络。
      • B类地址是格式为10xxxxxx.xxxxxxxx.xxxxxxxx.xxxxxxxx的IP地址，因此可以算出第一个字节（1字节=8位）的范围为1000000010111111，转换为二进制即128191。默认B类地址网络号占16位，剩下的16位为主机号。B类地址常用于中型网络。
      • C类地址是格式为110xxxxx.xxxxxxxx.xxxxxxxx.xxxxxxxx的IP地址，因此可以算出第一个字节（1字节=8位）的范围为1100000011011111，转换为二进制即192223。默认C类地址网络号占24位，剩下的8位为主机号。C类地址常用于小型网络。
      • D类地址第一个字节十进制范围为224~239。D类地址常用于多播地址。
      • E类地址第一个字节十进制范围为239~255。E类地址常保留于实验用。
  • (2)（子网）掩码
    • 作用：判定两个或多个IP是否在同一网络。
    • 双方电脑想要通信的最基本条件：如果没有其它网络设备的帮助，节点之间的IP地址必须在同一网络内才能通信。IP地址分为两部分：网络位（在哪个网络）+主机位（具体位置），例如192.168.1.1，但这个时候需要判定哪部分是网络位，哪部分是主机位，由此产生子网掩码，需要根据子网掩码进行判断。
    • 子网掩码由连续的1加上连续的0组成，连续的1对应的IP地址的位是网络位，连续的0对应的IP地址的位是主机位。同样的，子网掩码也是二进制数，十进制是简化的表达方式，连续的8个1对应的十进制数为255。实际情况例如IPv4地址 192.168.1.251 IPv4子网掩码 255.255.255.0，就表明192.168.1这部分是网络位，251是主机位。
    • 同样也是一种常见的写法，例如192.168.1.1/24，这里的24表示子网掩码中为1的位有24个（11111111.11111111.11111111.00000000），也就是说192.168.1这部分是网络位，251是主机位。
    • 主机地址全（表示）为0的叫网络地址。用来表示某一网络下的全部主机，例如1.1.1.1/24和1.1.1.99/24的网络地址都是1.1.1.0/24，说明它们都在1.1.1.0/24这个网络内。
    • 主机地址全（表示）为1的叫广播地址。网络号并不是一个真正的ip地址，无法用它进行通信，而广播地址可以跟同一网络下所有主机通信，例如1.1.1.255/24，那么它可以给在同一网络地址下的1.1.1.1/24和1.1.1.99/24进行通信。
  • (3)子网划分
    • 作用：将一个大的网络划分为多个小的网络。
    • 按上述划分的ABC三类，容易造成资源浪费的问题，例如分配8.0.0.0/8，但实际上并不需要2^24这么多个主机，因此，我们一般采用子网划分的方法来划分网络，即自定义网络号位数，就能自定义主机号位数，就能根据主机个数来划分出最适合的方案，不会造成资源的浪费。
    • 步骤：
      • 将原网络的主机位写回2进制。
      • 把网络位“变长”，主机位变短，即逐位向主机位借位，并写出所有可能性。
      • 写出划分后的网络号、掩码、有效的主机IP范围。
      • 例如，要将200.1.1.0/24变成2个子网，200.1.1.0000000/24借1位就会有2^1两种可能性，满足需要，即200.1.1.0000000/25和200.1.1.1000000/25，变回十进制表示即200.1.1.0/25和200.1.1.128/25，有效范围需要去掉网络地址和广播地址，200.1.1.0/25有效范围为200.1.1.1200.1.1.126，200.1.1.128/25有效范围为200.1.1.129200.1.1.254。而这时子网掩码的表示是25位个1，也即255.255.128.0。
      • 同样的，也可以看到，借了x位，就可以划分出2^x个子网。

6.IPv6

  • (1)上述所说的IP地址实际上都是指IPv4，而随着互联网的发展，IP地址不够用的问题需要解决，于是出现IPv6。IPv4有32位地址空间，能表达的ip地址个数为2^32，而IPv6有128位地址空间，能表达的ip地址个数为2^128，相较IPv4地址空间增大了2^96倍。

7.无线网

  • (1)蓝牙：覆盖范围最小，通信距离最短。

8.网络诊断命令

  • (1)ipconfig
    • 功能：查看和管理网络配置。
    • ipconfig/release：DHCP客户端手工释放IP地址。
    • ipconfig/renew：重新获得一个ip地址。DHCP客户端手工向服务器刷新请求（重新申请IP地址）。
    • ipconfig/reset：重置网络适配器配置。
    • ipconfig/flushdns：清除本地DNS缓存内容，可以解决客户端域名解析故障问题。
    • ipconfig/displaydns：显示本地DNS内容。
    • ipconfig/registerdns：DNS客户端手工向服务器进行注册。
    • ipconfig：显示所有网络适配器的IP地址、子网掩码、缺省网关值。
    • ipconfig/all：显示所有网络适配器的完整TCP/IP配置信息，包括DHCP服务是否已启动。
  • (2)ping
    • 功能：测试与另外一台计算机之间的连接、网络连通性。
    • ping命令进行网络检测顺序：执行ping 127.0.0.1 检查本机配置是否正常 → ping本地IP → ping默认网关（路由器） → ping远程主机。
  • (3)netstat
    • 功能：获取某个网络开放端口所对应的应用程序信息。可以看到有哪些网络连接正在运作。（无法检测DNS是否出现故障）
    • -a 显示所有连接和监听端口
    • -n 以数字格式显示IP地址
    • -e 显示以太网统计
    • -r 显示路由表
    • -s 显示每个协议统计
  • (4)nslookup
    • 功能：域名查询，查询DNS记录、诊断DNS服务问题。
  • (5)tracert
    • 功能：分析DNS路由是否正确，用于确定IP数据包访问目标所采取的路径。

9.路由

  • (1)当Windows服务器收到一个IP数据包时，先查找主机路由，再查找网络路由（直连网络和远程网络），这些路由查找失败时，最后才查找默认路由。
  • (2)主机路由：子网掩码为255.255.255.255
  • (3)默认路由：0.0.0.0，作用为当没有其它路由可选时最后选择的路由。
  • (4)如果路由器收到了多个路由协议转发的，关于某个目标的多条路由，则比较各个路由的管理距离，并采用管理距离小的路由来源提供的路由信息。
  • (5)路由协议是通过执行一个算法来完成路由选择的一种协议，路由器之间可以通过路由协议学习网络的拓扑结构，允许让数据包在主机之间传送路由。
