Redis：数据类型

1.概述

  • (1)这里所指的数据类型是指键值对中值的数据类型。

2.string类型

  • (1)Redis中的string类型保存的是字节序列（Sequence of bytes），因此任意类型的数据，只要经过序列化之后都可以保存到Redis的string类型中，包括文本、数字甚至是一个对象。string类型常用于缓存、计数器等场景。
  • (2)set命令用于添加string类型的键值对，语法：SET key value [NX|XX] [EX seconds|PX milliseconds]。
    • NX：仅在key不存在时set。
    • XX：仅在key存在时set。
    • EX seconds：设置过期时间，单位为秒。
    • PX milliseconds：设置过期时间，单位为毫秒。
  • (3)get命令用于获取某个string类型的键对应的值，语法：GET key。
  • (4)incr命令用于对数值做自增操作，语法：INCR key。
  • (5)decr命令用于对数值做自减操作，语法：DECR key。

3.list

  • (1)list类型可用于存储多个string类型的元素，并且所有元素按照被添加的顺序存储。list类型常用于社交应用中，可使用list缓存每个用户发布的最新的N条记录，以及用作异步消息队列。
  • (2)添加元素，相关命令有lpush、rpush 、linsert：
    • lpush用于向list左侧（头部）添加元素，语法：lpush key element [element ...]。
    • rpush用于向list右侧（尾部）添加元素，语法：rpush key element [element ...]。
    • linsert用于向list指定位置添加元素，语法：linsert key before|after pivot element。pivot表示基准元素。
  • (3)查询元素，相关命令有lindex、lrange、llen：
    • lindex用于获取指定索引位置的元素，语法：lindex key index。
    • lrange用于获取指定范围内的元素列表，语法：lrange key start stop。
    • llen用于查看list长度，语法：llen key。
  • (4)删除元素，相关命令有lpop、rpop、lrem：
    • lpop用于移除并返回list左侧元素，语法：lpop key [count]。
    • rpop用于移除并返回list右侧的元素，语法：rpop key [count]。
    • lrem用于移除list中的指定元素，语法：lrem key count element。
      • 若count>0，则从左到右删除最多count个element元素。
      • 若count<0，则从右到左删除最多count（的绝对值）个element元素。
      • 若count=0，则删除所有的element元素。
  • (5)修改元素：
    • lset用于修改指定索引位置的元素，语法：lset key index element

4.set

  • (1)和list类型相似，set类型也可用来存储多个string类型的元素，但与list类型不同，set中的元素是无序的，且set中不会包含相同元素。set可用于计算共同关注好友，随机抽奖系统等等。
  • (2)添加元素：
    • sadd用于向set中添加元素，语法：sadd key member [member ...]。
  • (3)查询元素，相关命令有smembers、scard、srandmember、sismember：
    • smembers用于查询set中的全部元素，语法：smembers key。
    • scard用于查询set中的元素个数，语法：scard key。
    • srandmember随机返回set中的n个元素（不删除），语法：srandmember key [count]。
    • sismember用于判断元素是否在set中，语法：sismember key element。
  • (4)删除元素，相关命令有srem、spop：
    • srem用于移除set中的指定元素，语法：srem key member [member ...]。
    • spop用于随机移除并返回set中的n个元素，语法：spop key [count]。
  • (5)多个集合的操作，相关命令有sinter、sunion、sdiff：
    • sinter用于计算多个集合的交集，语法：sinter key [key ...]。
    • sunion用于计算多个集合的并集，语法：sunion key [key ...]。
    • sdiff用于计算多个集合的差集，语法：sdiff key [key ...]。

5.hash

  • (1)hash类型类似于Java语言中的HashMap，可用于存储键值对，这里的键值对是指Redis存储的键值对中的值是键值对。hash类型常用于缓存对象。
  • (2)添加元素，相关命令有：
    • hset用于向hash中增加键值对，语法：hset key field value [field value ...]。
  • (3)查询元素，相关命令有：
    • hget用于获取hash中某个键对应的值，语法：hget key field。
    • hkeys用于返回hash中所有的键，语法：hkeys key。
    • hvals用于返回hash中所有的值，语法：hvals key。
    • hgetall用于返回hash中所有的键与值，语法：hgetall key。
    • hlen用于查询hash中的键值对个数，语法：hlen key。
    • hexists用于判断hash中的某个键是否存在，语法：hexists key field。
  • (4)删除元素，相关命令有：
    • hdel用于删除hash中的指定的键值对，语法：hdel key field [field ...]。

6.zset

  • (1)zset（sorted set）被称为有序集合，同set相似，zset中也不会包含相同元素，但不同的是，zset中的元素是有序的。并且zset中的元素并非像list一样按照元素的插入顺序排序，而是按照每个元素的分数（score）排序。zset主要用于各种排行榜。
  • (2)添加元素，相关命令有：
    • zadd用于向zset中添加元素，语法：ZADD key [NX|XX] score member。
      • NX：仅当member不存在时才add。
      • XX：仅当member存在时才add。
    • zincrby用于增加元素的分数，语法：zincrby key increment member。
  • (3)查询，相关命令有：
    • zscore用于查看某个元素的分数，语法：zscore key member。
    • zrange用于查询指定区间范围的元素，语法：zrange key start stop [byscore] [rev] [limit offset count] [withscores]。
      • start/stop：用于指定查询区间，但是在不同模式下，其代表的含义也不相同。默认模式下，start~stop表示的是名次区间，且该区间为闭区间。名次从0开始，且可为负数，-1表示倒数第一，-2表示倒数第二，以此类推；byscore模式下（声明了byscore参数），则start~stop表示的就是分数区间，该区间默认仍为闭区间。在该模式下，可以在start或stop前增加(来表示开区间，例如(1 (5，表示的就是(1,5)这个开区间。除此之外，还可以使用-inf和+inf表示负无穷和正无穷。
      • byscore：用于切换到分数模式。
      • rev：表示降序排序。在byscore模式下使用rev参数需要注意查询区间，start应大于stop。
      • limit：该选项只用于byscore模式，作用和sql语句中的limit一致
      • withscores：用于打印分数。
  • (4)删除，相关命令有：
    • zrem用于删除元素，语法：zrem key member [member ...]。
  • (5)计算，相关命令有：
    • zcard用于计算zset中的元素个数，语法：zcard key。
    • zrank/zrevrank用于计算元素的排名，其中zrank按照score的升序排序，zrevrank则按照降序排序，语法：zrank/zrevrank key member。
