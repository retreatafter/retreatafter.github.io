基础面板：项目创建及用户界面

1.项目创建

  • Unity已经内置提供了一些模板，可根据需求选择。
  • 项目Project名称和位置，建议将项目单独放在一个文件夹中方便管理。
  • 启用版本管理相当于上传至云端。

2.编辑器窗口

(1)调整

  • 1)打开项目后将样式调整为默认Default。

  • 2)语言选择
    • 不推荐，建议熟悉原版英文界面，方便后续查找资料后能快速对应。且官方汉化语言包并不完善，中英夹杂。
    • 语言包需要先在UnityHub中下载，才能在编辑器中开启。如果是导入的编辑器安装包则无法在UnityHub界面进行添加模块操作。

(2)设计界面

  • 1)中央的这部分即设计界面，用于搭建场景。上方的场景面板Scene类似于编辑状态，游戏面板Game类似于预览状态。
  • 2)设计界面中的两个物体，左边的摄像机相当于呈现给玩家的“视角”，右边的太阳表示光照。
  • 3)内置工具常用快捷键（可修改），Q：视图工具，W：移动工具，E：旋转工具，R：缩放工具，F：聚焦当前物体，Ctrl：步移当前物体。

(3)层次界面Hierarchy与属性界面Inspector

  • 1)左侧部分为层级面板Hierarchy，显示场景中所有不同游戏对象，展示当前打开的场景中有哪些游戏物体。

  • 2)当选中一个对象时，右侧的属性面板检查器Inspector会相对应的显示该物体由哪些组件组成。

(4)项目工程界面Project

  • 1)工程面板，项目的相关文件（并非全部）都会在这里展示，我们的项目文件管理将在Assets中完成，包括声音、模型、场景、材质、脚本等。
  • 2)Packages中放置着内置插件包。

3.检查器窗口

(1)原理

  • 可以视为检查器部分就是一个个的组件，以及Unity提供了一些基础的组件，但更多的是通过我们导入C#脚本来实现我们需要的效果。

4.文件管理

  • 建议项目在创建后，在Assets下分类创建各个文件夹管理素材，包括且不限于场景Scenes、材质Materials、C#代码。 s
