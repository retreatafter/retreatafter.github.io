1.计算机语言

(1)类型

  • 类型：机器语言、汇编语言、高级语言。
    • 计算机硬件只“认识”机器语言，能直接执行的只有机器语言，即0和1。
    • 汇编语言是一种低级语言，直接面向机器硬件。汇编语言需要通过汇编器翻译成机器语言后才能被计算机执行。例如ARM汇编语言。
    • C/C++、JAVA、Python都属于高级语言。

(2)脚本语言

  • (1)概念：脚本语言/弱类型语言属于动态语言，不需要进行变量/对象声明的语言，在程序运行时可以改变其结构例如可以引进新的函数，属于解释型语言，不产生独立保存的目标程序。

(3)编程语言

  • (1)C/C++，C语言常用于开发操作系统或是进行软件开发，属于编译型语言。
  • (2)Python。Python为解释型语言，可用于编写独立程序和快速脚本。
  • (3)JAVA。特点为即时编译、对象在堆空间分配，有自动的垃圾回收处理。
  • (4)PHP，PHP更适合用来进行动态网页处理。
  • (5)函数式编程语言：Lisp。
  • (6)逻辑式程序语言：Prolog。

2.解释器和编译器

  • (1)解释器
    • 定义：翻译源程序时不生成独立的目标程序。
    • 特点：解释程序和源程序要参与到程序的运行过程中。
  • (2)编译器
    • 定义：翻译时将源程序翻译成独立保存的目标程序。
    • 特点：机器上运行的是与源程序等价的目标程序，源程序和编译程序都不再参与目标程序的运行过程。

3.程序设计语言基本成分

  • (1)程序设计语言中，可计算问题的程序都可以用顺序、选择、循环这3种控制结构来描述。
  • (2)程序设计语言规定其程序中的数据必须有类型，这时的类型是静态数据结构。

4.逻辑运算符

  • 基础定义：1为真，0为假
  • “与”：同时为1时（都为真）结果为1（真）。
  • “或”：存在1时结果为1（真）。
  • “同或”：相同时为1（真）。
  • “异或”：不同时为1（真）。

// 例题
问题：对于逻辑表达式 x and y or not z，优先级从高到低为not、and、or，若进行短路运算，表达式的值的真假由什么决定？
解答：首先，短路运算是指：无须对表达式中所有操作数或运算符进行计算就可确定表达式的值。
可得x & y || !z，可以看到若x & y为真或!z为真，只要两种情况之一成立，这个表达式则为真，而x & y为真需要x和y均为真
同样的，无论是x为真或假，都无法单一决定整个表达式为真或假。

5.传值调用和引用/地址调用

  • (1)传值调用：实参的值传递给形参，实参可以是变量、常量、表达式。不可以实现形参和实参间双向传递数据的效果。
  • (2)传引用/地址调用：可以实现形参和实参间双向传递数据的效果，即改变形参的值的同时也会改变实参的值。由于需要存在地址，实参不可以是常量和表达式。

// 例题
问题：函数t()、f()的定义如下所示，若调用函数t时传递给x的值为5，并且调用函数f()时，第一个参数x采用传值方式，第二个参数a采用传引用方式，则函数t的返回值为？
t(int x)
int a;
a = 3*x+1;
f(x,a);
return a-x;

f(int r, int&s)
int x;
x=2*s+1;s=x+r;
r=x-1;
return;

解答：首先，从函数t(int x)开始看起，得到x=5 a=16，这时调用函数f()并且传入参数情况为f(x,a)，根据题意知当传引用方式时双方指向地址一致值会同时的发生变动，即a和s指向相同地址，值发生改变时会同时影响。这时看到函数f(int r, int&s)，得到x=33 s=38，这个时候a=38。r=32但是对于t()的x是没有影响的，函数f()里的运算结束，回到函数t()，这时a-x=38-5=33。

6.编译过程

  • (1)流程
    • 起点：源程序（下述1-3步骤不可省略，顺序不可调换；编译方式中中间代码生成和代码优化不是必要的，可省略。）
      • (1)词法分析
      • (2)语法分析
      • (3)语义分析
      • (4)中间代码生成
      • (5)代码优化
      • (6)目标代码生成
    • 终点：目标代码
    • 注：从源程序到目标程序，编译方式包括以上所有6个步骤，解释方式只包括词法分析、语法分析、语义分析这前3步。
    • ![[2025__软设__程序设计语言.编译过程.png]]
  • (2)符号表
    • 1)定义：不断收集、记录、使用源程序中一些相关符号的类型和特征等信息，并将其存入符号表中。记录源程序中各个字符的必要信息，以辅助语义的正确性检查和代码生成。在编译过程中每一步都有符号表参与。
    • 2)编译过程中，对高级语言程序语句的翻译主要考虑声明语句和可执行语句。对声明语句，主要是将所需要的信息正确地填入合理组织的符号表中；对可执行语句，则翻译成中间代码或目标代码。
  • (3)词法分析：
    • 过程：【输入：源程序】，【输出：记号流】
    • 作用：分析构成程序的一个个字符，及由字符按照构造规则^1构成的符号是否符合程序语言规定。逐个字符进行扫描从而识别单词符号，例如输入int会识别i然后识别n再识别t，最终识别出输入了一个单词int。注意此处构造规则与结构区分。
    • 相关工具：正规式、自动机。
  • (4)语法分析
    • 过程：【输入：记号流】，【输出：语法树/分析树】
    • 特点：语法分析阶段可以发现程序中所有的语法错误。语法分析的任务是在词法分析的基础上，根据语言的语法规则将单词符号序列分解成各类语法单位，如“表达式”“语句”和“程序”等。例如Java语法中，输入int a=2会识别出没有分号。
    • 作用：1)对各条语句的结构进行合法性分析，例如变量是否定义；2)分析程序中的句子结构是否正确。即判断程序语句的形式/结构是否正确。例如检查程序中的括号是否配对。
  • (5)语义分析
    • 过程：【输入：语法树/分析树】，【输出：中间代码】
    • 特点：语义分析阶段不能发现程序中的所有语义错误，能发现的是静态语义错误而无法发现动态语义错误，动态语义错误是指类似除0、可能导致无限循环的情况，动态语义错误只有在程序运行时才能发现。又例如未赋初值的变量，也可能会造成动态语义错误。（但我们未赋初值，有些变量是默认有初值的，例如int a; 默认初值为0）
    • 作用：进行类型分析和检查，类型分析是指int型、boolean型……不能把boolean赋值给int类型，假如这样操作就会在语义分析阶段检查出来，例如int a = true;这样的错误就会在语义分析阶段被检查出来。
    • 相关工具：语法指导翻译。
  • (6)中间代码
    • 1)常见的中间代码：后缀式、三地址码式、三元式、四元式、树（图）……（不包括正则式、栈、队列（这两个是线性结构））
    • 2)特点：中间代码不依赖具体的机器，可以将不同的高级程序语言翻译成同一种中间代码，且中间代码可以跨平台。
    • 3)作用：有利于进行与机器无关的优化处理，提高编译程序的可移植性。
  • (7)目标代码生成
    • 1)过程：目标代码生成阶段的工作与具体的机器密切相关。
    • 2)寄存器的分配工作就处于目标代码生成阶段。
  • (8)源程序：在源程序中，可以为变量、函数、数据类型等进行命名。
  • (9)编译过程中的地址分配
    • 编译过程中为变量分配存储单元所用的地址是逻辑地址，程序运行时映射为物理地址。

// 例题
在仅由字符a、b构成的所有字符串中，其中以b结尾的字符串集合可用下述哪一正规式表示？
A.(b|ab)*b B.(ab*)b C.a*b*b D.(a|b)*b

解答：可以举特例进行排除，由于所有选项都有b结尾，因此看到题中另一个条件【仅由字符a、b构成的所有字符串】，也就是说bab理应也可以取到，而这个情况仅有(a|b)*b可以达到要求。（其实从正规式的定义中也可得(a|b)*就代表了字符a、b构成的所有字符串）
  • (2)词法分析的工具——有限自动机。可以正确地识别正规集
    • 计算机控制系统的控制程序具有有限状态(FA)的特征，可以用有限状态机理论来描述。
      • (1)非确定有限自动机NFA(Determinstic Finite Automata)：对每一个状态来说识别字符后转移的状态是不唯一的。即每个状态下选择1/0的途径是唯一的。
      • (2)确定有限自动机DFA(Nondeterminstic Finite Automata)：对每一个状态来说识别字符后转移的状态是唯一的。
    • 判断方式：输入一个字符，看是否能得出唯一的后继，若能，则是确定的，否则，若得出多个后继，则是不确定的。

  • (3)语法分析方法

    • (1)自上而下
      • 递归下降思想：原理是利用函数之间的递归调用模拟语法树自上而下的构造过程，是一种自上而下的语法分析方法。
      • 预测分析法。
    • (2)自下而上
      • 移进-规约思想：设置一个栈，将输入符号逐个移进栈中，栈顶形成某产生式的右部时，就用左部去代替，称为归约。很明显，这个思想是通过右部来推导出左部，因此是自下而上语法分析的核心思想。

  • (4)语义分析方法

    • (1)语法指导翻译。是一种静态语义分析方法。（编译过程中的语义分析都是静态语义，运行时才有动态语义。）

8.文法定义

  • (1)大多数程序设计的语法规则用上下文无关文法描述。
  • (2)开始符号→产生式集合→非终结符号的集合→终结符号的集合。
  • (3)优先级：
      1. 括号 ()
      1. 乘除 × ÷
      1. 加减 + -
  • (4)二叉树读取方式（以“根”的位置命名）：
    • 1)后缀式/逆波兰式：左右根
    • 2)中缀式：左根右。一个小技巧是如果题目给的是后缀式需要找对应的二叉树，可以先转换为中缀式再进行对应。

  • (5)特点：后缀式/逆波兰式可以利用栈求值。

// 例题2
后缀表达式abc-+d*的中缀表达式为？
解答：首先从左往右找到第一个符号，又因为是后缀表达式形式为AB?，再找到其左侧的两个符号，可以将bc-还原为b-c，这时把b-c看作一个整体，a(b-c)+还原为(a+(b-c))，这时把(a+(b-c))看作一个整体，(a+(b-c))d*还原为(a+(b-c)) *d，即为原本的中缀表达式。

10.编译器优化

  • (1)寄存器直接集成在CPU中，无需通过内存总线访问，其访问速度远高于内存。寄存器分配是编译器优化中的一个重要环节，由于寄存器数量有限，编译器必须决定哪些变量应该存储在寄存器中，哪些变量可以存储在内存中。寄存器分配的目标是最大限度地减少内存访问次数，从而提高程序的执行速度。
  • (2)内存分配：
    • 栈区：用于存储函数的局部变量、函数参数等。这部分内存由编译器自动分配和释放，其生命周期与所在的函数或代码块相关。即计算机执行程序时，栈是局部变量以及每次函数调用时所需保存的信息的存储区域。堆是一块动态存储区域，由程序员在程序中进行分配和释放。（栈帧不包括全局变量）
    • 自由堆区：用于动态分配内存，如通过malloc、new等函数分配的内存。这部分内存需要程序员手动管理（分配和释放）。
    • 静态数据区：包括全局变量和静态变量的存储空间。这部分内存在程序启动时分配，在程序结束时释放。
    • 文本区：存放程序的机器指令代码，通常是只读的。
