1.前后端分离

  • (1)流程：
    • 需求分析：首先我们需要阅读需求文档，分析需求，理解需求。
    • 接口定义（API接口文档）：查询接口文档中关于需求的接口的定义，包括地址，参数，响应数据类型等等。
    • 前后台并行开发：各自按照接口文档进行开发，实现需求。
    • 测试：前后台开发完了，各自按照接口文档进行测试。
    • 前后段联调测试：前段工程请求后端工程，测试功能。

2.YApi

  • (1)前后台分离开发中，前后台开发人员都需要遵循接口文档（这里的接口不同于我们在基础阶段说的接口Interface，这里更多的是指需要实现的功能），YApi是一款撰写接口文档的平台，支持API接口管理和Mock服务。官方地址： https://yapi.pro 。
    • API接口管理：根据需求撰写接口，包括接口的地址，参数，响应等等信息。
    • Mock服务：模拟真实接口，生成接口的模拟测试数据，用于前端的测试。

3.前端工程

  • (1)特点：
    • 模块化：将js和css等，做成一个个可复用模块。
    • 组件化：我们将UI组件，css样式，js行为封装成一个个的组件，便于管理。
    • 规范化：我们提供一套标准的规范的目录接口和编码规范，所有开发人员遵循这套规范。
    • 自动化：项目的构建、部署、测试全部都是自动完成。

4.脚手架Vue-cli

  • (1)vue官方提供的脚手架Vue-cli用于快速的生成一个Vue的项目模板。依赖环境NodeJS，即需要先安装NodeJS，然后才能安装Vue-cli。
    • NodeJS官方地址： https://nodejs.org/en/download
    • 安装NodeJS后，NodeJS会自动配置环境变量，我们可以在命令提示符界面使用命令node -v验证是否安装成功、版本是否正确；并配置包资源管理器npm的全局安装路径，命令提示符界面（管理员身份运行）执行命令npm config set prefix "盘符路径:\盘符路径\NodeJS（Node.exe所在目录）"，并可以通过命令npm config get prefix检查是否设置成功。
    • 在命令提示符界面使用命令npm install -g @vue/cli安装Vue-cli。可以通过命令vue --version来验证是否安装成功。

5.Vue项目开发流程

  • (1).vue结尾的都是vue组件，vue的组件文件包含3个部分：
    • template：模板部分，主要是HTML代码，用来展示页面主体结构。
    • script：js代码区域，主要是通过js代码来控制模板的数据来源和行为。
    • style：css样式部分，主要通过css样式控制模板的页面效果。

6.Vue路由

  • (1)需求：当点击导航栏时，浏览器的地址栏会发生变化，路由自动更新显示与url所对应的vue组件。vue官方提供了路由插件Vue Router，其主要组成如下：
    • VueRouter：路由器类，根据路由请求在路由视图中动态渲染选中的组件。
    • <router-link>：请求链接组件，浏览器会解析成超链接<a>。
    • <router-view>：动态视图组件，用来渲染展示与路由路径对应的组件。
  • (2)使用步骤：
    • 安装vue-router插件，可使用命令npm install vue-router@3.5.1。若创建项目时已经勾选了路由功能，则已经安装，无需重复安装。
    • 在src/router/index.js文件中定义路由表，对应关系。
