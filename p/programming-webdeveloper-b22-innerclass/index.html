1.特点

  • (1)定义：内部类就是在一个类的内部再定义一个类，比如，A类中定义一个B类，那么B类相对A类来说就称为内部类，而A类相对B类来说就是外部类。应用场景：当一个类和另一个类间存在依赖关系（非继承），且这个类单独存在没有意义。又或者这个类只需要另一个类使用，单独定义为一个类文件从项目结构来说不够简洁，这种情况就可以用内部类。
  • (2)类的特性：
    • 1)一个Java文件只能有一个public class，但是可以有多个class。
    • 2)多个class类里可以写main方法，当测试类来使用。

2.成员内部类/实例内部类

  • (1)位置：类中，方法外。
  • (2)特点：
    • 成员内部类可以被一些修饰符所修饰，比如：private，default，protected，public，static等。
    • 实例内部类中不能定义静态成员，但JDK16之后允许在成员内部类里面定义静态成员。
  • (3)获取成员内部类对象：
    • 1)直接创建，格式：外部类名.内部类名 对象名 = 外部类对象.内部类对象;，例如Outer.Inner oi = new Outer().new Inner();。即实例内部类属于外部类对象。实例内部类的宿主是外部类对象，因此等号右边是new Outer()
    • 2)外部类编写一个new出内部类对象的方法，供外界使用。
  • (4)外部类成员变量和内部类成员变量重名时，内部类想要访问，采用外部类名.this.变量名。

3.静态内部类

  • (1)概念：静态内部类是成员内部类的一种特殊情况，即内部类为static关键词修饰。只会加载一次。
  • (2)获取静态内部类对象：格式外部类名.内部类名 对象名 = new 外部类名.内部类名();，例如Outer.Inner oi = new Outer.Inner();。（如果是独立的类，写为Inner oi = new Inner();，相当于在等号左右两侧加上外部类Outer）
  • (3)调用静态内部类中的方法：
    • 非静态方法：先创建对象，用对象调用
    • 静态方法：外部类名.内部类名.方法名();

        // 外部类名称.内部类名称 对象名称 = new 外部类名称.内部类构造器
        Outter.Inner in = new Outter.Inner();

    }
}

5.匿名内部类

  • (1)在调用包含有接口类型参数的方法时，通常为了简化代码，可以直接通过匿名内部类的形式传入一个接口类型参数，在匿名内部类中直接完成方法的实现。
  • (2)特点：
    • 匿名内部类一旦写出来，就会立即创建一个匿名内部类的对象返回。
    • 匿名内部类的对象的类型相当于是当前new的那个的类型的子类类型。
  • (3)格式：

6.Lambda表达式

  • (1)JDK8后引入了Lambda表达式，基本语法是使用箭头将参数和表达式分开，基本格式为：
1
2
3

(匿名内部类被重写方法的形参列表) -> {
	 //被重写方法的方法体代码
}
  • (2)作用：
    • Lambda表达式可以用来简化匿名内部类的书写。
    • 但需要注意，Lambda表达式只能简化函数式接口的匿名内部类的写法，函数式接口指的是有且仅有一个抽象方法的接口，接口上方可以加@FunctionalInterface注解来验证。
  • (3)省略规则：可推导的可省略。
    • 参数类型可以省略不写。
    • 如果只有一个参数，参数类型可以省略，同时()也可以省略。
    • 如果Lambda表达式的方法体只有一行，大括号，分号，return可以省略不写，但需要同时省略。

7.方法引用

  • (1)方法引用是一种更简洁易懂的Lambda表达式。符号：::。
  • (2)类型：
    • 引用静态方法，被引用的方法的参数列表和函数式接口中的抽象方法的参数列表一致，格式：类名::静态方法。例如Collections.sort(lists, ( o1, o2) -> Student.compareByAge(o1 , o2));简化为Collections.sort(lists, Student::compareByAge);。
    • 引用成员方法/实例方法，被引用的方法的参数列表和函数式接口中的抽象方法的参数列表一致，包括引用本类、基类、其它类。引用本类格式：this::方法名；引用基类格式：super::方法名；引用其它类格式：其它类对象::成员方法。例如lists.forEach(s -> System.out.println(s));简化为lists.forEach(System.out::println);。
    • 使用类名引用成员方法，第一个参数列表中的形参中的第一个参数作为了后面的方法的调用者，并且其余参数作为后面方法的形参，格式：类名::成员方法。例如Arrays.sort(strs, ( s1, s2 ) -> s1.compareToIgnoreCase(s2));简化为Arrays.sort(strs, String::compareToIgnoreCase);。
