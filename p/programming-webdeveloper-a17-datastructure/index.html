1.算法分析基础

(1)时间复杂度与空间复杂度

  • 1)时间复杂度是指程序运行从开始到结束所需要的时间。
    • 复杂度从低到高：
    • 常数O(1) ＜ 对数O(log2n) ＜ 线性O(n) ＜ 线性对数O(nlog2n) ＜ 平方O(n^2) ＜ 立方O(n^3) ＜ 指数O(2^n) ＜ 阶乘O(n!) ＜ n次方阶O(n^n)
  • 2)空间复杂度是指对一个算法在运行过程中临时占用存储空间大小的度量。一个算法的空间复杂度只考虑在运行过程中为局部变量分配的存储空间的大小。

2.线性表

  • 1)以下所说的顺序表和链表都是一维结构，可简单看作1行n列的表。
  • 2)顺序表
    • 定义：一组地址连续的存储单元依次存储线性表中的数据元素。
    • 增删改查：
      • 增删：在顺序表中增加元素，如果是在已有元素的位置上进行添加，例如对于A[100]=[1，3，5，7]（由于静态数组定义后无法更改大小，这里预留100个空间）需要将一个新元素插入到A[0]，那么需要将[1，3，5，7]都往后移动1位。类似的，在顺序表中删减元素，例如对于A[100]=[1，3，5，7]删除A[2]，那么A[3]需要向前移动1位。增删的时间复杂度最好情况为O(1)（插入到尾部且尾部有空位，无需移动任何元素），最坏情况为O(n)（插入到头部，那么所有元素都要往后移动），平均移动(n-1)/2个元素。
      • 查：对表中的任意结点可以高效进行随机访问，通过下标去查找即可。查找的时间复杂度为O(1)。
    • 缺点：增删数据时经常需要大量的移动元素。
    • （附：顺序表的一种底层实现是数组。）
  • 3)链表
    • 单链表：
      • 定义：数据域和指针域两部分信息组成。数据域用于存储数据元素的值，指针域则存储当前元素的直接前驱或直接后继的位置信息，指针域中的信息称为指针（或链）。存储各数据元素的结点的地址并不要求是连续的，因此存储数据元素的同时必须存储元素之间的逻辑关系。另外，结点空间只有在需要的时候才申请，无须事先分配。所需空间与结点个数成正比。
      • 创建：创建链表时只需要创建出一个头结点，之后有新增元素在头节点基础上增添即可。
      • 增删：插入包括头插法与尾插法和指定位置插入元素，头插法与尾插法最为常用，即增加元素时永远将元素放在头节点/尾节点的后面，例如对于链表A=[1，3，5，7]，需要根据头插法插入一个新元素，那么先将新元素的地址指向3，再将1的地址从指向3改为指向新元素，这样就做到了增加一个元素。而使用尾插法，通过遍历直到找到尾节点（next=null的节点），将尾节点的地址指向新元素。增删平均移动0个元素，只需改动地址即可。增删的时间复杂度最好情况为O(1)，最坏情况为O(n)。
      • 查：由于存储的位置信息并不连续，因此需要查找一个元素时需要遍历，查找的时间复杂度为O(n)。
      • 在表中任意位置插入和删除都不用移动其它元素结点。
      • 缺点：数据元素之间的关系（指针）需要占用存储空间，导致存储密度不高，且随机访问速度慢。因为一个节点只知道它的前一个节点的地址或是后一个节点的地址，无法“回头”。
    • 双链表：
      • 每个节点包含两个指针，分别指出当前元素的直接前驱和直接后继。
    • 循环链表：
      • 在单向链表（或双向链表）的基础上令表尾结点的指针指向链表的第一个结点，构成循环。

3.特殊的线性表

(1)栈和队列

  • 1)栈stack：
    • 定义：只能通过访问一端来实现数据存储和检索，也就是说栈是限定仅在表尾进行插入和删除操作的线性表。在栈中进行插入和删除操作的一端称为栈顶(Top)，相应地，另一端称为栈底(Bottom)。不含数据元素的栈称为空栈。
    • 顺序存储：用一组地址连续的存储单元依次存储自栈顶到栈底的数据元素，同时附设指针top指示栈顶元素的位置（初始值-1，从这可以看出如果指针top为-1可以说明是空栈）。
    • 链式存储：用链表作为存储结构的栈也称为链栈。
    • 特点：
      • 先进后出，只有栈顶能进出。
      • 入栈和出栈序列为1:n，即一种入队序列可以对应多种出栈序列的可能。
    • 作用：实现递归/嵌套调用函数。
  • 2)队列queue：
    • 定义：插入和删除在两个不同的端进行。允许插入的一端称为队尾(rear)，允许删除的一端则称为队头(front)。队列有两个指针rear和front，当rear=front时说明队列为空。（不能根据rear和front为0而判断是空队列）
    • 循环队列：入队和出队操作都不需要移动队列中的其它元素。循环队列最多可存放的元素是最大容量-1，不能放满，否则队头指针和队尾指针将重合，就无法分辨到底是空队列还是满队列。
      • 特点：循环单链表的队列入队和出队都不需要遍历链表。即出队入队的时间复杂度均为O(1)。
      • 性质：对于循环队列Q，容量M，那么长度L=(rear-front+M)%M。（也可以用特殊值模拟一个循环队列来进行推导分辨）
    • 特点：
      • 先进先出，分队头和队尾。
      • 入队和出队序列为1:1，即一种入队序列只会对应一种出队序列的可能。

(2)串

  • 1)概念：
    • 字符串是一种特殊的线性表，其数据元素都为字符。
  • 2)类型：
    • 空串不包括任何字符，也不包括空白字符。
  • 3)特点：
    • 空格是一个空白字符，但也是一个字符。字符串的长度是指串中所含字符的个数，包括空格。
  • 4)朴素匹配时间复杂度：
    • 主串长度n，模式串长度m
    • 最好 时间O(m) 次数m
    • 最坏 时间O(n×m) 次数(n-m+1)×m
  • 5)KMP匹配算法(Knuth-Morris-Pratt)：
    • 模式串和next值，前串和后串做对比，每部分的next值为相等的部分+1，默认第一个值的next为0第二个值的next为1。
    • 时间复杂度：O(n+m) 次数n+m

4.数组与矩阵

  • 1)数组
    • 一维数组
      • 假设一维数组a[n]每个数组元素占用内存长度为len，起始地址为a，m和n的下标都从0开始，a[i]的存储地址为a+i×len。
    • 二维数组
      • 假设二维数组a[m][n]每个数组元素占用内存长度为len，起始地址为a，m和n的下标都从0开始，a[i][j]按行存储（以行为主序）的存储地址为a+(i×n+j)×len，a[i]按列存储（以列为主序）的存储地址为a+(i+j×m)×len。
  • 2)矩阵
    • 对称矩阵：以主对角线为对称轴，各元素对应相等的矩阵。
    • 三角矩阵：分为上三角、下三角、三对角。上三角矩阵是指主对角线以下元素全为0的矩阵，下三角矩阵是指主对角线以上元素全为0的矩阵，三对角矩阵是指除了主对角线及其上下两条邻近对角线上的元素外，其它位置（上三角和下三角部分）的元素均为零。
    • 稀疏矩阵
      • 三元组顺序表和十字链表是对稀疏矩阵进行压缩存储的方式。

//例题
设有数组A[i,j]，数组的每个元素长度为3字节，i的值为从1到8，j的值为1到10，数组从内存首地址BA开始顺序存放，当用以列为主序存放时，元素A[5,8]的存储首地址为？
解答：（可以画图辅助理解）这是一个8行10列的数组（每一行有10个元素，每一列有8个元素），并且按列存储，因此A[5,8]前面有8-1=7列数据，而在同一行的之前有5-1=4个数据，因此A[5,8]是第(8-1)×8+(5-1)=60个元素，而每个元素长度为3字节，首地址为BA，那么元素A[5,8]的存储首地址为BA+60×3=BA+180。

5.树

(1)树与二叉树

  • 1)树的概念：一个节点的子树个数记为该结点的度。
  • 2)树的特点：
    • (A)树中的结点总数等于树中所有结点的度数之和（即子结点个数）加1。（加1实际上就是加上顶点那个结点）
    • (B)度为m的树中第i (i≥1)层上最多有m^(n-1)个结点。
    • (C)高度为h的m次树最多有m^(h-1) /(m-1)个结点。
    • (D)具有n个结点、度为m的树的最小高度为logm (n(m-1)+1)。
  • 3)二叉树特点：
    • (A)二叉树第i层(i≥1)上最多有2^(i-1)个结点。
    • (B)高度为h的二叉树最多有2^(h-1)个结点。
    • (C)对于任何一棵二叉树，度为0的结点数等于度为2的结点数+1。（即度为0的结点数永远大于度为2的结点数）
    • (D)具有n个结点的完全二叉树的高度为⌞log2 n⌟+1或⌜log2 (n+1)⌝。

(2)完全二叉树与非完全二叉树

  • 1)仅最后一层非满且结点连续的二叉树为完全二叉树，仅最后一层非满但结点不连续（不是连续地从左到右放置）的二叉树为非完全二叉树。
    • 特点：完全二叉树 更适合 顺序存储，一般二叉树（非完全） 更适合 链式存储。
  • 2)当二叉树的结点数目确定时，完全二叉树的高度一定是最小的。

//例题
以下二叉树进行顺序存储，已知结点A、B、C下标分别为1、2、3，那么结点F对应的数组元素下标为？
     A
  B     C
       D  E
         F(F是E的左孩子)
解答：根据顺序存储定义，可知一共需要2^4 -1=15个存储单元（4为高度），存储顺序是从上至下，从左到右，因此F的下标为14。

(3)卡特兰树

  • 1)卡特兰树是计算二叉树排列的可能性，具有n个结点的二叉树有种排列方式。（常见：3→5种，4→14种，5→42种）

(4)二叉树的遍历

  • 1)遍历方式：
    • 先序：根左右。
    • 中序：左根右。
    • 后序：左右根。
    • 层次遍历：即一层一层遍历，从上到下，从左到右。
  • 2)根据序列构造二叉树：有中序+先序 / 中序+后序，就可以构造出唯一的二叉树。（一定要有中序序列）

//例题
已知某二叉树的先序遍历序列为ABCDEF，中序遍历序列为BADCFE，那么该二叉树的后序遍历序列为？二叉树的高度为？
解答：核心为根据两个序列一步步确定每一层的“根”。先看先序序列，由于特点是根左右，那么根节点一定是A，再回到中序序列，在A左侧的只有B，其余的在右侧，再看先序序列，那么CDEF的根节点一定是C，回到中序序列，在C左侧的只有D，FE在右侧，回到先序序列，EF的根节点一定是E，最后再回到中序序列，F在E左侧，说明是E的左结点。可以构造出以下二叉树
     A
  B     C
       D  E
         F(F是E的左结点)
可以看到该二叉树的高度为4，而后序遍历序列可以一层一层来看，ABC三个元素根据后序遍历的特点左右根排序为BCA，而C结点下还有结点，再看下一层，CDE三个元素根据后序遍历的特点左右根排序为DEC，结合上一层为BDECA，E结点下还有结点，再看下一层，EF两个元素根据后序遍历的特点左右根排序为FE，因此后序遍历序列应为BDFECA。

(5)平衡二叉树AVL

  • 1)定义：二叉树中任意一个结点的左右子树高度之差的绝对值不超过1。
  • 2)特点：完全二叉树是平衡二叉树，但平衡二叉树不一定是完全二叉树。

(7)最优二叉树/哈夫曼树

  • 1)原理：权值越大的叶子结点离根结点越近，那么结点所乘的系数就越小，从而使得树的路径长度达到最小。哈夫曼编码方案基于贪心策略。
  • 2)构造方法：选取两个权值最小的数（包括新生成的），组成一个新结点 → 把新结点加入原来序列，和剩下未排序字符再次从小到大排序 → 小左大右 → 权值相同的情况按照从先往后的顺序 → 重复上述操作 → 用时再调。
  • 3)哈夫曼编码：左分支标0，右分支标1来描述路径，这样可以保证每一个结点的路径描述都不相同。
  • 4)用n个值构造最优二叉树，结点总数为2n-1。
  • 5)性质：哈夫曼树中只有度为0和度为2的结点，且度为0的结点比度为2的结点多1个。（总结点数2n-1，必定为奇数）

6.图

(1)图的概念

  • 1)概念：
    • 定义：图(Graph)由顶点的有穷非空集合和顶点之间边的集合组成。即顶点不允许为空，而边可以为空。
    • 无向图：图的结点之间连接线是没有箭头的，不分方向。
    • 有向图：图的结点之间连接线是箭头，区分A到B，和B到A是两条线。
    • 完全图：任意两个顶点之间都存在边。有向完全图（有向图边的最大数量）有n(n-1)条边，无向完全图（无向图边的最大数量）有n(n-1)/2条边。（无向完全图满足等差数列公式，以4个顶点的图示例，那么边数为3+2+1+0，因此总和为n(n-1+0)/2，有向完全图因为具有方向，在这个和的基础上×2，因此为n(n-1)）
      • 注意此时无向图是连通的，非连通图则再加1个节点。
    • 连通图：如果对于图中任意两个顶点都有可以到达的路径（并非必须直接相连），则称此图为连通图。
  • 2)特点：
    • 1)度、出度和入度：顶点的度是关联与该顶点的边的数目。在有向图中，顶点的度为出度和入度之和。出度是以该顶点为起点的有向边的数目。入度是以该顶点为终点的有向边的数目。
      • 对于边数为e的无向图，度数之和为2e。
      • 有向图中所有顶点的出度之和=入度之和=弧的数量。

(2)图的存储

  • 1)邻接矩阵
    • 概念：邻接矩阵的本质是用两个数组来存储图。行标为起点，列标为终点。
    • 特点：
      • 邻接矩阵适合存储稠密图，即边数多的图。那么也可以说完全图适合采用邻接矩阵存储。
      • 无向图的邻接矩阵一定是对称的。
      • 顶点数N=4，边数E=3，矩阵中非零元素数（度）=2E=6。
  • 2)邻接表
    • 概念：邻接表用一维数组来存储图。每个元素都是一个链表，每个链表存储与该顶点直接相连的顶点。（邻接表中仅表述与顶点直接连接的所有顶点，而这些顶点按什么顺序表述不做限制，例如下图无向图邻接表中与v1连接的顶点本质是v1=[v0,v3]，也可以表示为v1=[v3,v0]）
    • 特点：
      • 邻接表适合存储稀疏图，即边数少的图。
  • 3)邻接矩阵拓展
    • 稀疏矩阵是指矩阵中有较多元素为0。
    • 三角矩阵是指只有一个三角区域有值，剩下一半的三角（几乎）没有值。有序的拓扑排序序列的有向图的邻接矩阵必定为三角矩阵。

(3)图的遍历

  • 1)深度优先搜索DFS(Depth First Search)
    • 即一条路走到里再去走另一条路，类似于前序遍历。例图中的深度遍历顺序为v1→（与v1直接连接的出度有v2和v3这里选择v2）v2→（与v2直接连接的出度有v4和v5这里选择v5）v5→（这条路走到尽头即v5没有出度，回溯至走过的路径中的上一个顶点即v2，而与v2连接且没走过的路径为v4）v4→（v4有条出度是v5但是v5已经访问过，没有其它路径，因此回溯至v2，v2也没有其它未访问的顶点，因此再回溯至v1，与v1连接且未访问的路径为v3）v3（以上路径不唯一）
  • 2)广度优先搜索BFS(Breadth First Search)
    • 类似层次遍历。例图中的广度遍历顺序为v1→v2→v3→v4→v5。（以上路径不唯一）
    • 通过队列实现层次遍历。
  • 3)DFS和BFS时间复杂度相同，采用邻接矩阵存储时，平均时间复杂度为O(n^2)，采用邻接表存储时，平均时间复杂度为O(n+e)。e为边数。

(4)网

  • 1)概念：边/弧带权重值的图称为网。两个无连接的顶点在矩阵中用无穷∞符号表示。
  • 2)遍历的时间复杂度，其中矩阵为O(n^2)，邻接表为O(n+e)，上述均为n个结点，e条边。

(5)拓扑排序

  • 1)AOV网即有向无环图，拓扑排序是为将AOV网中所有顶点排成一个线性序列。操作为：按顺序排列入度=0的序号，已入队的在图中删除顶点及与该顶点有关的所有弧，重复上述操作直到网中不存在入度为0的顶点为之。
  • 2)特点：在有向无环图G的拓扑序列中，顶点Vi在Vj之前，则：可能存在弧<Vi,Vj>，一定不存在弧<Vj,Vi>；可能存在Vi到Vj的路径，一定不存在Vj到Vi的路径。

7.查找

(1)静态查找与动态查找

  • 1)通常将只进行查询和检索这两种操作的查找表称为静态查找表，若需要在查找表中插入或删除元素，则称此类查找表为动态查找表。
  • 2)静态查找：顺序、折半、分块。
    • 顺序查找：
      • 对任何表都可用（有序无序都可以，顺序存储链表存储都可以），但效率低。
      • 顺序查找成功的平均查找长度为(n+1)/2。（每个元素的概率1/n × 每个元素比较次数为等差数列n(n+1)/2）
    • 折半查找/二分查找：
      • mid的值向上还是向下取整根据题意。（普遍是向下取整）mid值取到之后注意下一次查找不包括上一次的mid值。
      • 适合顺序存储即有序表，最多查找次数为∟log2 n⌟ （向下取整）+1。
    • 分块查找：
      • 索引顺序查找
        • 大事化小。为每个块建立索引表，索引表记录每块的最大值及其起始位置。确定块后，在块内使用顺序查找或二分查找定位目标值。例如有元素 2 1 0 3 5 4 7 6 8，可以看到这些元素是部分有序的，我们把2 1 0分为一个块其中最大值为2，3 5 4分为一个块其中最大值为5，7 6 8分为一个块其中最大值为8，再在每个块中进行查找。
  • 3)动态查找：平衡、排序、B_树、哈希表。

      • 原理：顺序地探查可用存储单元。

//Java代码实现
public static int[] insertionSort(int[] array) {
		if (array.length == 0)
				return array;
		int current;
		for (int i = 0; i < array.length - 1; i++) {
				current = array[i + 1];
				int preIndex = i;
				while (preIndex >= 0 && current < array[preIndex]) {
						array[preIndex + 1] = array[preIndex];
						preIndex--; //令current和前i个元素进行比较
				}
				array[preIndex + 1] = current;
		}
		return array;
}

public static int[] bubbleSort(int[] array) {
		if (array.length == 0)
				return array;
		for (int i = 0; i < array.length; i++)
				for (int j = 0; j < array.length - 1 - i; j++)
						if (array[j + 1] < array[j]) {
								int temp = array[j + 1];
								array[j + 1] = array[j];
								array[j] = temp;
						}
		return array;
}

//Java代码实现
public static int[] MergeSort(int[] array) {
		if (array.length < 2) return array;
		int mid = array.length / 2;
		int[] left = Arrays.copyOfRange(array, 0, mid);
		int[] right = Arrays.copyOfRange(array, mid, array.length);
		return merge(MergeSort(left), MergeSort(right));
}

//将两段排序好的数组结合成一个排序数组
public static int[] merge(int[] left, int[] right) {
		int[] result = new int[left.length + right.length];
		for (int index = 0, i = 0, j = 0; index < result.length; index++) {
				if (i >= left.length)
						result[index] = right[j++];
				else if (j >= right.length)
						result[index] = left[i++];
				else if (left[i] > right[j])
						result[index] = right[j++];
				else
						result[index] = left[i++];
		}
		return result;
}

//Java代码实现
public static int[] QuickSort(int[] array, int start, int end) {
		if (array.length < 1 || start < 0 || end >= array.length || start > end) return null;
		int smallIndex = partition(array, start, end);
		if (smallIndex > start)
				QuickSort(array, start, smallIndex - 1);
		if (smallIndex < end)
				QuickSort(array, smallIndex + 1, end);
		return array;
}

//快速排序算法——partition
public static int partition(int[] array, int start, int end) {
		int pivot = (int) (start + Math.random() * (end - start + 1));
		int smallIndex = start - 1;
		swap(array, pivot, end);
		for (int i = start; i <= end; i++)
				if (array[i] <= array[end]) {
						smallIndex++;
						if (i > smallIndex)
								swap(array, i, smallIndex);
				}
		return smallIndex;
}

//交换数组内两个元素
public static void swap(int[] array, int i, int j) {
		int temp = array[i];
		array[i] = array[j];
		array[j] = temp;
}

(7)选择排序-堆排序

  • 1)堆
    • 堆是完全二叉树（层次遍历），如果任一结点≥其左右子树，那么为大根堆/大顶堆，反之，如果任一结点≤其左右子树，那么为小根堆/小顶堆。
    • （构造大顶堆一定要构造二叉树再进行比较，不能仅根据其特性来判断）
  • 2)堆排序
    • 原理：构造堆，由于堆的性质，根节点一定是最小/最大的元素，将其与前/后元素交换，新堆再将根节点调整为剩余元素中最小/最大的元素，依次排序。
    • 特点：每一轮排序都能确定一个元素的位置，即N个元素，最多通过n-1轮排序即可获得其大顶堆/小顶堆。

//C代码实现
//2022下
#include <stdio.h>

#define MAXITEM 100

/*
 * 主要变量说明n：待排序的数组长度R[]：待排序数组，n 个数放在 R[1]，R[2]，...，R[n]中，即下标从1开始
 * 调正堆
 * R：待排序数组；
 * V：结点编号, 以 v 为根的二叉树, R[v] ≥ R[2v], R[v] ≥ R[2v + 1],
 * 且其左子树和右子树都是大顶堆；
 * n：堆结构的规模，即堆中的元素数
 */
void Heapify(int R[MAXITEM], int v, int n) {
    int i, j;
    i = v;
    j = 2 * i; //即j是i的左子树下标

    R[0] = R[i];
    while (j <= n) { //j <= n意为判断j是否在n这个数组里，如果为假说明j对应的根结点i没有左子树
        if (j < n && R[j] < R[j + 1]) { //R[j] < R[j + 1]即j + 1（右子树）的值更大
            j ++ ;
        }
        if ((1)) {//交换 (1)答案：R[0] < R[j]
            R[i] = R[j]; //j的值赋值给i
            i = j;
            j = 2 * i;
        } else {
            j = n + 1;
        }
    }
    R[i] = R[0];
}

/* 堆排序，R 为待排序数组： n 为数组大小 */
void HeapSort(int R[MAXITEM], int n) {
    int i;

    for (i = n / 2; i >= 1; i -- ) { // 构建初始大顶堆，即调整有左右子树的结点，从下向上调整，例如有5个元素，第一个调整的结点即n / 2（向下取整）第2个结点
        (2); //方法调用 (2)答案：Heapify(R, i, n)
    }
    
    for (i = n; (3); i -- ) { //调整大顶堆直到只有1个元素 (3)答案：i > 1
        R[0] = R[i];
        R[i] = R[1];
        (4); //交换 (4)答案：R[1] = R[0]
        Heapify(R, 1, i - 1);
    }
}

int main() {
    int R[] = {0, 7, 10, 13, 15, 4, 20, 19, 8};
    int n = 8;

    HeapSort(R, n);

    int k;
    for (k = 1; k <= n; k ++ ) printf("%d ", R[k]);

    return 0;
}

对数组A=（2，8，7，1，3，5，6，4）构建大顶堆为（用数组表示）？
解答：如图，先根据已知数组层序排列完全二叉树，再一步步从分支从下往上进行调整，每次调换与子树中最大的那个值进行调换（如果是小顶堆则与最小的值进行调换），调换4和1的位置，调换2和8的位置，此时发现2的位置上依旧小于子树，调换2和4的位置，得到满足条件的大顶堆（8，4，7，2，3，5，6，1）。

//Java代码实现
public static int[] selectionSort(int[] array) {
		if (array.length == 0)
				return array;
		for (int i = 0; i < array.length; i++) {
				int minIndex = i;
				for (int j = i; j < array.length; j++) {
						if (array[j] < array[minIndex]) //找到最小的数
								minIndex = j; //将最小数的索引保存
				}
				int temp = array[minIndex]; //用临时变量储存最小值下标
				array[minIndex] = array[i];
				array[i] = temp;
		}
		return array;
}

//Java代码实现
public static int[] ShellSort(int[] array) {
		int len = array.length;
		int temp, gap = len / 2;
		while (gap > 0) {
				for (int i = gap; i < len; i++) {
						temp = array[i];
						int preIndex = i - gap;
						while (preIndex >= 0 && array[preIndex] > temp) {
								array[preIndex + gap] = array[preIndex];
								preIndex -= gap;
						}
						array[preIndex + gap] = temp;
				}
				gap /= 2;
		}
		return array;
}
