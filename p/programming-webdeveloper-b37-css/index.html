    <meta charset="UTF-8">
    <title>Title</title>
    <style>
    
        /*
        后代选择器：某个元素的后面，本次即选择body层级之下的所有p标签
         */
        body p{
            background: red;
        }
        
        /*
        子选择器：用符号">"，仅选择下一层级，本次即选择body的下一层级的p标签
        记忆：">"指向下一代
        */
        body>p{
            background: #3cbda6;
        }
        
        /*
        相邻同胞选择器：用符号"+"，只选择同辈，且选择相邻向下的p标签
        记忆："+"加向下的1个
        */
        .active + p{
				/*选择active类的标签 */
            background: #a13d30;
        }
        
        /*
        通用选择器：用符号"~"，当前选中元素的向下的同辈p标签
        记忆："~"表示范围
        */
        .active ~ p{
            background: #02ff00;
        }
    </style>
</head>

3.美化页面

(1)字体样式

  • font-family：字体。
  • font-size：字体大小。
  • font-weight：字体粗细。
  • color：字体颜色。颜色的常见表示方式有3种：
    • 预定义的颜色名关键字。例如red、blue、grey。
    • rgb表示法，红绿蓝三原色，每项取值范围：0-255。例如rgb(0,0,0)。
    • 十六进制表示法，#开头，将数字转换成十六进制表示。例如#ff0000。

(4)边框塌陷

  • 1)清除浮动元素：clear:。clear: right：清除右侧浮动元素；clear: left：清除左侧浮动元素；clear: both：两侧都不允许浮动元素；clear: none：默认值，不做处理。
  • 2)解决方案一（不够灵活不推荐）：增加基类元素的高度。
  • 3)解决方案二：增加一个空的div标签，通过调用这个标签清除浮动。
  • 4)解决方案三：溢出控制。在基类元素中增加一个overflow属性。overflow:hidden;，隐藏超出部分，overflow:scroll;，超出部分为滚动条。
  • 5)解决方案四：最推荐，基类添加一个伪类after，这样不会像增加一个空的div标签而显得冗余。

(2)绝对定位和固定定位

  • 绝对：
    • 相对于基类或浏览器的位置进行指定的偏移。
    • 绝对定位不在标准文档流中，原来的位置不会被保留。
  • 特点：
    • 没有基类元素定位的前提下，即相对于浏览器定位。
    • 假设基类元素存在定位，通常做法是相对于基类元素进行偏移；
    • 在基类元素范围内移动。
  • 固定：
    • 相对于浏览器的初始状态进行指定的偏移。
    • 实际应用：“返回顶部”。
