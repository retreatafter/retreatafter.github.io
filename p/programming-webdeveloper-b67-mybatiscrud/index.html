Mybatis实现CRUD

1.查询

  • 1)查询所有数据
    • Mapper接口，无参数，返回值由数组接收，例：List<Brand> selectAll();。
    • SQL映射文件，例：<select id="selectAll" resultType="com.retreatafter.pojo.Brand">select * from tb_brand;</select>。
    • 执行方法，核心方法例：List<Brand> brands = brandMapper.selectAll();。
  • 2)查看某个物品详情
    • Mapper接口，参数为主键，返回值只有1个，例：Brand selectByld(int id);。
    • SQL映射文件，例：<select id="selectById" resultType="com.retreatafter.pojo.Brand">select * from tb_brand where id = #{id};</select>。
    • 执行方法，核心方法例：Brand brand = brandMapper.selectById(id);。
  • 3)条件查询
    • (A)多条件查询
      • Mapper接口，参数为所有的查询条件，返回值由数组接收，这里接收有三种方式，散装参数方式例：List<Brand> selectByCondition(@Param("status")int status, @Param("companyName")String companyName, @Param("brandName")String brandName);；对象参数方式例：List<Brand> selectByCondition(Brand brand); ；Map集合参数方式例：List<Brand> selectByCondition(Map map);。
      • SQL映射文件，例：<select id="selectByCondition" resultMap="com.retreatafter.pojo.brandResultMap">select * from tb_brand where status = #{status} and company_name like #{companyName} and brand_name like #{brandName};</select>。
      • 执行方法，根据在Mapper接口处理多个参数的方式不同，执行方法传进的参数也有所区别，散装参数方式例：List<Brand> brands = brandMapper.selectByCondition(status,companyName,brandName);；对象参数方式例：List<Brand> brands = brandMapper.selectByCondition(brand);；Map集合参数方式例：List<Brand> brands = brandMapper.selectByCondition(map);。
    • (B)多条件动态查询：多条件查询基础上SQL映射文件使用动态SQL。
    • (C)单条件动态查询
      • Mapper接口，参数为对象，返回值由数组接收，例：List<Brand> selectByConditionSingle(Brand brand);。
      • SQL映射文件，使用动态SQL，例：<select id="selectByConditionSingle" resultMap="com.retreatafter.pojo.brandResultMap"> select * from tb_brand <where> <choose> <when test="status != null"> status = #{status} </when> <when test="companyName != null and companyName != ''"> company_name like #{companyName} </when> <when test="brandName != null and brandName != ''"> brand_name like #{brandName}; </when> </choose> </where> </select>。
      • 执行方法，核心方法例：List<Brand> brands = brandMapper.selectByConditionSingle(brand);。

2.添加

  • 1)添加字段
    • Mapper接口，参数为主键（这里为id）之外的其它数据，无返回值，例：void add(Brand brand);。（这里已经将参数声明定义且封装为对象brand）
    • SQL映射文件，例：<insert id="add">insert into tb_brand(brand_name, company_hame, ordered, description, status) values (#{brandName}, #{companyName}, #{ordered}, #{description}, #{status});</insert>。
    • 执行方法，核心方法例：brandMapper.add(brand);。并提交事务sqlsession.commit()，或者获取sqlSession对象时传递参数openSession(true)自动提交事务。
  • 2)主键返回的添加：SQL映射文件中配置属性useGeneratedkeys和keyProperty（主键名称），例：<insert id="add" useGeneratedkeys="true" keyProperty="id">insert into tb_brand(brand_name, company_hame, ordered, description, status) values (#{brandName}, #{companyName}, #{ordered}, #{description}, #{status});</insert>。

3.修改

  • 1)修改全部字段
    • Mapper接口，参数为所有列，无返回值，例：void update(Brand brand);。（这里已经将参数声明定义且封装为对象brand）
    • SQL映射文件，例：<update id="update">update tb_brand set brand_name=#{brandName}, company_hame=#{companyName}, ordered=#{ordered}, description=#{description}, status=#{status} where id = #{id};</update>。
    • 执行方法，核心方法例：brandMapper.update(brand);。
  • 2)修改动态字段：修改字段基础上SQL映射文件使用动态SQL。例：<update id="update">update tb_brand <set> <if test="brandName != null and brandName != ''"> brand_name=#{brandName}, </if> <if test="companyName != null and companyName != ''"> company_hame=#{companyName}, </if> <if test="ordered != null"> ordered=#{ordered}, </if> <if test="description != null and description != ''"> description=#{description}, </if> <if test="status != null"> status=#{status} </if> </set> where id = #{id};</update>。

4.删除

  • 1)删除一个
    • Mapper接口，参数主键（这里为id），无返回值，例：void deleteById(int id);。
    • SQL映射文件，例：<delete id="deleteById"> delete from tb_brand where id = #{id};</delete>。
    • 执行方法，核心方法例：brandMapper.deleteById(id);。
  • 2)批量删除
    • Mapper接口，参数主键组成的数组（这里为id组成的数组ids），返回值由数组接收，例：void deleteByIds(@Param("ids")int[] ids);。使用@Param注解是为了改变SQL映射文件中collection的默认key的名称，相当于重命名。
    • SQL映射文件，使用动态SQL，例：<delete id="deleteByIds"> delete from tb_brand where id = in (<foreach collection="ids" item="id" separator=","> #{id} </foreach>);</delete>。
    • 执行方法，核心方法例：brandMapper.deleteByIds(ids);。
