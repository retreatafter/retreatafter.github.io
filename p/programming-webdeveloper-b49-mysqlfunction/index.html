2.聚合函数

  • (1)COUNT()：返回满足Select条件的记录总和数。
  • (2)SUM()：返回数字字段或表达式列作统计，返回一列的总和。
  • (3)AVG()：通常为数值字段或表达列作统计，返回一列的平均值。
  • (4)MAX()：可以为数值字段，字符字段或表达式列作统计，返回最大的值。
  • (5)MIN()：可以为数值字段，字符字段或表达式列作统计，返回最小的值。

-- 示例代码
-- 以下三种方式都表示对全部数据行的查询
SELECT COUNT(studentname) FROM student; -- count(字段)，会忽略null值
SELECT COUNT(*) FROM student;  -- count(*)，不会忽略null值
SELECT COUNT(1) FROM student;  -- count(1) 推荐，不会忽略null值

3.流程函数

  • (1)if(表达式, tvalue, fvalue)，含义：当表达式为true时，取值tvalue；当表达式为false时，取值fvalue，例如：

-- 男性与女性员工的人数统计 (1 : 男性员工 , 2 : 女性员工)
select
        if(gender = 1, '男性员工' , '女性员工') '性别',
        count(*) '人数'
from emp group by gender;
  • (2)case expr when value1 then result1 [when value2 then value2 ...] [else result] end，例如：

-- 员工职位信息
select
       (case when job = 1 then '班主任' when job = 2 then '讲师' when job = 3 then '教研主管' when job = 4 then '学工主管' else '无职位' end ) '职位',
       count(*)
from emp group by job;

4.MD5加密

  • (1)MD5信息摘要算法，特点是不可逆性。MD5破解网站（密码破解）的原理是和“字典”进行对比，将常见的MD5加密后的值进行对比，因此比较复杂的值通常是无法破解的。
