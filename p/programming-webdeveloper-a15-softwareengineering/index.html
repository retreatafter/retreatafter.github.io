1.防火墙

  • (1)概念：防火墙(Firewall)是在内部网络和外部因特网之间增加的一道安全防护措施，它认为内部网络是安全的，外部网络是不安全的。分为网络级防火墙和应用级防火墙。核心功能是网络安全防护（如访问控制、入侵防御）、安全过滤（如ACL、状态检测）。
    • 工作层次、工作效率、安全性之间的关系：工作层次越低，需要处理的工作越简单，工作效率会越高，但安全性越低。
    • 网络级防火墙，层次低，但是效率高，因为其使用包过滤和状态监测手段，一般只检验网络包外在（起始地址、状态）属性是否异常，若异常，则过滤掉，不与内网通信，因此对应用和用户是透明的。但是这样的问题是，如果遇到伪装的危险数据包就没办法过滤。
    • 应用级防火墙，层次高，效率低，因为应用级防火墙会将网络包拆开，具体检查里面的数据是否有问题，会消耗大量时间，造成效率低下，但是安全强度高。包括双宿主主机、屏蔽主机网关、被屏蔽子网等方法。保护程度由低至高：内网、DMZ（非军事区，通常放置公用服务器）、外网。
  • (2)防火墙技术三个发展阶段：包过滤、应用代理网关、状态检测技术。
    • 1)包过滤防火墙
      • 对数据包的过滤依据：源IP地址、目的IP地址、协议、源端口号。
      • 特点：安全性低、成本低；对应用和用户透明；内容是网络层的数据报文。
    • 2)应用代理网关防火墙
      • 所有通信都必须经应用层代理软件转发，是内部网和外部网的隔离点。
      • 特点：安全性高，难以配置，处理速度慢（即网络整体性能会受到影响）。
    • 3)状态检测技术防火墙
      • 结合了代理防火墙的安全性和包过滤防火墙的高速度等优点。
  • (3)防火墙特点：
    • 通过在出口防火墙上配置访问控制列表ACL功能可以阻止外部未授权用户访问内部网络。
    • 防火墙无法查毒杀毒、漏洞扫描。
  • (4)易混淆的：
    • IDS（Intrusion Detection System，入侵检测系统）：专用于安全监控，如威胁检测。IDS攻击包括端口扫描、广播风暴、系统漏洞攻击。
      • 端口扫描即攻击者通过扫描目标系统的开放端口来寻找潜在的安全漏洞。IDS可以通过监控网络流量来检测端口扫描行为。
      • 广播风暴是指网络中大量的广播数据包导致网络拥堵甚至瘫痪的现象。攻击者可能会利用广播风暴来干扰IDS的正常运行。
      • 系统漏洞攻击是攻击者通过利用系统中的已知漏洞来发起攻击。IDS可以通过分析网络流量和系统日志来检测潜在的系统漏洞攻击。
    • 网闸：用于物理隔离网络，如涉密网络。
    • QoS（Quality of Service）即服务质量，是一种网络流量管理机制，通过优先级调度、带宽保障和拥塞控制等技术，确保关键业务流量（如语音、视频）低延迟、低丢包。核心部署位置是路由器。

2.病毒木马

  • (1)概念：
    • 病毒：编制或者在计算机程序中插入的破坏计算机功能或者破坏数据，影响计算机使用并且能够自我复制的一组计算机指令或者程序代码。
      • 宏病毒Macro：感染的对象为文本文档Word、电子表格Excel等。
      • 蠕虫病毒：计算机端虫病毒是一种会自我复制并主动散播到网络系统上的其它计算机里面，就像虫子一样在网络系统里面到处爬蹿，所以称为“蠕虫”。特点为人为的、可自我复制的。例如熊猫烧香、欢乐时光、红色代码、爱虫病毒、震网Stuxnet。
    • 木马：典型特征是有未知程序试图建立网络连接。客户端是攻击者，服务器端是用户。伪装成程序或游戏，当用户下载了带有木马的软件或附件时，这个程序就会向黑客发起连接请求，建立连接后黑客就实施攻击活动，盗取信息。
      • 木马软件Trojan：获取未授权的访问权限、窃取敏感信息、远程控制受感染系统、进行非法操作或者作为其它攻击的入口。伪装为”系统服务“的方式，建立网络连接。恶意软件。例如冰河、X卧底。
  • (2)病毒特征：传播性、隐蔽性、感染性、潜伏性、触发性、破坏性。

3.网络攻击

  • (1)主动攻击与被动攻击
    • 主动攻击：攻击者试图改变、破坏系统或网络的正常运行，包括中断、伪造等行为。如：篡改信息、欺骗攻击、拒绝服务攻击、重放攻击。
    • 被动攻击：攻击者获取/截获机密信息，但不更改或破坏数据。如：嗅探信息、数据流分析、流量分析、会话拦截。
  • (2)检测远程主机状态
    • 端口扫描技术检测远程主机状态是攻击远程主机的手段。
  • (3)拒绝服务攻击/DoS攻击
    • 特点：不断向计算机发起请求，使得所有可用的系统资源都被消耗殆尽，最终计算机无法再处理合法用户的请求。
    • 目的：使计算机或网络无法提供正常服务。
    • 常见的拒绝服务攻击有SYN Flodding攻击。
  • (4)重放攻击
    • 特点：攻击者发送一个目的主机已经接受过的报文来达到攻击目的。主要用于身份认证过程。
    • 目的：破坏认证的正确性。
    • 避免手段：在报文中加入时间戳。
  • (5)SQL注入攻击：是黑客对数据库进行攻击的常用手段之一。目标是获得数据库的权限。没有对用户输入数据的合法性进行判断，使应用程序存在安全隐患。攻击者可以提交一段数据库查询代码，根据程序返回的结果，获得某些它想得知的数据，首先获取数据库的权限，就可获取用户账号和口令信息，以及对某些数据修改等。
  • (6)欺骗攻击
    • 端口欺骗攻击：采用端口扫描找到系统漏洞从而实施攻击。
    • IP欺骗攻击：产生的IP数据包为伪造的源IP地址，以便冒充其它系统或发件人的身份。
  • (7)口令入侵攻击：使用某些合法用户的账号和口令登录到目的主机，然后再实施攻击活动。
  • (8)网络监听
    • 攻击者可以接收某一网段在同一条物理通道上传输的所有信息，使用网络监听可以轻松截取包括账号和口令在内的信息资料。
    • 防范手段：数据加密。
  • (9)入侵检测技术包括专家系统、模型检测、简单匹配。
  • (10)零日漏洞攻击：指利用尚未被公开披露或厂商未修复的软件漏洞（即“零日漏洞”）实施的网络攻击。例如震网Stuxnet病毒，利用Windows系统的零日漏洞入侵伊朗核设施，破坏离心机控制系统。
  • (11)供应链投毒：指攻击者在软件的开发、构建、分发等合法流程中植入恶意代码，例如在第三方库中注入恶意模块；使用代码混淆技术隐藏恶意行为；利用伪造或盗用的数字证书签名恶意组件，绕过审查机制。
  • (12)社工库
    • 拖库：黑客入侵有价值的网络站点，把注册用户的资料数据库全部盗走的行为。
    • 洗库：在取得大量的用户数据之后，黑客会通过一系列的技术手段和黑色产业链将有价值的用户数据变现。
    • 撞库：黑客将得到的数据在其它网站上进行尝试登陆。是指黑客使用在其它服务中已经泄露的用户名和密码组合，尝试登录另一个网站或服务。这是因为很多用户在不同网站上使用相同的用户名和密码。
  • (13)AI赋能攻击：通过使用AI技术改进或自动化各种类型的网络攻击，使攻击更加高效、难以检测和防御。其特点有：
    • 自动识别漏洞：利用机器学习算法自动扫描软件和服务中的潜在安全漏洞，甚至预测未来可能出现的新漏洞。
    • 自动生成恶意代码：基于生成对抗网络（GANs）等技术，Al可以创建高度复杂且难以检测的恶意软件。
    • 社会工程学攻击：通过分析社交媒体和其它公开来源的数据，AI可以帮助攻击者定制更具针对性的社会工程学攻击，如钓鱼邮件。

4.网络安全协议

  • (1)物理层主要使用物理手段，隔离、屏蔽物理设备等，其它层都是靠协议来保证传输的安全。
  • (2)网络层的手段中，IPSec为IP数据报文进行加密。
  • (3)SSL协议(Secure Socket Layer)，安全套接层，安全加密协议，用于在网络通信中提供加密和身份验证的协议，常用于保护网站的安全通信，可用于网银交易。注意与SSH协议区分，SSH(Secure Shell)协议，安全连接，在终端设备与远程站点之间建立安全连接。
  • (4)TLS(Transport Layer Security)，传输层安全协议，其前身是SSL，用于在两个通信应用程序之间提供保密性和数据完整性。
  • (5)Https(Hyper Text Transfer Protocol over Secure Socket Layer)，是使用SSL加密算法的HTTP。默认端口443。
  • (6)PGP(Pretty Good Privacy)，优良加密通信协议，基于RSA公匙加密体系的邮件加密软件，常用于加密和签名电子邮件。
  • (7)SFTP(Secure File Transfer Protocol)，一种基于SSH（Secureshell）协议的安全文件传输协议，数据经过加密传输，确保传输的安全性。
  • (8)网关协议
    • 内部：RIP、OSPF、IS-IS、IGRP、EIGRP
    • 外部：BGP

5.网络安全

  • (1)信息安全基本要素：机密性、完整性、可用性、可控性、可审查性。
  • (2)安全需求可划分为物理线路安全、网络安全、系统安全和应用安全，其中机房安全属于物理线路安全，（物理）入侵检测、流量控制属于网络安全，漏洞补丁管理属于系统安全，数据库安全属于应用安全。数据库容灾属于系统安全和应用安全。（数据恢复、备份）
  • (3)防范网络监听的对策是数据加密。例如http（默认端口80）升级为https（默认端口443）。
  • (6)端口1至1023为公共端口。
