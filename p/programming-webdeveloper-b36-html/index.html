1.基础结构

  • (1)定义：
    • HTML（Hyper Text Markup Language 超文本标记语言），超文本：即不限于文字，包括文字、图片、音频、视频、动画。
  • (2)特点：
    • 1)文件的后缀是.html。
    • 2)HTML标签都是预定义好的。
    • 3)HTML代码直接在浏览器中运行，HTML标签由浏览器解析。
    • 4)标签不区分大小写。

3.页面结构

  • (1)内容：
    • header：标题头部区域的内容（用于页面或者页面中的一块区域）
    • footer：标记脚部区域的内容（用于整个页面或页面的一块区域）
    • nav 导航类辅助内容

4.图片标签

  • (1)格式：<img src="path" alt="text" title="text" width="x" height="y">
    • 标签：img。
    • 属性src：图像地址，可用相对路径和绝对路径（绝对磁盘路径和绝对网络路径即图库），常用相对路径。
    • 属性alt：在图片加载失败的时候，就会用文字代替。
    • 属性title：鼠标悬停在图片上时，所显示的名字。
    • 属性width height：图片的高和宽，单位可以写明像素也可以用百分比表示，百分比指的是相对于上一级元素的百分比。

5.链接标签

  • (1)基本格式：<a href="path" target="目标窗口位置">链接文本或图像</a>
    • 1)标签：<a>。
    • 2)属性：
      • href必填，Hypertext Reference，超文本引用，path为链接路径，指定资源访问的url，表示要跳转到哪个页面。
      • target：表示链接在哪个窗口打开，常用值_self _blank，_blank表示在新标签打开页面，_self表示在当前网页中打开。
    • 3)示例：

8.表单

(1)基本语法

  • 1)表单格式：<form method="get/post" action="result.html">
    • 标签：<form>。
    • 属性：
      • method：选择提交方式，可以选择使用post或者get方式提交。
        • get效率高，但在url中可以看到提交的内容，高效，不安全，不能提交大文件。
        • post表单数据是在请求体（消息体）中携带的，比较安全且可以提交大文件。
      • action：表单提交数据到哪，可以是交给一个网址，也可以是交给一个请求处理地址。
  • 2)表单项：不同类型的input元素、下拉列表、文本域等。
    • 标签：
      • <input>：定义表单项，通过type属性控制输入形式。
      • <select>：定义下拉列表。
      • <textarea>：定义文本域。
  • 3)示例：

(2)表单项

  • 1)type：指定元素的类型，默认为text。

    • text：默认值，定义单行的输入字段。
    • password：定义密码字段。
    • radio：定义单选按钮。
    • checkbox：定义复选框。
    • file：定义文件上传按钮。
    • date/time/datetime-local：定义日期/时间/日期时间。
    • number：定义数字输入框。
    • email：定义邮件输入框。
    • hidden：定义隐藏域。
    • submit / reset / button：定义提交按钮 / 重置按钮 / 可点击按钮。

  • 2)name：指定表单元素的名称（提交时所对应的key）。（必要）

  • 3)value：元素的初始值，radio必须提供。

  • 4)size：指定表单元素的初始宽度。当type为text或者password时，以字符为单位；其它type以像素为单位。

  • 5)maxlength：type为text或者password时，输入的最大字符数。

  • 6)check：type为radio或者checkbox时，指定按钮是否被选中。
