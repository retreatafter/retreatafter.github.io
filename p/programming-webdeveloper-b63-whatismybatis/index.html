1.概述

  • (1)Mybatis是一个开源项目，它是基于JAVA的持久层框架，简化了JDBC（数据保存到数据库，操作数据库）的操作。mybatis是一个sql映射框架，让开发人员集中精神写sql。
    • 持久化是将程序的数据在持久状态和瞬时状态转化的过程，持久状态类似于数据放在数据库中只要数据库存在则数据就存在，而内存的特性断电即失如果数据不转化为持久状态，那么此时瞬时状态的数据就会丢失。而持久层是将数据进行持久化的工作。
  • (2)JDBC的缺陷：
  • (3)Mybatis的功能：
    • 1)提供了创建Connection ,Statement, ResultSet的能力 ，不用开发人员创建这些对象了。
    • 2)提供了执行sql语句的能力， 不用再书写执行sql的代码。
    • 3)提供了循环sql， 把sql的结果转为java对象， List集合的能力。
    • 4)提供了关闭资源的能力，不用再手动关闭Connection, Statement, ResultSet。
  • (4)框架的使用：任何一个框架都有官方文档，而SSM框架都涉及到修改配置文件，相关操作也可以在官方文档中查询到。

    private Integer age;

        this.id = id;
    }
    
    public String getName() {
        return name;
    }
    
    public void setName(String name) {
        this.name = name;
    }
    
    public String getEmail() {
        return email;
    }
    
    public void setEmail(String email) {
        this.email = email;
    }
    
    public Integer getAge() {
        return age;
    }
    
    public void setAge(Integer age) {
        this.age = age;
    }

        return "Student{" +
                "id=" + id +
                ", name='" + name + '\'' +
                ", email='" + email + '\'' +
                ", age=" + age +
                '}';
    }
}

(3)配置文件

  • 2)编写mybatis（mybatis-01）的核心配置文件。在src/main/resources文件夹下新建mybatis-config.xml。
    • 这一块忘记了可以去官方文档下查找后对比修改，这部分是固定内容无需记忆。
    • 主配置文件定义了数据库的配置信息和sql映射文件的位置。
    • mybatis-3-mapper.dtd是约束文件的名称，扩展名是dtd，用于限制，检查在当前文件中出现的标签，属性必须符合mybatis的要求。
    • configuration为根标签，表示各种配置信息。environments环境表示数据库的连接信息，允许配置多套环境，一个数据库用一个environment，environment的id仅表示环境的名称，见名知意即可，而environments的default表示当前用哪一套环境。
    • mappers管理sql映射文件的类路径，每一个Mapper/Dao.xml都需要在mybatis核心配置文件中注册。

<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE configuration
        PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-config.dtd">
<configuration>
    <environments default="mydev">
        <environment id="mydev">
		        <!--事务管理类型，这里可以看到为JDBC-->
            <transactionManager type="JDBC"/>
            <!--数据源，连接数据库 type表示数据源类型，POOLED为使用连接池-->
            <dataSource type="POOLED">
		            <!--属性，根据我们自己在mysql设置的修改对应value值-->
                <property name="driver" value="com.mysql.jdbc.Driver"/>
                <!--这里的/mybatis是我们创建的数据库名为mybatis，如果命名不同则对应修改-->
                <property name="url" value="jdbc:mysql://localhost:3306/mybatis?useSSL=true&amp;useUnicode=true&amp;characterEncoding=UTF-8"/>
                <property name="username" value="root"/>
                <property name="password" value="root"/>
            </dataSource>
        </environment>
    </environments>

    <!--控制mabatis全局行为-->
    <settings>
        <!--输出日志-->
        <setting name="logImpl" value="STDOUT_LOGGING"/>
    </settings>

    <!--sql mapper映射文件的位置-->
    <mappers>
        <mapper resource="com/retreatafter/dao/StudentDao.xml"/>
    </mappers>

</configuration>
  • 3)编写sql映射文件接口实现部分StudentDao.xml（对应表的数据库操作层即增删改查）：
    • mybatis-3-mapper.dtd是约束文件的名称，扩展名是dtd，用于限制，检查在当前文件中出现的标签，属性必须符合mybatis的要求。
    • mapper是当前文件的根标签，必须的。
    • namespace命名空间，绑定一个对应的Dao/Mapper接口，可以是自定义的字符串，但建议使用dao接口的全限定名称。
    • 在当前文件中，可以使用特定的标签，表示数据库的特定操作，<select>表示执行查询，<update>表示更新数据库，<insert>表示插入，<delete>表示删除。语句中id表示要执行的sql语法的唯一标识， mybatis会使用这个id的值来找到要执行的sql语句，可以自定义，但是建议使用接口中的方法名称；sql语句执行后得到resultType，resultType遍历得到转变的java对象的类型，可得resultType为结果集类型的全限定名称。

<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.retreatafter.dao.StudentDao">

    <!--查询操作-->
    <select id="selectStudents" resultType="com.retreatafter.domain.Student" >
        select id,name,email,age from student order by id
    </select>
    <!--插入操作-->
    <insert id="insertStudent">
        insert into student values(#{id},#{name},#{email},#{age})
    </insert>
</mapper>

public class StudentTest {
    //测试方法，测试功能
    @Test
    public void testInsert() throws IOException {
        //访问mybatis读取student数据
        //1.定义mybatis主配置文件的名称, 从类路径的根开始（target/clasess）
        String config="mybatis-config.xml";
        //2.读取这个config表示的文件
        InputStream in = Resources.getResourceAsStream(config);
        //3.创建了SqlSessionFactoryBuilder对象
        SqlSessionFactoryBuilder builder  = new SqlSessionFactoryBuilder();
        //4.创建SqlSessionFactory对象
        SqlSessionFactory factory = builder.build(in);
        //5.获取SqlSession对象，从SqlSessionFactory中获取SqlSession，并开启事务
        SqlSession sqlSession = factory.openSession(true);
        //6.【重要】指定要执行的sql语句的标识，sql映射文件中的namespace + "." + 标签的id值
        String sqlId = "com.retreatafter.dao.StudentDao.selectStudents";
        //7.【重要】执行sql语句，通过sqlId找到语句
        List<Student> studentList = sqlSession.selectList(sqlId);
        //8.输出结果
        studentList.forEach(stu -> System.out.println(stu));
        //9.关闭SqlSession对象
        sqlSession.close();
    }
}

4.Dao代理实现数据库操作

  • (1)动态代理：Mybatis能根据dao接口，创建出dao接口对应的实现类，并创建这个类的对象，再使用SqlSession调用获取执行sql语句的信息。可以看到，Mybatis简化了创建dao实现类的过程。使用前提：
    • dao接口和mapper文件属于同一个目录。
    • dao接口和mapper文件名称一致。
    • mapper文件中的namespace的值是dao接口的全限定名称。
    • mapper文件中的<select><insert><update><delete>等标签的id是接口中方法名称。
  • (2)当我们的dao接口存在多个功能时，例如存在查询、插入等操作，根据动态代理的特性进一步优化代码，核心方法为getMapper(dao接口.class)，以上述的查询为例：

public class StudentTest {
    //测试方法，测试功能
    @Test
    public void testInsert() throws IOException {
        //访问mybatis读取student数据
        //1.定义mybatis主配置文件的名称, 从类路径的根开始（target/clasess）
        String config="mybatis-config.xml";
        //2.读取这个config表示的文件
        InputStream in = Resources.getResourceAsStream(config);
        //3.创建了SqlSessionFactoryBuilder对象
        SqlSessionFactoryBuilder builder  = new SqlSessionFactoryBuilder();
        //4.创建SqlSessionFactory对象
        SqlSessionFactory factory = builder.build(in);
        //5.获取SqlSession对象，从SqlSessionFactory中获取SqlSession，并开启事务
        SqlSession sqlSession = factory.openSession(true);
        //6.【重要】获取对应的dao类
        StudentDao dao = sqlSession.getMapper(StudentDao.class);
        //7.【重要】执行对应方法，执行sql语句
        List<Student> students = dao.selectStudents();
        //8.输出结果
        studentList.forEach(stu -> System.out.println(stu));
        //9.关闭SqlSession对象
        sqlSession.close();
    }
}
