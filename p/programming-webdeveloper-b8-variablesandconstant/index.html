1.变量

(1)概念

  • (1)变量的定义：数据类型 变量名 = 数据值;。
  • (2)特点：变量名不允许重复定义；变量存在作用域范围。

(2)局部变量

  • 位置：方法里
  • 作用域：方法
  • 规则：必须声名和初始化值
  • 注：形式参数实际上也是局部变量。

public class Var {
    //main方法
    public static void main(String[] args) {

        //局部变量：必须声明和初始化值 只在这个方法有用
        int i = 10;
        System.out.println(i);
    }
}

(3)成员变量

1）实例变量

  • 位置：方法外，类里
  • 作用域：类
  • 规则：通过调用类来调用变量，涉及到new对象，若不初始化值也可以在方法里进行调用，会显示默认值，基本数据类型中布尔型默认值是false，其它是0，引用数据类型默认值都是null

public class Var {
    String name;//不用初始化
    int age;

    //main方法
    public static void main(String[] args) {
        //new对象来调用
        Var var = new var();
        System.out.println(var.age);
        System.out.println(var.name);
    }
}

2）类变量

  • 位置：方法外，类里
  • 作用域：类
  • 规则：添加关键字static，方法里可以直接调变量

public class Var {
    //类变量必须由static修饰
    static double salary = 2500;

//main方法
    public static void main(String[] args) {
        System.out.println(salary);

    }
}

3.常量

  • (1)概念：规范叫法为字面量。它的值被设定后，在程序运行过程中不允许被改变。
  • (2)使用规则：关键字final。常见写法由public static final修饰。
  • (3)命名规则：常量名一般使用大写字符，多个单词下划线连接，例如SCHOOL_NAME。

public class Constant {
    //static和final都属于修饰符，不存在先后顺序
    static final double PI = 3.14;
    public static void main(String[] args) {
        System.out.println(PI);
    }
}

4.特殊字符

  • (1)制表符\t：在打印的时候，把前面字符串的长度补齐到8，或者8的整数倍。补齐方式为添加空格，最少补1个空格，最多补8个空格。常用于数据对齐。

  • (2)\r：回车。
  • (3)\n：换行。

5.命名规范

  • (1)局部变量、类成员变量、方法名：首字母小写和驼峰原则 例realName。
  • (2)常量：大写字母，若比较长用下划线 例MAX_VALUE。
  • (3)类名：首字母大写和驼峰原则 例GoodName。
